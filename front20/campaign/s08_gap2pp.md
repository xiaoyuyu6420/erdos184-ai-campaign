## 1. 剖面的自动不变量：三条件实为两条件

**引理 0**。prof(F) = prof(G) ⟹ |F| = |G| 且 C_min(F) = C_min(G)。
*证明*：|F| = deg_F(∅) = deg_G(∅)（level 0 ∈ 剖面）。C_min 是 deg 在非空 Z、|Z| ≤ n−1 上的逐点函数 ⟹ 剖面逐点相等直接传递。∎

**战役含义**：GAP-2″ 的「同剖面、同 spread」中第二条冗余——任何同剖面对自动同 spread。故本报告的分裂对一律自动满足「同 spread」；又 spread 状态（包括 2-spread 与否）本身是剖面泛函，与花状态不同，不存在「spread 分裂」。

## 2. 定理 A：层激活带与决定性阈值（一般 n，完全证明）

**定理 A**。设 F 为 n-一致族（n ≥ 2），宇宙 N 元。
**(a) 激活带**：若 F 含核大小 c 的 3-花，则 **N ≥ 3n − 2c**。等价地：核大小 ≥ c 的花层在 N < 3n − 2c 时恒空。
**(b) 核-(n−1) 层的剖面恒等式（一切 N）**：
  Σ_{Y ∈ binom(U, n−1)} deg_F(Y)·(deg_F(Y)−1)·(deg_F(Y)−2) = 6 · #{F 中核大小恰为 n−1 的无序花}。
**(c) 决定性**：若 N ≤ n+3，则每朵花的核恰为 n−1，且
  T(F) = Σ_{|Y|=n−1} deg_F(Y)(deg_F(Y)−1)(deg_F(Y)−2)，
 右端是纯 level-(n−1) 剖面泛函。特别地 N ≤ n+1 时 T ≡ 0。

*证明*。
(a) 设花 (A,B,C)，核 Y₀，|Y₀| = c。三瓣 A∖Y₀, B∖Y₀, C∖Y₀ 两两不交：若 t 同属两瓣则 t ∈ 两成员之交 = Y₀，与 t 在瓣中矛盾；各瓣又与 Y₀ 不交，各大小 n−c。八块（核 + 3 瓣）两两不交 ⟹ N ≥ c + 3(n−c) = 3n − 2c。∎
(b) 固定 (n−1)-集 Y。含 Y 的成员形如 Y∪{x}（大小 n），故 d_Y(d_Y−1)(d_Y−2) = 含 Y 的互异成员有序三元组数。这样的三元组（成员 = Y∪{a}, Y∪{b}, Y∪{c}，a,b,c 互异）两两交均 = Y ⟹ 是核-Y 花。反之，设 (A,B,C) 是核-(n−1) 花，核 Y₀：(A,B) 有序对在 Y 处被计数 ⟺ Y ⊆ A∩B = Y₀ ⟺ Y = Y₀，且此时 (A,B) 确实被计（d_Y ≥ 3，三成员都含 Y₀）；每无序花恰 6 个有序对，各恰计一次。∴ LHS = 6·#{核-(n−1) 无序花}。∎
（注：这正是 S-05 命题 D1 的恒等式 Σ_{|A∩B|=n−1 对} s(A,B) = Σ_P d(d−1)(d−2) 的花计数重述——该层 s(A,B) = deg(P) − 2 恒定，故两种写法逐项相等。）
(c) 由 (a)：c ≥ (3n−N)/2 ≥ (3n−n−3)/2 = n − 3/2 ⟹ c ≥ n−1；互异成员 ⟹ 瓣非空 ⟹ c ≤ n−1。故 c = n−1，由 (b) T = LHS。N ≤ n+1 时 deg(Y) ≤ N−|Y| ≤ 2 ⟹ 每项 d(d−1)(d−2) = 0 ⟹ T ≡ 0。∎

**推论 A′（无分裂区，μ 下界）**。N ≤ n+3 ⟹ 不存在同剖面族对使 T₁ ≠ T₂（花状态亦剖面决定）。特别地 **μ(n) ≥ n+4**（一切 n ≥ 2），且 n ≤ 3 时该下界在 N = n+2, n+3 处由「T = 6·#{deg(Y)=3} 型星计数」给出显式决定泛函。

**机器确认**（`threshold_check.py`）：n=1（2000 族）；n=2 N=2..5 全枚举（公式 0 违例、0 分裂）；n=3 N=6 全量 2²⁰（公式 0 违例、995085 剖面类 0 分裂）；n=4 N=7 随机 20 万族（0 违例、花核分布恰 {3}）；激活带 n=4 N=9 随机 3 万族（花核分布恰 {2,3}，无 c ≤ 1——与 N ≥ 3n−2 = 7 矛盾排除一致）。n=2 N=6 全枚举：公式违例 24823、分裂类 1322 ⟹ 相变精确发生在 N = n+4。∎（机器）

**推论 A″（小宇宙剖面决定性的显式公式，回答 S-05 D2 的推广）**：
- N ≤ n+1：T ≡ 0；
- N = n+2：T = 6·#{Y : |Y| = n−1, deg(Y) = 3}（度全为星）；
- N = n+3：T = Σ_{|Y|=n−1} d_Y(d_Y−1)(d_Y−2)。
这解释了 S-05 观察的「小 n 搜不出壁垒」：在 N ≤ n+3 内搜分裂是逻辑上不可能的，与算力无关。

**定义（层激活相图）**：由 (a)，核-c 花层在 N ≥ 3n−2c 点亮：c = n−1 于 N ≥ n+2、c = n−2 于 N ≥ n+4、……、c = 0 于 N ≥ 3n。**T 的可分裂性恰在第一非剖面层（核 n−2）点亮处（N = n+4）成为可能**——n ≤ 4 时实现（定理 B/D），n = 5 时于 N = 10 实现（§11.6，差一层），n ≥ 6 开放（§10 遗留 2）。

**定义（R-泛函，GAP-1′ 接口）**：R(F) := T(F) − Σ_{|Y|=n−1} d_Y(d_Y−1)(d_Y−2) = 6·#{核 ≤ n−2 的花}。R 是「剖面不可读花结构」的规范度量：R ≡ 0 当 N ≤ n+3（定理 A）；N ≥ n+4 且 n ≤ 4 时可 R = 6 vs 0（定理 B/D）。任何花版 petal 引理的期望若可从剖面读出，则它读不到 R；S-05 §5「免费期望层」的精确边界即此。

## 4. 命题 E：低 m 不可能性（μ 的 m-轴下界）

> **收尾轮勘误**：本节 E2 的原证明有两处洞（核-0 情形整支缺失；核-1 情形的 deg(x,v) 漏计 D 贡献），且结论可大幅强化。**最终版 = §11.2 命题 E2′**（完全证明，全 N，单点刚性）；E2 作为 E2′ 的推论保留在本节，证明以 §11.2 为准。E1、E3 不受影响（E3 的 ν(3) 数值由 §11.1 更新）。

**命题 E1（m = 3 无分裂；任意 n ≥ 2、任意 N）**。若 prof({A,B,C}) = prof({A′,B′,C′}) 且 {A,B,C} 是花，则 {A′,B′,C′} 亦是花（T₁ = T₂ = 6）。
*证明*：设核 Y，c = |Y|。
- c = 0：F₁ 两两不交 ⟹ 每个 x ∈ V := A∪B∪C 有 deg = 1 ⟹ F₂ 成员两两不交（共享元素将给 deg ≥ 2）且 ⋃F₂ = V。若 n ≥ 3：取互异 a,a′ ∈ A，Y₁ = A∖{a}, Y₂ = A∖{a′}（交 = A∖{a,a′} 大小 n−2 ≥ 1）：剖面相等 ⟹ 两族在 Yᵢ 处的度同为 1 ⟹ Y₁ ⊆ 某 M₁ ∈ F₂、Y₂ ⊆ M₂ ∈ F₂；M₁∩M₂ ⊇ Y₁∩Y₂ ≠ ∅ 且 F₂ 两两不交 ⟹ M₁ = M₂ ⊇ Y₁∪Y₂ = A ⟹ M₁ = A（大小相等）；a 遍历 ⟹ F₂ ⊇ A，对称 ⟹ F₂ = F₁ ⟹ 花。若 n = 2：F₂ 是 6 点完美匹配 ⟹ 本身是核空花 ⟹ T₂ = 6 = T₁。
- c ≥ 1：deg(y) = 3（y ∈ Y）⟹ F₂ 全体成员含 Y（m = 3 = deg）；剖面给出 deg(Y) = 3 ⟹ 三成员皆 ⊇ Y；瓣元素 v：deg(v) = 1 ⟹ v 恰属一个成员 ⟹ F₂ = {Y∪P₁, Y∪P₂, Y∪P₃} 且 P₁,P₂,P₃ 两两不交 ⟹ 核-Y 花。∎

**命题 E2（m = 4 无强分裂；n = 3、任意 N）**。设 prof(F₁) = prof(F₂)，|F_i| = 4，F₁ 含花。则 F₂ 含花。
*证明*：F₁ = 花 {S₁,S₂,S₃} ∪ {D}。

## 5. 定理 C：链接-掩码 gadget（n → n+1 提升）与 n = 4 精确证书

**定理 C（链接-掩码 gadget；n₀ → n₀+1 提升）**。设 D₁, D₂ ⊆ binom(V, n₀)（|V| = n₀+3）满足：
 (H1) prof(D₁) = prof(D₂)（levels 0..n₀−1 全部）；
 (H2) T(D₁) > 0，T(D₂) = 0；
 (H3) **自由元**：存在 s ∈ V 不属于 D₁△D₂ 的任何成员；
 (H4) **上影子配平**：对一切 Z ⊆ V，|Z| ≤ n₀−1：#{a ∈ A : Z ⊆ a} = #{b ∈ B : Z ⊆ b}，其中 A = D₁∖D₂, B = D₂∖D₁（|A| = |B| 由 level-0）。
取新枢轴 x ∉ V，令 E₁ = {b∪{s} : b ∈ B}，E₂ = {a∪{s} : a ∈ A}（均 (n₀+1)-一致），**F_i := {x∪d : d ∈ D_i} ∪ E_i**：F₁, F₂ 是 (n₀+1)-一致族，宇宙 V∪{x}，N = (n₀+3)+1 = n₀+4。
则：(i) prof(F₁) = prof(F₂)（levels ≤ n₀）；(ii) T(F₁) = T(D₁) > 0，T(F₂) = 0；(iii) C_min 传播（两实例机器验证 = 输入值；一般精确传播 [部分核验]）。
*证明*：
(i) 对 Z ⊆ V∪{x}，|Z| ≤ n₀，记 Δ(Z) = deg_{F₁}(Z) − deg_{F₂}(Z)。F_i 成员两类：锥部 x∪d（d ∈ D_i）与掩码部 b∪{s} / a∪{s}。逐点：
 1. x ∈ Z, s ∈ Z（Z = {x}∪Y∪{s}，Y ⊆ V，|Y| ≤ n₀−2）：锥部差 = deg_D 差 at level |Y| ≤ n₀−2 ⟹ 0（H1）；掩码部 ⟺ Z∖{s} = {x}∪Y ⊆ b ⟹ x ∉ b ⟹ 0。Δ = 0。
 2. x ∈ Z, s ∉ Z（Z = {x}∪Y，|Y| ≤ n₀−1）：锥部差 = deg_D 差 at |Y| ≤ n₀−1 ⟹ 0（H1 全 levels——注意 level n₀−1 是 D 的最高剖面层，恰在此被消费）。掩码部：b∪s ⊇ Z 需 s ∈ Z ✗ ⟹ 0。Δ = 0。
 3. x ∉ Z, s ∈ Z（Z = Y∪{s}，|Y| ≤ n₀−1）：锥部：x∪d ⊇ Z 需 s ∈ x∪d，即 s ∈ d——由 (H3)，差半成员不含 s ⟹ Z ⊆ x∪d 且含 s ⟹ 若 |Z| = n₀ 则 Z = d ∈ D₁△D₂ 含 s 矛盾 ⟹ 锥部差 = 0：|Z| ≤ n₀−1 时由 (H1) 为 0；|Z| = n₀ 时由 (H3) 为 0。✓（**(H3) 的精确消费点**：level n₀ 的含 s 剖面点，锥部在此读基隶属，(H3) 使这些点的两侧锥部同时为 0。）掩码部：b∪s ⊇ Z ⟺ Y ⊆ b ⟹ 差 = ud_B(|Y|) − ud_A(|Y|) = 0（H4）。Δ = 0。
 4. x,s ∉ Z（Z ⊆ V）：锥部：Z ⊆ x∪d ⟺ Z ⊆ d（x ∉ Z）：|Z| = n₀ 时不可能（|d| = n₀−1）⟹ 0（level n₀ 无泄漏——锥部的「+x」天然抬高一层）；|Z| ≤ n₀−1：差 = 0（H1）。掩码部：s ∉ Z ⟹ 0。Δ = 0。✓
 ∴ Δ ≡ 0（levels ≤ n₀）。
(ii) F₂ 的花必全锥或全掩码：混合三元组中锥-锥交 ∋ x、锥-掩码交 ∌ x ⟹ 两两交不可能全等。全锥 ⟺ D₂ 花 ⟹ 0（H2）；全掩码 ⟺ B 的花 ⟹ 0（B ⊆ D₂ 无花子族）。锥部映射 d ↦ x∪d 是花保持双射。⟹ T(F₁) = T(D₁) > 0 = T(F₂)（精确：T(F_i) = T(D_i) + T(cone_s(B 或 A)) + 0，而 cone 保 T 且 B,A 无花）。∎
(iii) [部分核验]：机器确认两实例 C_min(F_i) = C_min(D_i) = 2；一般精确传播开放，粗界 C_min(F) ≤ C_min(D) + 1。

**链式不变量（命题 D′）**：(H4) 在输出对上于 levels ≤ n₀ 自动成立（对 Z ⊆ V ∖ {x,s}：两侧都 = ud_A(Z)+ud_B(Z)；对 Z ∋ x：一侧 = ud_A(Z∖x)、另侧 = ud_B(Z∖x)，相等由输入 (H4)（|Z∖x| ≤ n₀−1 全 levels）；对 Z ∋ s：一侧 = ud_B(Z∖s)、另侧 = ud_A(Z∖s) ✓；Z ∋ x,s：两侧皆 0）⟹ (H4) 传播无损。(H3) 的输出自由元 = 旧自由元 ∖ {s}：输出差半成员的元素并 = ⋃(A∪B) ∪ {x,s}（新差半 = {x∪a}∪{b∪s} ∪ 对称，全部含 x 或 s，且元素并恰为并集）。⟹ **每步恰好烧掉一个自由元**。∎

**推论 D1（n = 3 发生学 = S-05 证书的重构）**。以 B3 对（n=2，(H4) at level ≤ 1 = 顶点度：A = {01,45} 度 (1,1,1,1)，B = {05,14} 度 (1,1,1,1) ✓；s = 6 ∉ {01,45,05,14} ✓）为输入，x = 2：输出（重标签 7↦2）逐成员等于 S-05 的 F₁,F₂（机器断言通过）。⟹ **[7] 证书的完整发生学**：链接对 B3 + 掩码元 6 + 枢轴 2；其花的核 {2} = 枢轴，花即「链接中的 3-匹配 + 公共枢轴」。
**推论 D2（n = 4 精确证书）**。以 B4/S-05 对为输入（自由元 s = 3：差半 A′ = {012,056,146,245}, B′ = {016,025,124,456} 均不含 3 ✓；(H4) at levels ≤ 2：顶点度 A′ = B′ = (2,2,2,2,2,2,0)，对度集恒同 ✓），x = 7：输出 4-一致对（m = 10，完整清单见 `cone_lift.py` 输出），机器验证：levels ≤ 3 全部 0 失配、T = 6 vs 0、F₂ 无花（F₁ 唯一花核 {2,7}，大小 2 = n−2）、**C_min = 2（双侧 2-spread）**。∎

**推论 D3（gadget 链的精确终点）**。每步自由元减一（命题 D′）。n=2 基自由元 ≤ 2：差半 ≥ 4 条边（m ≥ 4 的分裂必需，E1），4 条边至少覆盖 4 点，|V| = 6 ⟹ 自由 ≤ 2。⟹ k=1 gadget 类内链长 ≤ 2 ⟹ **覆盖 n ∈ {2,3,4} 后必然止步**。n ≥ 5 需要不同机制（§6）。∎

**构造汇总**：n = 2（三对，N = 6 = n+4）、n = 3（gadget 重构 = S-05，N = 7）、n = 4（gadget，N = 8，m = 10）——全部 N = n+4、C_min = 2、F₂ 侧无花。⟹ **μ(n) = n+4 精确（n ∈ {2,3,4}）**。

### 11.2 命题 E2′（完全证明，全 N）：含花 4-族的剖面单点刚性

**命题 E2′**。设 n = 3、m = 4，F = {S₁, S₂, S₃, D}，其中 S₁,S₂,S₃ 构成 3-花（核 Y，c = |Y| ∈ {0,1,2}）。则任何与 F 同剖面（levels ≤ 2，同宇宙）的族 G 满足 **G = F**。特别地命题 E2（无强分裂）对所有 N 成立，且连弱分裂也没有——剖面类是单点集。

*证明*。对族 F 定义**同成员对图** H_F：顶点 = F 的支撑点，边 = {pq : deg_F({p,q}) ≥ 1}（即「p,q 同属于某成员」）。

**关键引理（三角形刚性）**：G 与 F 同剖面 ⟹ G 的每个成员是 H_F 的三角形。
*证*：M ∈ G ⟹ M 的三对 {p,q} 各满足 deg_G({p,q}) ≥ 1 ⟹ deg_F({p,q}) ≥ 1 ⟹ 三边 ∈ H_F ⟹ 三点在 H_F 中两两相邻 = 三角形。∎

- D ∩ 花点集 = ∅ 或 D 含新点：枚举 D 的边集与花团边集的交。额外三角形 T 需三边两两来自「同成员」，即 T 的任意一边都在某团内。若 T ∋ 新点 s ∈ D：T 的过 s 边 {s,u} ∈ H_F ⟹ u ∈ D∖{s} ⟹ T ⊆ D ⟹ T = D ✓（成员）。若 T ∌ s 且 T ≠ A,B,C：T 的边须由 A,B,C,D∖s 的边拼成；花部（三团共边 {pq}）的三角形只有 A,B,C（跨团边 {r₁,b₁} 等不在 H_F）；含 D-边但不含 s 的边只有可能 {pq}（当 p 或 q ∈ D 时 D 与花团共享边）：此时 T = {p,q,w}，w ∈ {r₁,b₁,c₁,s} ⟹ T ∈ {A,B,C,D} ✓。故无额外三角形 ⟹ G = F。此类含 D ∩ 花点 ≤ 2 + 新点的全部模式。

  T(F) = 6·( Σ_{|Y|=2} C(deg_F(Y), 3) + #{F 的核-1 无序花} )，且类内第一项为常数。
*证明*：核-2 花即星：核 Y（2-集）上 deg(Y) ≥ 3，三个含 Y 成员自动成核-Y 花 ⟹ 核-2 无序花数 = Σ_Y C(d_Y,3)（纯 level-2 剖面）。核-0 花需 N ≥ 9 排除。核-1 花数 = 剩余项。由定理 A(b) 一致性核对：核-(n−1) = 核-2 花数是剖面泛函 ✓。∎

**推论**：分裂振幅 = 6 × (核-1 花数差)。m=7 全穷举最大振幅 12 ⟹ 类内核-1 花数差最大 2；m=8 振幅 24 ⟹ 差 4、|spec| = 3 ⟹ 核-1 花数在类内可取 3 个值。**遗稿初稿猜想「spec ⊆ {0,6}」证伪**——「同剖面花数至多差一」在 m ≥ 7 已不成立；正确的不变量是 R(F) = 6·核-1花数（GAP-1′ 接口的 R-泛函在 [7] 上的显式形）。

### 11.4 N3 定理化：不交组件组合永不分裂

**命题 N3（完全证明）**。设 F_i = A_i ⊔ B_i（i = 1,2），宇宙 U = U_A ⊔ U_B（不交并），A_i ⊆ binom(U_A, a)、B_i ⊆ binom(U_B, b)（a,b ≥ 1，a + b = n）。若 prof_{≤n−1}(F₁) = prof_{≤n−1}(F₂)，则 **A₁ = A₂ 且 B₁ = B₂**（作为族），从而 T(F₁) = T(F₂)。

*证明*：设 M ∈ A₁。b ≥ 1 ⟹ a ≤ n−1 ⟹ |M| ≤ n−1 ⟹ deg_{F₁}(M) ≥ 1 ⟹ deg_{F₂}(M) ≥ 1 ⟹ 存在成员 S ∈ A₂ ∪ B₂、M ⊆ S。B₂ 成员 ⊆ U_B，而 M ⊆ U_A、M ≠ ∅ ⟹ M ⊄ 任何 B₂ 成员 ⟹ S ∈ A₂、|S| = a = |M| ⟹ S = M ⟹ A₁ ⊆ A₂。对称得 A₁ = A₂；同理 B₁ = B₂。∎（机器佐证：随机组件组合 300 例，组件不同 ⟹ levels ≤ n−1 必失配，0 例外。）

**勘误（遗稿脚本注释）**：`cone_lift.py` 旧 docstring 声称「n ≥ 5 由不交并接管（N ≤ 3n）」——**作废**。union-n5 的 14 点失配是机制性的（Z = 组件成员的隶属指示在 level = 组件一致度处裸露），不是实现事故。收尾轮同时修复了一个**真实存在**的实现 bug：n=2 的 H 对/K 对支撑含点 6 而宇宙误声明为 [0,..,5]，levels ≤ 1 验证漏掉 deg(6)；修复后 B1–B4 证书与 gadget 重构全部复算 PASS（修复不影响证书有效性：deg(6) 双侧相等，碰巧健全）。⟹ 不交并不产生任何 μ(n) 上界；但 n=5 的上界已由双步 gadget 独立达成（§11.6：μ(5) ≤ 10），n ≥ 6 的 μ 上界保持开放（§10 遗留 2）。

### 11.5 μ(5) 的 m=4 层清场与口径备注

**事实 A（全穷举）**：n=5、N=9、m=4：C(126,4) = 10,009,125 个 4-族全穷举（`general_scan.py`），剖面类 9,999,675，**零 T-分裂**。

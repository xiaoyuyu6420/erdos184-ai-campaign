## 1. 记号与口径（沿用 s08）

prof(F) = (deg_F(Z))_{|Z| ≤ n−1}；T(F) = 有序 3-花三元组数 = 6 × 无序花数；μ(n) = min{N : 存在 N 元宇宙上 n-一致族对，prof 相等且 T 不等}。族 = 成员互异的集合。「分裂对」= 同剖面且 T 不等的族对（强分裂；不要求一侧无花——gadget 输入才要求 T(G) = 0，见 §3.4）。

## 2. 理论准备（本轮用到的全部引理，逐步证明）

### 2.1 T 差分解（n=5, N=9）

**引理 2.1**。设 F 为 N=9、n=5 一致族。则 F 无核 ≤ 2 的花，且
  T(F) = Σ_{Y ∈ C(U,4)} d_Y(d_Y−1)(d_Y−2) + 6·#{F 的核-3 无序花}，
右端第一项为纯 level-4 剖面泛函。

*证*：核-c 花的支撑 = c + 3(5−c) = 15−2c ≤ 9（八块两两不交，s08 定理 A(a)）⟹ c ≥ 3。c = 4 = n−1 的花数由 s08 定理 A(b) 恒等式（含 Y 的成员形如 Y∪{x}，任三互异者自动成花）给出，是 level-4 剖面泛函。c = 3 的花数即剩余项。∎

**推论 2.2**。同剖面对 (F,G)（N=9、n=5）：T(F) − T(G) = 6·(#核3花(F) − #核3花(G))。特别地 T(F) > T(G) ⟹ F 含核-3 花。∎

### 2.2 影子图与分裂的等价刻画（N=9, n=5）

对 3-集 Y，定义**影子图** E_Y(F)：顶点 = U∖Y（6 点），边 = {Q ∈ C(U∖Y, 2) : Y∪Q ∈ F}。核-Y 花三重 ⟺ 三边两两不交 ⟺ E_Y(F) 的完美匹配（PM）。

**引理 2.3**。同剖面对 (F,G)、T(F) > T(G) ⟹ 存在 3-集 Y₀ 使 PM(E_{Y₀}(F)) > PM(E_{Y₀}(G)) ≥ 0，且 deg_F(Y₀) = deg_G(Y₀) ≥ 3。
*证*：推论 2.2 ⟹ 核-3 花数差 > 0；按核分解 #核3花(F) = Σ_Y PM(E_Y(F))。取差项 Y₀；deg 由剖面相等。∎

### 2.3 覆盖定理（参数化搜索的完备性）

**定理 2.4（m 固定的覆盖）**。设 (F,G) 为 N=9、n=5、|F| = |G| = m 的分裂对，T(F) > T(G)。则存在点置换 σ 使：
  (i)  σ(F) ⊇ {Y∪Q₁, Y∪Q₂, Y∪Q₃}，其中 Y = {0,1,2}、{Q₁,Q₂,Q₃} 是 rest = U∖Y 上两两不交的 2-集三元组（即 rest 上完美匹配）；
  (ii) deg_{σ(G)}(Y) ≥ 3，即 σ(G) 有至少 3 个成员 ⊇ Y。
于是 σ(F) ∈ DomF(m) := {m-族 ⊇ 某 Y-花三重}，σ(G) ∈ DomG(m) := {m-族 : deg ≥ 3 at Y}，且二者同剖面（剖面在点置换下共轭）、T 不等。故「枚举 DomF 全实例建（剖面键 → T 值集合）字典 × 枚举 DomG 全实例查字典、命中条件 = 键同且 T ∉ T 值集合」覆盖一切 m-分裂对。∎

*证明要点*：(i) 中花三重存在由推论 2.2 + 引理 2.3；瓣两两不交 ⟺ 完美匹配（rest 恰 6 点）；(ii) 由剖面逐点性 deg_{σ(G)}(Y) = deg_F(Y) ≥ 3（花三重给出 ≥ 3）。 DomG 的枚举形「3 个含 Y 成员（rest 2-集任取三重，C(15,3) = 455 种）+ (m−3) 个任意其他成员」覆盖一切 deg ≥ 3 的 m-族（含 Y 成员数 3 ≤ d ≤ m 的全部情形——额外成员可再含 Y）。DomF 的枚举形「完美匹配三重 + (m−3) 任意其他成员」同理覆盖一切含核-Y 花的 m-族（可能多花被重复枚举，字典化吸收）。∎

**注意**：搜索器工作在**归一坐标**（花核 = {0,1,2}），检出的是分裂对的归一代表；由点置换群的对称性，检出归一对 ⟺ 检出原对（剖面键在置换下共轭）。这一「坐标差」是 §4 校准中检出数（720）与金标准分裂类数（5040）之比的根源，比率 7 = S₇ 轨道因子，已逐键机器验证。

### 2.4 n=4、N=8 的对应理论（A2 路线）

同构地：核 ≥ (3·4−8)/2 = 2 ⟹ c ∈ {2,3}；核-3 花数 = Σ_{|Y|=3} C(d_Y,3) 纯剖面（c = n−1 层恒等式）⟹ **T-差全部来自核-2 花数 = Σ_{|Y|=2} PM(E_Y)**，E_Y 是 rest 6 点上的影子图，其度序列由 level-3 剖面点 deg(Y∪{x}) 读出。归一核 Y₀ = {0,1}，DomF = 15 完美匹配 × 任意额外成员，DomG = C(15,3) = 455 个含 Y₀ 成员三重 × 任意额外成员。覆盖论证逐字同定理 2.4。∎

gadget 资格（A2 的附加过滤）：(F3) 存在自由元 s ∈ U∖∪(F△G 成员)；(F4) 差半 A = F∖G、B = G∖F 的上影子 levels ≤ n₀−1 逐点相等（定理 C 消费层：输出剖面的 case「x ∉ Z, s ∈ Z」在 |Y| ≤ n₀−1 处调用 ud_A ≡ ud_B）；(F2) T(G) = 0。三关全过 ⟹ s08 定理 C 的 gadget ⟹ (n+1, N+1) = (5, 9) 分裂证书。
*实现勘误留痕*：s09_toolkit.gadget_lift 初版把 (H4) 前置断言写成 levels ≤ n₀−2（弱于定理 C 的 n₀−1）；已修复并复算自击全链 PASS。受影响面评估：历史输入（B4 链、N8 谱系）满足强条件且输出经全剖面独立验证 ⟹ 无实际错误；A2 猎场的资格过滤器同口径已统一（其 m ≤ 6 层 hits = 0，过滤器从未触发 ⟹ 结论不受影响）。过滤器初版用 ≤ n₀−2 是「比定理更严」方向——不会放行假 gadget 输入，只可能把 level n₀−1 失配的对交给 gadget_lift 强断言拒绝，方向安全。∎

### 3.3 机理澄清：影子图边集的剖面裸露

**引理 3.3**。设族 F 的全部成员含 Y（d_Y = m），则对 rest 2-集 Q：deg_F(Q) = 1[Q ∈ E_Y(F)]。
*证*：成员 ⊇ Q 且 ⊇ Y ⟺ 成员 = Y∪Q（|Q| = 2、成员 = Y∪2-集）。∎

**推论 3.4**。m = 6、N = 8（n=4）或 N = 9（n=5）且 d_Y = m 的同剖面对：E_Y(F) = E_Y(G)（边集被 level-2 完全裸露）⟹ PM 数相等 ⟹ 该 Y 无 T-差贡献。特别地「纯 C₆-lift 核心对」（F₀ = {Y∪e : e ∈ C₆} vs G₀ = {Y∪e : e ∈ 2C₃}）**不是分裂对**（本轮机器确认：核心对自身剖面失配）。
**推论 3.4'**。T-差的实现需要：影子图边集差（level-2 部分裸露）+ 非 Y 成员的补偿同时发生 ⟹ m ≥ 6 时 d_Y ≤ m−1 的「部分补偿窗口」是真实门槛；m=6 时补偿成员只有 m−d_Y 个。这一门槛解释了 n=4 N=8 m ≤ 6 与 n=5 N=9 m=5 的清场为何「应该」发生，并与 §5 的机器结果一致。∎

### 3.4 gadget 资格三关与 2-族刚性

**引理 3.5（2-族刚性）**。n₀-一致 2-族 {P₁,P₂} ≠ {Q₁,Q₂} ⟹ levels ≤ n₀−1 剖面必失配。
*证*：4-集/5-集成员由其 (n₀−1)-子集族决定（C(S, n₀−1) 的交 = S）；deg ≤ 1 使影子多重集逐点决定族。∎

**推论 3.6**。差半恰为 2 族的分裂对不满足 (H4)（上影子配平）⟹ gadget 不可用。实例：n=4 N=8 m=6 的 C₆-lift 差半 {0145, 0172} vs {0142, 0175} 在 2-集层失配（{4,5} vs {4,2}）。⟹ gadget 输入需差半 ≥ 3 族且配平——这是 A2 猎场必须向大 m 推进的结构性原因。∎

金标准：32,468,436 族 / 31,993,696 类 / 60,480 分裂类（上棒双实现 + 本轮 general_scan 复核口径）。快速版：G 侧 31,156,580 实例、hits = 30,240、distinct 签名 = **7,560**。比率 60,480 / 7,560 = **8 = N**，与 n=3 N=7 校准的因子结构（5040 / 720 = 7 = N）完全同构——「核位置自由度」因子（分裂类的核可位于 N 个点中任意一个，归一聚合 8:1）。每键 G 侧 T 值实例数 = 30,240/7,560 = 4，亦与 n3N7 的 2880/720 = 4 一致。两条独立的 (n,N) 参数下快速版与金标准的因子结构逐点吻合 ⟹ 快速版在 m=6 语义上的正确性获得双重锚定。

## 7. m-轴完备性的诚实边界

路线 B 的完全证明需要排除 N=9 上一切 m ≥ 5 的分裂对。本轮完成 m ≤ 6。**m ≥ 7 未穷举**，原因：
1. 参数化枚举量随 m 增长为 (#花三重形状) × C(123, m−3)（F 侧）与 455 × C(123, m−3)（G 侧）：m=7 时 G 侧已达 ~48 亿实例，超出 16GB 机器的单日预算；
2. **无 m-归约定理**：不存在把「m-分裂对存在 ⟹ m′ < m 分裂对存在」的已知演绎（往族里加/删成员会同时改变两侧剖面，固定剖面的 T 自由度不随 m 单调）。标注开放。
3. 反向的希望：m 增大 ⟹ 剖面约束（levels ≤ 4 的 255 个点）加强 ⟹ 同剖面类的结构刚性可能压死 T-自由度；若 μ(5) = 10，其证明大概率是一条「大 m 刚性」论证而非穷举。本轮的 d_Y-窗口分析（推论 3.4'）是该方向的第一块砖。

## 10. 结论与遗留

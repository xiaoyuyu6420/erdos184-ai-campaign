# Lane 08：简并度/剥除序路线（degeneracy ordering）

> **结论摘要（5 行）**
> 1. **【完全证明，T2】degeneracy ≤ 2 ⟹ ce ≤ n − c(G)**；更强：每个非树分量满足 ce ≤ nᵢ − 2。等价地 **K₄-minor-free（treewidth ≤ 2）图类上 n−1 成立**，且 n−1 的极值恰为森林。自包含归纳证明 + 725 个随机 2-degenerate 图机器检验 0 违反（§2）。
> 2. **【完全证明，T4（否定）】对每个 d ≥ 3 存在 d-degenerate 无穷族使 ce > n − 1**：K_{3,7}（二部，精确 ce = 10 = n > 9）；K_{3,q}+e（q ≥ 14，**非二部**，率引理 + 机器证书 ce ≥ 17 > 16）；K_{5,11}（d = 5，ce ≥ 16 > 15）。**"除有限类外 degeneracy ≤ 6 ⟹ ce ≤ n−1" 被整体否定**（§4）。
> 3. **【证明 + 猜想，T3】degeneracy ≤ 3 ⟹ ce ≤ ⌊(5n−8)/3⌋**（经 lane_04 R1 + τ ≤ n−c）；**ce ≤ ⌊(4n−6)/3⌋ 为数值支持猜想**（630 例 0 违反）。极家族 **ce(K_{3,q}) = ⌈4q/3⌉ 精确** ⟹ d = 3 的 sup ce/n **下界 4/3 已证**（精确极族 K_{3,q}）；匹配的上界 4/3 = T3b 为开放猜想（已证上界 5/3，T3a）【审查备注：PREPUB_REVIEW Y4——原稿"渐近常数恰为 4/3"为过度声称】（§3）。
> 4. **【框架，T1】** 剥至 d-核 K：**ce(G) ≤ ce(K) + m_R − 2ν(R)**（m_R = 非核边数，ν = R 中边不交圈数），并给出 n−1 成立的精确台账；**修正作战计划**：d-核不是 Δ 有界的（K₅-风车反例，Δ = 4k），"d≤4 时由 Δ≤4 定理得 ce(K)≤|K|−1" 不是合法引用（§1、§5）。

## 0. 对象重述（与简报逐字对齐）

**ce(G)**：E(G) 划分为「圈件（简单圈，长 ≥ 3）∪ 单边件」的最少件数。简报目标之一：n−1 版（注意简报已指出 n−1 版对一般图被 3n/2 下界否定，目标为 O(n)/3n/2 上界或特殊图族的 n−1；本 lane 全程只攻「degeneracy 受限图族」）。

**简并度与核**。G 的 **degeneracy** d := max_{H ⊆ G} δ(H)。**d-核** K := G 的极大 δ ≥ d 子图（唯一）。d-核剥除序：V∖K = {v_1, …, v_t}（t = n − |K|），使 v_i 在 G_i := G[{v_i, …, v_t} ∪ K] 中度数 p_i ≤ d − 1。约定：所有图均为有限简单图；c(G) = 连通分量数。

**两个恒等式**（与 lane_04 记号一致）：
- (E1) 对任意分解 D：Π(D) = m − Σ_{圈件 C∈D}(|C|−1)。故 **ce(G) = m − max savings**，max savings 在「边不交圈族」上取（剩余边全部作单边件即可）。
- (E2) ce(G) = Σ_{分量} ce(Gᵢ)（件是连通的，不跨分量）。

## 1. 框架定理 T1：剥除台账

**引理 1.1（边记账）** 记 R := 生成子图 (V, E(G) ∖ E(K))。则 m_R = Σᵢ p_i ≤ (d−1)t。
*证明*。R 的每条边至少一端在 V∖K；把边 e 归记给其「较早剥除」的端点 v_i（若两端都剥除，归记给下标小者；若一端在 K，归记给剥除端）。归记到 v_i 的边恰是 v_i 在 G_i 中的全部关联边（对更早顶点的边已在早前步骤删除），共 p_i 条。∎

**定理 1.2** ce(G) ≤ ce(K) + ce(R) ≤ ce(K) + m_R − 2ν(R) ≤ ce(K) + (d−1)t，其中 ν(R) := R 中边不交圈的最大个数。
*证明*。第一步：K 与 R 的分解取并（E(K) ⊔ E(R) = E(G)，件不混用即得合法分解）。第二步：取 R 的 ν(R) 个边不交圈，剩余边作单边件：ce(R) ≤ ν(R) + (m_R − Σℓᵢ) = m_R − Σ(ℓᵢ − 1) ≤ m_R − 2ν(R)（每圈 ℓᵢ ≥ 3）。∎

**推论 1.3（n−1 台账）** 若 ce(K) ≤ |K| − 1 + s，则
  ce(G) ≤ n − 1 + s + [Σᵢ(p_i − 1) − 2ν(R)]，且 Σ(p_i − 1) ≤ (d−2)t。
即：d ≤ 2 时台账天然不亏（p_i ≤ 1 ⟹ Σ(p_i−1) ≤ 0）；d = 3 时 n−1 归结为 **2ν(R) ≥ t − s**；d = 4 时归结为 **2ν(R) ≥ 2t − s**。
**推论 1.4** 若 R 是森林，则 ce(G) ≤ ce(K) + n − c(R)；再结合 ce(K) ≤ |K| − 1 得 ce(G) ≤ n − 1。

**警告 1.5（修正作战计划）** 简报任务书写道 "(a) d≤4 时由 Δ≤4 定理得 ce(K)≤|K|−1"。**该引用不合法**：d-核只是 δ ≥ d，不必 Δ ≤ d。反例：**K₅-风车** W_k（k 个 K₅ 共享且仅共享一个顶点 u）是 4-degenerate 的（每片非 u 顶点度恰 4，可剥），δ(W_k) = 4 ⟹ W_k 是自身的 4-核，但 Δ(W_k) = 4k → ∞。（其 ce(W_k) = 2k ≤ |W_k| − 1 仍成立：每片 K₅ 分解为两个边不交 C₅，片间边不交——结论对、引用错。）核的正确通用工具是 lane_04 的 R1：ce(K) ≤ ⌊(m_K + 2τ_K)/3⌋。

## 2. 主定理 T2：degeneracy ≤ 2 ⟹ ce ≤ n − c（n−1 前沿的精确下沿）

**定理 2.1** 设 G 2-degenerate，c = c(G)，s(G) := 非树分量个数。则
  **ce(G) ≤ n − c − s(G)**。
特别地 ce(G) ≤ n − 1，且等号成立当且仅当 G 是森林。由于 2-degenerate ⟺ K₄-minor-free ⟺ treewidth ≤ 2（经典，见 §8 引用），定理亦可表述为：**K₄-minor-free 图有 ce ≤ n − 1**。

*证明*。由 (E2) 与「树的 ce = m = nᵢ − 1」，只需证连通情形：

**引理 2.2（连通情形）** G 连通 2-degenerate。若 G 是树则 ce(G) = n − 1（无圈，全单边件）；若 G 非树则 ce(G) ≤ n − 2。

对 n 归纳。n ≤ 2 时 G 是树。设 n ≥ 3、G 非树。2-degenerate ⟹ 存在 deg(v) ≤ 2 的顶点 v。

**情形 (i)：deg(v) ≤ 1。** G − v 连通且非树（若 G − v 是树，则 G = 树 + 悬挂边仍是树，矛盾）。悬边是桥，任何含它的件必须是过它的圈，不可能 ⟹ **ce(G) = ce(G−v) + 1**（精确）。由归纳假设 ce(G−v) ≤ (n−1) − 2，故 ce(G) ≤ n − 2。∎

**情形 (ii)：deg(v) = 2，N(v) = {u, w}，G − v 不连通**，分为 k ≥ 2 个分支。v 是割点、deg(v) = 2 ⟹ u, w 属于**两个不同**分支（否则另一分支与 v 不连通，矛盾于 G 连通）。两条 v-边都是桥 ⟹ ce(G) = ce(G−v) + 2。各分支 2-degenerate，记 s′ = 非树分支数。归纳假设：ce(G−v) ≤ Σᵢ(nᵢ − 1) − s′ = (n − 1 − k) − s′。若 G − v 全为树（s′ = 0）：G 的圈必须过 v，需要 G − v 中 u–w 路，但 u, w 在不同分支 ⟹ 无此路 ⟹ G 是树，矛盾。故 **s′ ≥ 1**，于是 ce(G) ≤ (n − 1 − k − s′) + 2 ≤ n + 1 − 2 − 1 = n − 2。∎

**情形 (iii)：deg(v) = 2，G′ := G − v 连通。**

**子情形 (α) uw ∈ E(G)。** 断言 **ce(G) ≤ ce(G′)**。证：取 G′ 的最优分解 D；边 uw 恰属于一件 P。若 P = {uw}（单边件）：换成三角形件 {uv, vw, uw}（u ≠ w 且 uw ∈ E ⟹ 三角形简单），件数不变。若 P = C（圈件含 uw）：置 C′ := (C ∖ {uw}) ∪ {uv, vw}；C ∖ {uw} 是 G′ 中简单 u–w 路，v ∉ 其顶点集 ⟹ C′ 是 G 的简单圈；(D ∖ {C}) ∪ {C′} 分解 E(G) 且件数相同。∎
　　若 G′ 是树：G = 树 + v（两条边）恰有一个圈（树中唯一 u–w 路 + uv + vw；uw ∈ E(G) 保证 uw 是树边），G 单圈，ce(G) = 1 + (#桥) = 1 + (n − ℓ) ≤ 1 + n − 3 = n − 2（圈长 ℓ ≥ 3）。若 G′ 非树：归纳假设 ce(G′) ≤ n − 3，故 ce(G) ≤ n − 3 ≤ n − 2。∎

**子情形 (β) uw ∉ E(G)。** 令 G″ := G − v + uw（**溶解** v）。三条性质：
 (a) *G″ 2-degenerate*（引理 2.3，下）；
 (b) G″ 连通（G − v 连通 + uw）；
 (c) *G″ 非树*：若 G″ 是树，则 G − v = G″ − uw 是森林，G 的圈全过 v；过 v 的圈需要 G − v 中的 u–w 路：若存在，则该路 + uw 使 G″ 含圈，矛盾；若不存在，则 G 无圈，是树，矛盾。
 (d) **ce(G) ≤ ce(G″) + 1**：取 G″ 的最优分解 D；含 uw 的件 P：若 P = {uw}（单边件），因 uw ∉ E(G)，换成两个单边件 {uv}, {vw}，+1；若 P = C（圈件含 uw），换成 (C ∖ {uw}) ∪ {uv, vw}（同 (α) 的论证），±0。
由 (a)(b)(c) 与归纳假设：ce(G″) ≤ (n−1) − 2，故 ce(G) ≤ n − 2。∎

**引理 2.3（溶解保持 2-degeneracy）** G 2-degenerate，v 度 2、邻域 {u, w}、uw ∉ E(G)，则 G″ := G − v + uw 2-degenerate。
*证明*。2-degenerate 具遗传性，故只需对每个 H ⊆ G″ 找一个度 ≤ 2 的顶点。若 uw ∉ E(H)：H ⊆ G，取 G 的 2-degenerate 性即得。若 uw ∈ E(H)：令 H* := (H ∖ {uw}) ∪ {uv, vw}。则 H* ⊆ G（uv, vw ∈ E(G)，且 v ∉ V(G″) ⟹ uv, vw ∉ H，添加是真添加，无重边）。H* 2-degenerate ⟹ 存在 z，deg_{H*}(z) ≤ 2。若 z ∉ {u, w}：z 的关联边在 H 与 H* 中相同（uw 不涉 z；uv, vw 不涉 z）⟹ deg_H(z) ≤ 2。若 z = u：deg_{H*}(u) = deg_H(u) − 1 + 1 = deg_H(u)（失 uw 得 uv）⟹ deg_H(u) ≤ 2；z = w 对称。∎

**定理 2.1 收尾**：连通情形由引理 2.2；一般情形由 (E2)：树分量贡献 nᵢ − 1，非树分量贡献 ≤ nᵢ − 2，合计 ce(G) ≤ n − c − s(G)。等号情形：森林 ce = m = n − c ✓；非树分量存在则严格更小。∎

**数值佐证（§6 脚本 A 项）**：725 个随机 2-degenerate 图（n = 7, 8）精确 ce：0 违反 ce ≤ n − c，0 违反 ce ≤ n − 2；且 deg-2 类最大 ce 恰为 n − 2（紧，实例如 K_{2,3}、diamond K₄−e：ce = 3 = n − 2、2 = n − 2，手工可验）。

**新颖性声明**：在本战役知识范围内（含 arXiv 侦察，见 §8），「K₄-minor-free ⟹ ce ≤ n−1」未见先例；相邻工作为 Gallai **路径**分解的 SP 图特例（Kindermann–Schlipf–Schulz 2017），属不同分解目标。标 `[UNVERIFIED-novelty]`，交 Librarian 复核。

## 3. 上界 T3：degeneracy ≤ 3（与一般 d）

**引理 3.1（R1，引用 lane_04 并独立复证）** 对任意连通图 G：ce(G) ≤ τ(G) + ⌊(m − τ(G))/3⌋ = ⌊(m + 2τ(G))/3⌋，τ(G) := 最小 T-join 边数（T = 奇度点集）。
*证明*。取最小 T-join F（|F| = τ）：每点 deg_F ≡ deg_G (mod 2) ⟹ G − F 各点度偶 ⟹ Eulerian ⟹ 边分解为圈；圈数 ≤ ⌊(m − τ)/3⌋；再加 F 的 τ 条单边件。∎（与 lane_04 定理 1.2 一致，独立于本 lane 重证。）

**引理 3.2（τ 的通用上界）** τ(G) ≤ n − c(G)。
*证明*。取 G 的生成森林 X（|E(X)| = n − c）。树的经典事实：对任意终端集 T，X 中的最小 T-join 唯一且为 {e ∈ E(X) : X − e 的某一侧含奇数个终端}（叶子归纳：叶边被强制当且仅当叶是终端；剥叶即得），其大小 ≤ |E(X)|。F_X ⊆ E(G) 且逐点奇偶性与 T 一致 ⟹ 是 G 的 T-join ⟹ τ(G) ≤ n − c。∎

**定理 3.3（T3a，完全证明）** deg(G) ≤ 3，n ≥ 3 ⟹ **ce(G) ≤ ⌊(5n − 8)/3⌋**；一般地 deg(G) ≤ d ⟹
  **ce(G) ≤ ⌊((d+2)n − d(d+1)/2 − 2)/3⌋**（不连通时以 n − c 代 n − 1，更紧），且 ce(G) ≤ m ≤ dn − d(d+1)/2。
*证明*。剥除序给出 m = Σp_i，p_i ≤ 3 且末三位 p ≤ 2, 1, 0 ⟹ m ≤ 3n − 6（一般 d：亏量 0+1+…+(d−1) = d(d+1)/2）。代入 R1 并用引理 3.2（连通时 τ ≤ n − 1）：ce ≤ ⌊(3n − 6 + 2n − 2)/3⌋ = ⌊(5n − 8)/3⌋。∎

**定理 3.4（T3b，猜想 + 数值）** deg(G) ≤ 3 ⟹ ce(G) ≤ ⌊(4n − 6)/3⌋。
*状态*：等价于对 3-degenerate 图证 **τ(G) ≤ (4n − 6 − m)/2**。注意 τ ≤ n/2 一般为假（星 K_{1,3}：τ = 3 > 2 = n/2，叶子强制树边），故需要 m 大时 τ 小的交换律。数值：630 个随机 3-degenerate 图（n = 7, 8, 9，精确 ce 与精确 τ）：0 违反。**GAP 定位**：3-核 K（δ ≥ 3）上证 τ(K) ≤ |K|/2 即可经 T1 推出全局 T3b（树上部分 m 小、不亏账）。标 `[GAP-τ]`。

**定理 3.5（T3c，极家族精确值）** 对一切 q ≥ 2：**ce(K_{3,q}) = ⌈4q/3⌉**。因此 3-degenerate 类的 sup ce/n **≥ 4/3**（下界，渐近由 K_{3,3k} 达到）；匹配上界 4/3 等价于 T3b（开放猜想），当前已证上界为 T3a 的 5/3【审查备注：PREPUB_REVIEW Y4——原稿"sup ce/n = 4/3"降级为下界声称】。
*证明*。上界：q = 3k：把 K_{3,q} 拆成 k 个 K_{3,3}，每个 = 1 个 C₆ + 3 单边件（4 件）：4k = ⌈4q/3⌉。q = 3k+1：(k−1) 块 + K_{3,4}（ce ≤ 6：2 个 C₄ + 4 单边）：4k + 2 = ⌈4q/3⌉。q = 3k+2：k 块 + K_{3,2}（= C₄ + 2 单边 = 3 件【勘误：PREPUB_REVIEW Y5——原稿误写"K_{3,2} = C₄：4k+1"，漏计 2 条单边件】）：4k + 3 = ⌈4q/3⌉。
下界（率引理 4.1，见 §4）：K_{3,q} 的圈 ℓ = 2j，j ≤ 3（A 侧仅 3 点），savings = 2j − 1 ≤ (5/3)·j = (5/3)|C ∩ B|；每个 B 点度 3，至多属 1 个圈 ⟹ B-槽共 q 个。故 ce ≥ 3q − ⌊(5/3)q⌋ = ⌈4q/3⌉。∎
*机器*：q = 6, 7 精确搜索 ce = 8, 10 ✓（§6 F 项）。

## 4. 否定定理 T4：n−1 在每个 degeneracy ≥ 3 处破产

**引理 4.1（槽-率引理）** 设 H 简单图，B ⊆ V，ρ ≥ 0，且 H 的每个圈 C 满足 |C| − 1 ≤ ρ·|C ∩ B|。则 H 的任何分解有至少 **m(H) − ρ·Σ_{v∈B}⌊deg(v)/2⌋** 件。
*证明*。由 (E1)：件数 = m − Σ_圈(|C|−1) ≤ m − ρ·Σ_圈|C∩B|；而 Σ_圈|C∩B| ≤ Σ_{v∈B}（过 v 的圈数） ≤ Σ_{v∈B}⌊deg(v)/2⌋（过 v 的每个圈用掉 v 的 ≥ 2 条边）。∎

**定理 4.2（非二部 3-degenerate 反例族）** 对 q ≥ 14，G_q := K_{3,q} + B 侧内部一条边 xy。则 deg(G_q) = 3、非二部，且 **ce(G_q) ≥ (4q − 7)/3 > q + 2 = n − 1**。
*证明*。G_q 的圈分两类：不含 xy 的圈 ℓ = 2j（交替），j ≤ 3，savings 2j − 1 ≤ (5/3)j；含 xy 的圈 = xy + 一条偶长 x–y 路，ℓ = 2j + 1 ≤ 7（A 侧 ≤ 3），|C∩B| = j + 1，savings = 2j ≤ (5/3)(j + 1) ⟺ j ≤ 5 ✓。B-槽：deg(x) = deg(y) = 4 ⟹ 各 2 槽；其余 q − 2 个 B 点各 ⌊3/2⌋ = 1 槽；共 q + 2。由引理 4.1：
  ce ≥ (3q + 1) − ⌊(5/3)(q + 2)⌋ ≥ (4q − 7)/3 > q + 2 ⟺ q > 13。∎
*机器证书（§6 D 项）*：q = 14（n = 17）：枚举全部 3324 个圈逐个验证率不等式（最大实测率 1.6667 = 5/3），得 ce ≥ 17 > 16；并给出槽相容的显式分解（4 个纯 C₆ + 1 个三角形 + 16 单边 = 21 件）作上界证书：ce ∈ [17, 21]。q = 6, 7, 8 精确搜索：ce = n − 2，**不是**反例（+e 在小 q 处救得回来）。

**定理 4.3（一般奇 d 反例族）** 对 k ≥ 1、q 充分大：K_{2k+1,q} 满足 deg = 2k+1 且
  **ce ≥ (3k+1)/(2k+1) · q − O(1) > n − 1**。
*证明*。圈长 ℓ = 2j ≤ 2(2k+1)，savings 2j − 1 ≤ ((4k+1)/(2k+1))·j（j ≤ 2k+1，递增）；B-槽各 ⌊(2k+1)/2⌋ = k 个，共 kq。ce ≥ (2k+1)q − kq(4k+1)/(2k+1) = q(3k+1)/(2k+1)。与 n − 1 = q + 2k 比较：(3k+1)/(2k+1) > 1，q 大时胜出。∎
*机器证书（§6 E 项）*：k = 2, q = 11（K_{5,11}，n = 16）：枚举全部 794,530 个圈，率不等式 |C|−1 ≤ (9/5)|C∩B| 全部成立（最大实测率恰 1.8，由 C₁₀ 达到），B-槽 22 ⟹ ce ≥ 55 − ⌊(9/5)·22⌋ = 16 > 15。

**推论 4.4（本路线的主结论：前沿精确）** n−1 对**全部** degeneracy ≤ 2 的图成立（T2）；而对每个 d ≥ 3 存在 d-degenerate 无穷族（4.2/4.3，d = 3 处还可取非二部）使 ce > n − 1。**"除有限类外 degeneracy ≤ 6 ⟹ ce ≤ n−1" 型目标被否定**——反例族无界且稠密分布于每个 degeneracy 层级。另注意 (3k+1)/(2k+1) → 3/2：与全局 3n/2 下界图景（简报引 BM2022 line 1060）完全一致，即 K_{2k+1,q} 家族同时是各 degeneracy 层级与全局的极族。

## 5. 与 d = 5, 6 战果的对接（lane_04 / lane_05）

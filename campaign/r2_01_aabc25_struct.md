## 0. 陈述校准与目标

**待证命题（按 AABC25 原文，main.tex:781–794 核对）**：

- **Problem**：6-正则图可分解为至多 n−1 条圈与单边（ce(G) ≤ n−1）。
- **Conjecture**：每个 6-正则图可分解为三个 2-因子，其中一个 2-因子有至少 4 点的分量。

**已知框架（承 Lane 05）**：even + Δ≤6 ⟹ ce ≤ 3⌊n/3⌋ ≤ n（其定理 A(i)）；且 n ≢ 0 (mod 3) 或非 6-正则时 ≤ n−1（A(ii)）。剩余缺口恰为：**6-正则 ∧ n ≡ 0 (mod 3) 时 ce ≤ n−1**。注意 6-正则 ⟹ even ⟹ Δ = 6，完全落入 Lane 05 框架。

**边界事实**：6-正则简单图要求 n ≥ 7；n ≡ 0 (mod 3) 时 n ≥ 9。记 n = 3m。

## 1. 三个归约（把缺口压到一条 4-正则引理）

**引理 0（Petersen 2-因子分解，自足版）**。设 G 为 2k-正则简单图。则 E(G) 可分解为 k 个边不交的支撑 2-因子。

*证明*。G 的每个连通分量所有点度均为偶数 2k 且连通 ⟹ Eulerian；取每个分量的 Euler 环游并沿环游定向每条边（每条边恰被经过一次、定向一次）。每次环游经过点 v 时一进一出，故每个点的出度 = 入度 = k。构造二部图 B(G)：左侧 = V×{out}、右侧 = V×{in}，每条弧 (u,v) 对应边 u_out—v_in；B(G) 是 k-正则二部图。k-正则二部图有完美匹配（Hall：S ⊆ 左侧发出的 k|S| 条边全部进入 N(S)，每个右点至多吸收 k 条 ⟹ |N(S)| ≥ |S|），删去后仍 (k−1)-正则，归纳得 k 个边不交完美匹配（König 1-因子分解）。每个完美匹配给 G 的一个支撑子图：每点恰一条出弧、一条入弧 ⟹ 有向圈的无交并。有向 2-圈需要 (u,v) 与 (v,u) 两条弧，而每条边只定向一次 ⟹ 不存在 ⟹ 所有有向圈长 ≥ 3，其无向化即支撑 2-因子。∎

**归约 1（长圈 2-因子 ⟹ ce ≤ n−1）**。设 G 6-正则、n = 3m、F 为 G 的任一含 ≥4 阶圈的 2-因子。则 ce(G) ≤ n−1。
*证明*。G − E(F) 是 4-正则支撑 even 图，引理 0（k=2）给两个支撑 2-因子 F₁, F₂。三者的分量作为分解件（划分 E(G)）。计件数：F 的分量均为圈、每圈 ≥3 点、有一圈 ≥4 点 ⟹ #comp(F) ≤ 1 + ⌊(n−4)/3⌋ = 1 + (m−2) = m−1；F₁, F₂ 各 ≤ ⌊n/3⌋ = m。合计 ≤ 3m − 1 = n−1。∎

**归约 2（缺口 ⟹ 4-正则引理）**。若「每个 4-正则简单图有含 ≥4 阶圈的 2-因子」（下称引理 1）为真，则每个 6-正则、n ≡ 0 (mod 3) 的图 ce ≤ n−1。
*证明*。n ≥ 9。取 G 的任一 2-因子 F（引理 0，k=3 的因子之一）。若 F 有 ≥4 阶圈，用归约 1。否则 F 的圈全为三角形（F 是三角形因子），令 H := G − E(F)：4-正则支撑图，n = 3m ≥ 9 ≥ 5 个点；引理 1 给 H 的含 ≥4 阶圈的 2-因子 S；T := H − E(S) 是 2-因子。分解件：F 的 m 个三角形 + S 的分量（≤ m−1）+ T 的分量（≤ m）⟹ ≤ n−1。∎

**注（等价性升级）**：同一构造证得 AABC25 的 Conjecture 原文：情形一里 F₀ 本身有 ≥4 点分量；情形二里 S 有。三分解 = F₀（或 F）、F₁、F₂（或 S、T）。故 Conjecture 对全部 6-正则图成立（n ≢ 0 mod 3 时任何 2-因子都非三角形因子，因 3 ∤ n 排除三角形因子）。

## 2. 引理 1（核心）：每个 4-正则简单图有含 ≥4 阶圈的 2-因子

**引理 1**。设 G 为 4-正则简单图，|V(G)| ≥ 5。则 G 有一个 2-因子，其某个圈长 ≥ 4。

*证明*。反设不然：则 G 的**每个** 2-因子的所有圈都是三角形（若某 2-因子有 ≥4 圈即已得证）。

**(1) 存在两个边不交三角形因子。** G 4-正则 ⟹ 引理 0（k=2）给分解 G = F ⊔ F′，F, F′ 均为支撑 2-因子。由反设，F 与 F′（= G − E(F)，也是 2-因子）都是三角形因子。记 n = |V(G)|，则 n = 3m，m = 每侧三角形数 ≥ 2。

**(2) 相交模式必为 (1,1,1)。** 设 τ ∈ F、σ ∈ F′。断言 |V(τ) ∩ V(σ)| ≤ 1：若 a ≠ b 同属二者，则简单图中三角形是其点集上的团 ⟹ 边 ab ∈ E(τ) ∩ E(σ)，与 F, F′ 边不交矛盾。每个点 v 恰属一个 τ(v) ∈ F、一个 σ(v) ∈ F′。若 τ 的两个不同点 v, w 有 σ(v) = σ(w)，则 |V(τ) ∩ V(σ)| ≥ 2 矛盾 ⟹ τ 的 3 个点落在 3 个**互不相同**的 F′-三角形中；对称地 σ 的 3 个点落在 3 个互不相同的 F-三角形中。（m = 2 时「3 个互不相同的 F-三角形」不存在，直接矛盾，引理成立；以下设 m ≥ 3。）

**(3) 关联图表示 G ≅ L(B)。** 定义二部图 B：二部两侧分别为 F 与 F′（B 的点 = 三角形），B 的边 = V(G)：v ↦ τ(v)σ(v)。由 (2)：B 是简单图（B 的重边意味着 |τ ∩ σ| ≥ 2）、3-正则（每个三角形 3 个点）、二部（按构造）。G 与线图 L(B) 同构：G 的点 ↔ B 的边；u ~_G v ⟺ u, v 同属一个三角形（F、F′ 是因子，三角形 = 团，故 G 的边恰为同三角形点对）⟺ 对应 B 边共享 B 端点 ⟺ 相邻于 L(B)。∎(3)

**(4) B 有完美匹配。** B 是 3-正则二部图 ⟹ Hall 条件成立（S 侧发出 3|S| 条边，每个 N(S) 点至多接收 3 条）⟹ 完美匹配 M。给 M 的每条边任意定向；M 完美 ⟹ B 的每个点 x 恰接触 M 的一条边 e_x，x 是 e_x 的**尾**（e_x 离开 x）或**头**（e_x 进入 x），二选一。记 x 处的另外两条边为 f_x, g_x。

**(5) 构造 Φ ⊆ E(G)。** 对 B 的每个点 x：若 x 是尾，取 Φ-邻接对 {e_x f_x, e_x g_x}；若 x 是头，取 {f_x g_x}（注意 {e_x, f_x, g_x} 是 B 中同端点 x 的三条边，任意两条共享端点 x ⟹ 对应 L(B) 的边 ⟹ G 的边）。

**(6) Φ 是支撑 2-因子。** 每个 B 边 h = xy 对应 G 的一个点，其 Φ-度数 = h 在 x 端获得的邻接数 + 在 y 端获得的邻接数：
- h ∈ M：h 在其一端为尾（获得 2）、另一端为头（获得 0）⟹ 度 2；
- h ∉ M：h 在 x 端属于 {f_x, g_x}：x 是尾时得 1（与 e_x 配对）、x 是头时得 1（与另一条非 M 边配对）；y 端同样得 1 ⟹ 度 2。
且无重复计邻接：两条不同 B 边至多共享一个端点（B 简单），邻接对只会在其唯一共享端点处被加入。故 Φ 是 G 的支撑 2-正则子图 = 2-因子（分量是长 ≥3 的圈）。∎(6)

**(7) Φ 无任何三角形。** Φ-三角形的三个点两两 Φ-邻接 ⟹ 两两 L(B)-邻接 ⟹ 对应 B 的三条边两两共享端点 ⟹ 共同端点在一点（星形）或构成 B 的三角形（B 二部，无）。故 Φ-三角形必为某 x 处的星 {e_x, f_x, g_x}。但 f_x 与 g_x 的唯一公共端点是 x：若 x 是尾，x 处加入的是 {e_x f_x, e_x g_x}，不含 f_x g_x ⟹ f_x g_x ∉ Φ；若 x 是头，e_x 与 f_x 的唯一公共端点是 x，x 处未加 e_x f_x ⟹ e_x f_x ∉ Φ。两种情形 Φ-三角形都凑不齐三条边。∎(7)

**(8) 结论。** Φ 是 G 的 2-因子且所有分量长 ≥ 4——与反设矛盾。∎

**推论 1.1**。不存在「所有 2-因子都是三角形因子并」的 4-正则简单图；特别地不存在所有 2-因子彼此同构于 mK₃ 的 4-正则图。

## 3. 主定理

**定理 2**。每个 6-正则简单图 G、|V(G)| ≡ 0 (mod 3)，有 ce(G) ≤ n − 1。
*证明*：归约 2 + 引理 1。∎

**定理 3（AABC25 Conjecture 原文）**。每个 6-正则简单图可分解为三个支撑 2-因子，其中一个 2-因子有至少 4 点的分量。
*证明*：§1 注（等价性升级）。∎

**系 4**。每个 6-正则简单图 ce(G) ≤ n − 1。（n ≡ 0 mod 3 用定理 2；3 ∤ n 时 Lane 05 定理 A(ii)——等价地：任何 2-因子化三因子各 ≤ ⌊n/3⌋ 且和 ≤ 3⌊n/3⌋ = n−1。）

**系 5（封闭 Lane 05 缺口）**。even + Δ ≤ 6 ⟹ ce(G) ≤ n − 1。（Lane 05 定理 A(ii) 的两分支 + 系 4。）

**注记（机理定位，回应任务书的分情形设计）**：任务书设想的「Hamilton / 少大圈 / 多三角形」分情形里，前两类被归约 1 一并吃掉（任一非三角形 2-因子即可，Hamilton 只是特例）；真正的全部困难集中在「多三角形」——而引理 1 说明该情形的结构是刚性的（G = L(B)），Φ(M) 就是所需的「吸收机制」：它把全部 n 个点重组进长 ≥4 的圈，无需逐圈吸收。

```lean
import Mathlib.Combinatorics.SimpleGraph.Basic
-- ce 的建模沿用 notes/attack_delta5.md §5 的 CycleEdgeDecomp / ce

/-- 引理 0：2k-正则简单图有 k 个边不交支撑 2-因子的分解（Petersen）。 -/
theorem two_factorization_of_even_regular (G : SimpleGraph V) [Fintype V]
    (hreg : ∀ v, G.degree v = 2 * k) :
    ∃ Fs : Finset (Finset (Sym2 V)), (∑ F ∈ Fs, F.card) = G.edgeFinset.card ∧
      (∀ F ∈ Fs, IsSpanningTwoFactor G F) := sorry

/-- 引理 1（★）：4-正则简单图有含 ≥4 阶圈的 2-因子。 -/
theorem exists_two_factor_with_long_cycle (G : SimpleGraph V) [Fintype V]
    (hreg : ∀ v, G.degree v = 4) :
    ∃ F : Finset (Sym2 V), IsSpanningTwoFactor G F ∧
      ∃ C ⊆ F, IsCycleEdges C ∧ 4 ≤ C.card := sorry

/-- 定理 2：6-正则 + n ≡ 0 (mod 3) ⟹ ce ≤ n−1。 -/
theorem six_regular_ce_le_pred (G : SimpleGraph V) [Fintype V]
    (hreg : ∀ v, G.degree v = 6) (hn : Fintype.card V % 3 = 0) :
    ce G ≤ Fintype.card V - 1 := sorry

/-- 定理 3：AABC25 Conjecture（三 2-因子分解其一含 ≥4 点分量）。 -/
theorem six_regular_three_two_factors_with_big_component (G : SimpleGraph V) [Fintype V]
    (hreg : ∀ v, G.degree v = 6) :
    ∃ F₁ F₂ F₃ : Finset (Sym2 V),
      F₁ ⫿F₂ ⫿F₃ = G.edgeFinset ∧
      IsSpanningTwoFactor G F₁ ∧ IsSpanningTwoFactor G F₂ ∧ IsSpanningTwoFactor G F₃ ∧
      (∃ C ⊆ F₁ ∪ F₂ ∪ F₃, IsComponentOf C ∧ 4 ≤ C.card) := sorry

/-- 系 5：even + Δ≤6 ⟹ ce ≤ n−1（封闭 Lane 05 定理 A 的例外）。 -/
theorem even_delta6_ce_le_pred (G : SimpleGraph V) [Fintype V]
    (hΔ : ∀ v, G.degree v ≤ 6) (he : ∀ v, Even (G.degree v)) :
    ce G ≤ Fintype.card V - 1 := sorry
```

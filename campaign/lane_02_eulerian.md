## 3. 定理与证明

### 3.1 引理 1（去单边引理 / EG 界到 Eulerian 界的转换器）

**陈述.** 设 H 欧拉，且 E(H) 有一个分成 t 个圈与 e 条单边的分解。则 c(H) ≤ t + ⌊e/3⌋。

**证明.** 设 S 为单边构成的子图。对每个顶点 v：deg_H(v) ≡ 0 (mod 2)，而每个圈片在 v 处贡献 0 或 2，故 deg_S(v) ≡ deg_H(v) ≡ 0 (mod 2)，即 S 全偶。S 的每个非平凡连通片是连通偶图，由 Veblen/Euler 分解为圈；每个圈 ≥ 3 条边，故该片用掉 ≤ e_i/3 个圈（e_i 为其边数）。这些圈是 H 的圈。合计得 E(H) 的纯圈分解，圈数 ≤ t + Σ⌊e_i/3⌋ ≤ t + ⌊e/3⌋。∎

**推论（对题目的意义）.** 任何"n 顶点图 ≤ f(n) 个圈+单边"型定理（EG、CFS O_ε(n)、GGKO (3/2+o(1))n、BM log\* n）**不经任何损失地**给出欧拉图 c(H) ≤ f(n)。

### 3.2 定理 2（与 Erdős–Gallai 的等价；核准 BM line 171/180/1057/1060）

**(i) EG-O(n) ⟹ Eulerian-O(n)。** 设每个 n 顶点图可分解为 ≤ Cn 个圈与单边。对欧拉 H 用之，再由引理 1 得 c(H) ≤ Cn + ⌊Cn/3⌋ = O(n)。∎

**(ii) Hajós ⟹ EG ≤ 3n/2 − 1（BM line 1060 论证的复写）。** 任取 n 顶点图 G。取极大边不相交圈族 𝒰；若 G − 𝒰 含圈则与极大性矛盾，故 G − E(𝒰) 是森林，边数 ≤ n−1。G₁ = (V, E(𝒰)) 欧拉。Hajós 给 c(G₁) ≤ n/2；森林的 n−1 条边作单边。合计 ≤ n/2 + (n−1) = 3n/2 − 1 个圈与单边。∎

**(iii)（BM line 1057）** BM 的 O(n log\* n) 定理按(i)同法给出 c(H) = O(n log\* n)。

**意义（本 lane 的边界条件）.** 由 (i)，任何显式线性 C 的 c(H) ≤ Cn 都立即给出 EG 的 O(n) 版——60 年未决。因此本 lane 的合理产出是：把 C 的存在性 difficulty **精确压到最小结构类**并定位抵抗量（§4），而非期待完整证明。

### 3.3 定理 3（抑制核归约；欧拉图的"核"）

**陈述.** 设 v 是 H 的 2 度点，N(v) = {u, w}，u ≠ w。
(a) 若 uw ∉ E(H)：令 H̃ = H − v + uw（简单图），则 H̃ 欧拉、n(H̃) = n(H) − 1，且 **c(H) = c(H̃)**。
(b) 若 uw ∈ E(H)：令 △ = 三角形 uvw，则 H − E(△) 欧拉、v 变孤立，且 c(H) ≤ 1 + c(H − E(△))。
(c) 迭代抑制得核 M（欧拉多重图，δ(M) ≥ 4，或退化为两点平行边束），满足 c(H) = c(M)、n(H) = n(M) + t(M)，其中 t(M) = 把 M 变成简单图所需的最少剖分顶点数 = Σ_{平行类} (q_c − 1)。

**证明.** (a) 分解看圈：欧拉图中 2 度点 v 的两条边若被分解使用，必属同一圈（过 v 的圈恰用 v 处两条边），且该圈形如 v–u–P–w–v；映射为 u–P–w 即 H̃ 中的圈（P 不含 v）。其余圈不动。反向：H̃ 中含 uw 的圈 u–w–Q–u 映回 u–v–w–Q–u（v ∉ Q 因 v 已删）。逐圈双射 ⟹ c 相等。度：u, w 各 ±1，偶性保持。(b) u, v, w 各失 2 度，欧拉性保持；v 度 2 变孤立；分解 = △ + H′ 的分解。(c) 迭代 (a)（uw ∈ E 的顶点在多重图意义下同样抑制，允许平行边；u = w 即环的情形在简单图核中不出现，多重图核中跳过）。t(M) 即被抑制顶点总数：每条"多余平行边"恰好由一个剖分点产生。∎

**推论 3.4（Hajós ⟺ 核猜想，精确等价）.** HJ 对所有简单欧拉图成立 **⟺** 对所有 δ ≥ 4 的欧拉多重图 M：c(M) ≤ ⌊(n(M) + t(M) − 1)/2⌋。
证明：⟸ 抑制保持 c、n = n(M)+t；若 H 的核退化为两点 q-平行边束（抑制终点也可能是 2-正则多重图），则 H 是该束的细分，c(H) = ⌈q/2⌉ 且 t ≥ q−1（q−1 条平行边各需一条长 ≥2 的细分路），故 ⌈q/2⌉ ≤ ⌊(t+1)/2⌋ = ⌊(n(H)−1)/2⌋ 直接成立，限定 δ ≥ 4 无损。⟹ 任一 δ≥4 欧拉多重图 M 可仅剖分平行冗余边（每类 q_c 条留 1 剖 q_c−1）成简单欧拉图 H，c(H) = c(M)，n(H) = n(M) + t(M)；对 H 用 HJ 即得。∎

**推论 3.5（极小反例结构，注意比任务书中"δ≥4"更弱——诚实修正）.** 若 H 是 HJ 的极小（按 n）反例，则：(i) H 无孤立点；(ii) H 2-连通；(iii) H 的每个 2 度点 v 落在三角形 uvw 中且 deg(u), deg(w) ≥ 4。
证明：(i) 删孤立点保 c、减 n，仍是反例。(ii) 先证欧拉图无桥：桥 e=uv，含 u 的 G−e 分片恰 u 一点奇度，与握手定理矛盾；故块均 2-连通。再证块的欧拉性：块 B 的非割点 x 满足 deg_B(x) = deg_H(x) 偶（x 只属一个块），握手定理给 deg_B(割点) = Σ偶 − 偶 = 偶。故每块欧拉。**圈必整含于单个块**：圈是 2-连通子图，而块是极大 2-连通子图。于是分解限制到每块仍是该块的圈分解，逐块计数得 **c(H) = Σ_B c(B)（精确等式）**；又连通图块满足 n = 1 + Σ_B(|B| − 1)（对块树归纳）。若每块都非反例：c(H) ≤ Σ⌊(|B|−1)/2⌋ ≤ ⌊Σ(|B|−1)/2⌋ = ⌊(n−1)/2⌋，矛盾。故某块是更小反例，极小性 ⟹ H = B 2-连通。(iii) 2 度点 v：若 uw ∉ E，3.3(a) 给出更小反例，矛盾；若 uw ∈ E 且 deg(u) = 2（w 同理对称），3.3(b) 中 u 亦变孤立，n′ = n−2，c(H) ≤ 1 + ⌊(n−3)/2⌋ = ⌊(n−1)/2⌋，矛盾。∎

**注 3.6（Ham 分解充分性）.** 若 2-连通欧拉核 M 可被 Hamilton 圈分解（如 K_{2m+1}，Walecki），则 c(M) = m/n ≤ (n−1)/2 自动成立且除非 m = n(n−1)/2（完全图）均有严格余量。即：**困难全部在"没有 Hamilton 分解、必须长短圈混搭"的核上。**

### 3.4 定理 4（正则带：Petersen 2-因子）

**陈述.** 若 H 是 2k-正则简单图（n 顶点），则 c(H) ≤ k·⌊n/3⌋。

**证明.** Petersen（1891）：2k-正则图的边集可分解为 k 个 2-因子（经典定理；教科书级，如 Bondy–Murty）。每个 2-因子是生成的不相交圈并，每圈 ≥ 3 顶点，故圈数 ≤ ⌊n/3⌋。合计 ≤ k⌊n/3⌋。∎

**推论.** Δ = O(1) 的正则欧拉图有线性界 c ≤ Δn/6。但即使 4-正则（k=2）：得 2n/3，与目标 ⌊(n−1)/2⌋ 差 n/6 + O(1)——**4-正则情形在方法内不闭合**，数值上（§5）随机 4-正则图 c=2 远低于 2n/3，说明 Petersen 分解远非最优。

### 3.5 定理 5（进展判据：孤立点—分裂货币）

**陈述.** 设 H 欧拉。对圈 C（在当前图中）定义 s(C) = |{v ∈ V(C) : deg(v) = 2}|，r(C) = H − E(C) 的非平凡（含边）连通分支数。若 H 的每个非平凡连通分支或者本身是一个圈、或者存在圈 C 使 **s(C) + r(C) ≥ 3**，且该性质对移除过程的每个后继分支遗传（欧拉图的分支欧拉，故"所有欧拉图"即封闭类），则 c(H) ≤ ⌊(n−1)/2⌋。

**证明.** 对 n 归纳。取满足条件的圈 C，H′ = H − E(C)，其非平凡分支 H_1,…,H_r（新孤立点已计入 s）。c(H) ≤ 1 + Σ_j c(H_j)；归纳与 ⌊·⌋ 次可加性：c(H) ≤ 1 + ⌊(Σn_j − r)/2⌋ = 1 + ⌊(n − s − r)/2⌋ ≤ 1 + ⌊(n−3)/2⌋ = ⌊(n−1)/2⌋（n 奇：1 + (n−3)/2 = (n−1)/2；n 偶：1 + (n−4)/2 = n/2 − 1 = ⌊(n−1)/2⌋）。基例：单圈图 c=1 ≤ ⌊(n−1)/2⌋（n≥3）。∎

**紧性（方法已到顶）.** friendship 图 F_k（k 个三角形共中心）每步恰 s=2, r=1：s+r=3 处处取等，c = k = (n−1)/2 精确——判据在极小反例族上**无任何余量**，不可能靠此货币单独证出比 HJ 更强的界，也不可能失败于 HJ 的真实例（方向一致）。

**诊断（定理失效面）.** 对 K_{2m+1}、八面体图、K_{2m}−M 等 2-连通 δ≥4 核：任何圈 C 均有 s=0（无 2 度点）且 r=1（去 ≤ n 条边后最小度 ≥ n−4 > 0，连通），s+r=1 < 3 **永久失效**。这就是 §4 的墙。

### 3.6 定理 6（稀疏完成带）

**陈述.** 任何 n 顶点欧拉图 H 满足 c(H) ≤ ⌊m/3⌋。特别地，若 m ≤ 3(n−1)/2（即 ā ≤ 3 − 3/n），则 c(H) ≤ ⌊(n−1)/2⌋。核版本：若核 M 满足 m(M) ≤ 3(n(M)+t(M)−1)/2，则 c(H) ≤ ⌊(n−1)/2⌋。

**证明.** 每圈 ≥ 3 边，c ≤ ⌊m/3⌋；与 ⌊(n−1)/2⌋ 比较即得；核版本由 3.3(c)。∎

### 3.7 定理 7（下界曲线；任何普适 C ≥ 1/2）

**(a)** c(K_{2m+1}) = m = (n−1)/2。下界：每圈 ≤ n = 2m+1 条边，|E| = m(2m+1)，故 c ≥ ⌈|E|/n⌉ = m。上界：Walecki 分解为 m 个 Hamilton 圈（脚本对 m ≤ 30 验证边不相交与覆盖；文献见 §2）。
**(b)** c(F_k) = k = (n−1)/2（friendship；每个圈必整含于一个叶片三角形——割点不能过两次——故分解恰为各三角形）。
**(c)** c(bouquet of k 个 K_5) = 2k = (n−1)/2，n = 4k+1（下界 ⌈|E|/n⌉ 不够——给 3——真下界由 3.3 核保持 + K_5 精确值或直接由块论证；上界由块分解拼接；脚本精确验证 k ≤ 4）。
**(d)** c(K_{2m} − M) = m − 1 = ⌊(n−1)/2⌋：下界 ⌈|E|/n⌉ = m−1 严格成立；上界 m≤4 由脚本精确给出；一般 m 的 Walecki 型构造存在（经典）但本 lane 手推两次失败，标 [UNVERIFIED-construction]，只承认 m ≤ 4 的计算验证。

**结论.** sup_{H 欧拉 n 顶点} c(H)/n ≥ (n−1)/2 · 1/n → 1/2，且四个族同时达到离散最优 ⌊(n−1)/2⌋。故 HJ 的常数不可再降；任何 c(H) ≤ Cn 的 C ≥ 1/2。

## 4. 障碍定位（哪个量在抵抗）

**归约链（全部已证）**：HJ(一般) ⟸ 块可加 ⟹ 只需 2-连通；抑制核 ⟹ 只需 δ≥4 核（带 t 校正）；于是战场 = **2-连通、δ≥4 的欧拉（多）图**。在此类中：

1. **孤立点货币死亡。** s(C) ≡ 0（无 2 度点），若图还高连通则 r(C) = 1，定理 5 的 s+r≥3 永不成立。所有已知名例（K_{2m+1}、八面体、K_{2m}−M）都在死区，但它们的 c 恰好 = ⌊(n−1)/2⌋——**判据失效不是因为界错，而是因为货币太粗，看不见"长圈"的价值。**
2. **量化恒等式（抵抗量的精确形状）.** 对分解记平均圈长 L̄ = m/c。逐步推导：c(H) ≤ (n−1)/2 ⟺ m/c ≥ 2m/((n−1)/2) ⟺ **L̄ ≥ ā·n/(n−1)**（ā = 平均度；末步用 m = ān/2）。即：猜想等价于存在平均圈长不小于平均度（差因子 n/(n−1)）的圈分解。对照紧例，全部取等、无一例外：
   - friendship F_k：ā·n/(n−1) = (6k/(2k+1))·((2k+1)/(2k)) = 3 = 每圈长（三角形）✓；
   - K_{2m+1}：ā·n/(n−1) = 2m·(2m+1)/(2m) = 2m+1 = n（Hamilton 圈）✓；
   - K_{2m}−M：所需 (2m−1)·(2m/(2m−1)) = 2m = n（Hamilton 圈）✓；
   - Petersen 4-正则分解：L̄ = 3 < 所需 4：**恰好差 4/3 因子——Petersen 路线的缺口被此恒等式精确刻画。**
3. **已知长圈工具的覆盖缺口.** Petersen 分解平均圈长恰 3（k 因子 × n/3 圈），对 4-正则需 ≥ 4·(1+o(1))：差 4/3 因子。Dirac（δ≥n/2 ⟹ Hamilton）只覆盖稠密端；GGKO/CFS 在稠密端给线性但常数 3/2（被迫匹配非欧拉下界构造，对欧拉类预计不是真常数）。**4 ≤ δ < εn 的中段没有任何工具保证"平均圈长 ≥ 平均度"的不相交分解**——这是墙的坐标。
4. **与 EG 的关系反向核对.** Erdős 1983 的 (3/2−o(1))n 下界构造 K_{2k+1,n−2k−1} 均非欧拉（B 侧每点度数 2k+1 为奇）；欧拉类的已知下界全部 = 1/2。这解释了为何 Hajós（n/2）与 EG（≥3/2 才被迫）可以共存：**Hajós ⟹ EG 恰好 3n/2 咬合下界**（BM line 1060），两问题的常数结构自洽。
5. **为什么 BM 的 log\* 不能直接线性化.** BM 的机器（鲁棒次线性扩张 + 吸收器）把图分成 O(n) 个圈 + 剩边，再迭代处理剩边；迭代次数 log\* 正是圈数超线的来源。欧拉版要求**第一遍就计数紧**，其框架不跟踪精确圈数（line 1057 只能把 log\* 原样传导到欧拉版）。缺口：在中密度核里构造"第一遍即 ⌊(n−1)/2⌋"的分解。

  (∀ F ∈ ℱ, ∃ C : SimpleGraph V, C.IsCycle ∧ ∀ v, Even (C.degree v) ∧ …) ∧

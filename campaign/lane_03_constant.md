## §0 记号

对有限简单图 G：记 m = |E(G)|，n = |V(G)|。一个**分解**（decomposition）是 E(G) 划分为若干部件，每个部件是一条单边或一个（简单）圈。ce(G) = 分解的最少部件数。f(n) = max{ce(G) : |V(G)| = n}。覆盖数 cov(G) = 覆盖 E(G) 的最少部件数（部件为圈或单边，**边可重复覆盖**）。显然 cov(G) ≤ ce(G)。

关键恒等式（定义改写，用于记账）：若分解为 c 条圈与 e 条单边，则

> ce(G) = c + e = m − Σ_{圈 C}(ℓ(C) − 1) = m − max_save(G)，

其中 max_save(G) 是 G 的边不相交圈族 D 上 Σ(ℓ−1) 的最大值（每条长 ℓ 的圈比 ℓ 条单边省 ℓ−1 个部件）。**注意**：连通欧拉图的圈分解条数**不固定**（例：K_{2,4} 可拆成 2 个 4-圈，也可作为圈的并更少），任何「分解条数 = 圈秩」式的推理都是错的——本 lane 的所有计数均绕开此陷阱。

## §3 定理 A：下界的精确定量化

**定理 A**。设 s ≥ 3 为奇数，m ≥ s，n = s + m。则

> ce(K_{s,m}) ≥ ⌈ m(3s−1)/(2s) ⌉ = ⌈ (3/2 − 1/(2s)) · m ⌉。

**证明**。K_{s,m} 是二部图（|小侧| = s，|大侧| = m）。任何简单圈在二部图中交替经过两侧，故圈长为偶数、至多 2s（小侧每点至多出现一次）。小侧每点度 = m 为奇数，大侧每点度 = s 为奇数。在分解中，一个点从它所在的每个圈获得度 2（偶），从单边获得度 1：故**每个大侧点关联的单边数为奇数，至少 1**。每条单边恰有一个大侧端点，故 e ≥ m。又 Σℓ_i = sm − e ≤ 2s·c，故

c + e ≥ (sm − e)/(2s) + e = m/2 + e(2s−1)/(2s) ≥ m/2 + m(2s−1)/(2s) = m(3s−1)/(2s)。

（函数 e ↦ e(1 − 1/(2s)) 递增，代入下界 e ≥ m。）取整即得。∎

**推论 A.1（下界精确形态与 O(√n) 空隙）**。f(n) ≥ (3/2)n − min_k [3k + 3/2 + (n−2k−1)/(4k+2)]，k 的可行域为 1 ≤ k ≤ (n−2)/4 的整数（需 m = n−2k−1 ≥ s = 2k+1）。被 min 化的函数 ≈ 3k + n/(4k)，极小点 k\* ≈ √(n/12)（解 3k = n/(4k)；审计修正记录：二稿曾写 k = ⌈√(n/24)⌉ 与约束 k ≤ (n−1)/4，均只影响常数因子，渐近结论不变），得

> f(n) ≥ (3/2)n − Θ(√n)。

即在一切已知构造中，距 3n/2 最近者只到 3n/2 − Θ(√n)。
脚本核对：ce(K_{3,t}) = ⌈4t/3⌉（定理 N，t = 2..9 全验证，t = 10..12 见 §9.3），ce(K_{5,5}) = 7 = ⌈5·14/10⌉。

## §4 引理 B：度 ≤ 2 顶点可剥离（主猜想归约到 min 度 ≥ 3）

**引理 B**。若每个最小度 ≥ 3 的图 H 满足 ce(H) ≤ (3/2)|V(H)|，则每个 n 点图满足 ce(G) ≤ 3n/2。

**证明**（对 n 归纳；各情形的「分解拼接」均不产生边冲突，因为被删/替换的边不与剩余图共享）。设 G 有 n 点。
1. **孤立点**：删点，+0 部件。3(n−1)/2 ≤ 3n/2 ✓。
2. **度 1 点 v（邻 u）**：先分解 G − v（n−1 点），补上单边 uv：ce(G) ≤ 3(n−1)/2 + 1 < 3n/2 ✓。
3. **度 2 点 v（邻 u, w），uw ∈ E**：三角形 T = {uv, vw, uw} 的三条边全部与 v 关联，故与 G − v 边不相交。先分解 G − v（归纳 P(n−1)：3(n−1)/2），加 T 一个圈：ce(G) ≤ 3(n−1)/2 + 1 = 3n/2 − 1/2 ✓。
   〔二稿审计修正存档：原稿此处写「分解 G − {u,v,w}」——u、w 可能还有指向 {u,v,w} 之外的边，被该论证丢弃。改为只删 v，正确且不损失界。〕
4. **度 2 点 v（邻 u, w），uw ∉ E**：令 G′ = (G − v) + uw（suppress v；uw ∉ E(G) 保证 G′ 简单）。|V(G′)| = n−1。给定 G′ 的最优分解：若 uw 是单边部件，换成两条单边 {uv, vw}（+1 部件）；若 uw 在某圈 C 上，把 C 中的 uw 替换为路径 u–v–w（v 在新圈上度恰 2，仍合法圈，部件数不变）。故 ce(G) ≤ ce(G′) + 1 ≤ 3(n−1)/2 + 1 = 3n/2 − 1/2 ✓。∎

**用途与组成校验（本次复核）**：对一般 G 剥离 r 个低度点得核 H（min 度 ≥ 3），每步至多 +1 部件，故 ce(G) ≤ ce(H) + r；若 ce(H) ≤ 3n_H/2 则 ce(G) ≤ 3n_H/2 + r ≤ 3n_H/2 + 3r/2 = 3n/2 ✓（r ≤ 3r/2 的松弛恰好吸收剥离代价）。任何反例必在 min 度 ≥ 3 的图中。低度顶点易处理是共识常识，此引理的价值是把攻击面严格圈定。

## §5 定理 I：覆盖到分解的转换代价 ≥ 2n/3（Pyber 路线的硬障碍）

**定理 I**。对 m ≥ 3，n = m + 3：

> ce(K_{3,m}) − cov(K_{3,m}) ≥ ⌈4m/3⌉ − 2⌈m/3⌉ ≥ 2m/3 − 2 = 2n/3 − 4。

**证明**。
(i) ce(K_{3,m}) ≥ ⌈4m/3⌉：定理 A 取 s = 3。
(ii) cov(K_{3,m}) ≤ 2⌈m/3⌉（m ≥ 3）：把大侧分成 ⌈m/3⌉ 组——m ≡ 0 (mod 3) 时全为 3 人组；m ≡ 2 时 3 人组 + 一个 2 人组；m ≡ 1（q ≥ 1）时 (q−1) 个 3 人组 + 一个 4 人组（m = 4 即只有 4 人组）。每组与大侧全部 3 点构成 K_{3,t′}（t′ ∈ {2,3,4}），各组边集两两不相交，故 cov ≤ 各组覆盖数之和。三张基础覆盖证书（边 xy = 小侧 x 与大侧 y 之间；覆盖允许边重用）：
  - **K_{3,3} 用 2 个圈**：C₁ = a–1–b–2–c–3–a（边 {a1,b1,b2,c2,c3,a3}）；C₂ = a–2–c–1–b–3–a（边 {a2,c2,c1,b1,b3,a3}）。并集 = 全部 9 条边（逐条核对：a1∈C₁, a2∈C₂, a3∈C₁∩C₂, b1∈C₁∩C₂, b2∈C₁, b3∈C₂, c1∈C₂, c2∈C₁∩C₂, c3∈C₁ ✓）。
  - **K_{3,2} 用 2 个圈**：a–1–b–2–a（{a1,b1,b2,a2}）与 a–1–c–2–a（{a1,c1,c2,a2}），并集 = 全部 6 条边 ✓。
  - **K_{3,4} 用 4 个部件**：C₁、C₂（盖住大侧 1,2,3 的 9 条边）+ 圈 a–4–b–1–a（新盖 a4、b4）+ 单边 c4。合计 12 条边全覆盖 ✓。
  组数计数：m = 3q ⟹ 2q = 2⌈m/3⌉；m = 3q+2 ⟹ 2q + 2 = 2⌈m/3⌉；m = 3q+1 (q ≥ 1) ⟹ 2(q−1) + 4 = 2q + 2 = 2⌈m/3⌉。∎（部件数逐图经脚本核验，见 §9。）
  〔二稿审计修正存档：原稿写「每组至多 3 点……t′ < 3 时取子图即可」——t′ = 1 时 K_{3,1} 无圈只能拆 3 单边（3 > 2 部件），且圈删边可能退化成路。3/2/4 分组绕开 1 人组，漏洞消除，定理陈述（m ≥ 3）不变。〕
(iii) 相减：⌈4m/3⌉ − 2⌈m/3⌉ ≥ (4m/3) − 2(m/3 + 1) = 2m/3 − 2。∎

**为什么这否定了任务书第 2 条的主攻路线**。设某人想：由覆盖版定理（简报：Pyber 覆盖版 cov ≤ n − 1 [UNVERIFIED，精确形式待查]）+「覆盖改分解至多损失 g(n) 个部件」得 ce(G) ≤ n − 1 + g(n)。要得到 3n/2 上界需要 g(n) ≤ n/2 + O(1)。但定理 I 表明**存在图族使 ce − cov ≈ 2n/3 对一切覆盖取到**，故普适的 g(n) 必须 ≥ 2n/3 − O(1)。因此：

- **推论 I.1**：「Pyber 覆盖 + 任意加性转换」至多证明 ce(G) ≤ 5n/3 + O(1)；该路线在原理上够不到 3n/2。转换损失的真身：覆盖允许边重用，从而**绕过**了大侧奇度点强制的单边代价（K_{3,m} 分解中每大侧点 ≥ 1 单边，而 2-圈覆盖让每点 2+2 度无单边）——这是度奇偶层面的本质差，非实现技巧问题。
- **猜想 H（本 lane 提出，新目标）**：ce(G) ≤ cov(G) + 2n/3 + O(1)。与定理 I 匹配（K_{3,m} 达到 2n/3 − 4）。若 H 真，则得 **ce(G) ≤ 5n/3 + O(1)**——第一个显式常数的 O(n) 上界（强于 O(n log\* n)）。后续性价比最高的方向：先攻 H，再图 3n/2。
- **结构障碍写透**：朴素「断裂-拼接」法失败于两处：(a) 配对需要端点相容的**空闲**连接边，K_{3,m} 型图中断裂路的端点集中在大侧，而大侧间无边（二部）；(b) 长 ≥ 2 的路既非圈也非单边，每次配对失败**全额**+1 部件，而断裂数在稠密覆盖中无界。定理 I 断言这在 K_{3,m} 上合计 ≥ 2m/3 − 2。

## §6 命题 K 与推论 L：min 度 ≥ 3 核心图的条件性 3n/2 结果

**命题 K**。若 G 有 2-因子 F（支撑 2-正则生成子图），F 由 f 个圈组成，则 ce(G) ≤ f + (m − n)。
**证明**：F 的 f 个圈两两边不相交；余弦边（E(G)∖E(F)，共 m − n 条）全取单边。∎

**推论 L**。设 G 含 2-因子且 m ≤ 13n/6。则 ce(G) ≤ 3n/2。
**证明**：2-因子每圈长 ≥ 3 ⟹ f ≤ n/3 ⟹ ce ≤ n/3 + m − n = m − 2n/3 ≤ 13n/6 − 4n/6 = 3n/2。∎
（与引理 B 组合使用时无需额外条件：核 H 满足 L 的假设即可，剥离代价已被 r ≤ 3r/2 吸收，见 §4。）

**重要注记（诚实边界）**：
- min 度 ≥ 3 **不蕴含** 2-因子存在；推论 L 是条件性结果。哪些 min 度 ≥ 3 图必有 2-因子（如桥less cubic：Petersen 定理的补）需按族逐一核实 [UNVERIFIED 项：Tutte r-因子定理 r=2 的精确陈述，待 Librarian]。
- **核心 GAP**：m ∈ (13n/6, ω(n)) 的中密度区没有任何常数预算工具；3n/2 的真正战场在此。低密度端 m ≤ 13n/6 已被推论 L + 引理 B 覆盖（条件于 2-因子）。
- m ≤ 3n/2 时 ce ≤ m ≤ 3n/2 平凡成立——难度随 surplus(m − 3n/2) 单调上升，给出「按 surplus 分层攻击」的路线图。

**动机**。f(7) 的全枚举 witness 0x7fff 恰为 G_5；n=9 join 族扫描发现的 witness 0x1fffff 恰为 G_7。二稿两次看到 witness 但未识别其同构——本次确认两图为同一家族，并得到该族的**完整精确公式**（定理 M2）。该族给出 f(n) ≥ n − 3 + ⌈n/3⌉（一切 n ≥ 5），是本 lane 除完全二部族外第一个带精确公式的无穷图族，且为**非二部**。

### 8.2 命题 M（G_c 的结构记账引理）

**命题 M**。设 c ≥ 3，D 为 G_c 的任一边不相交圈族，κ = |D|，L = D 覆盖的叶数，CC = D 中核-核边数。则：
(i) 每圈长 ≤ 6；每圈至多含 3 叶、至多 3 个核点；每叶至多属一个圈；
(ii) save(D) = 2L + CC − κ；
(iii) 可行约束：L ≤ c − 1，CC ≤ 3，κ ≥ ⌈(L + CC)/3⌉。

**证明**。
M.0：叶-叶边不存在；核-核边全局恰 3 条。
M.1（圈结构）：设 C 为圈，K_C = V(C) ∩ K₀，L_C = V(C) ∩ 叶集，e_KK = C 上核-核边数。先证 |K_C| ≥ 2：|K_C| = 0 不可能（无叶-叶边，圈无法全由叶组成）；|K_C| = 1（设 = {v}）不可能——v 在 C 上度 2、两邻居须为叶 u₁, u₂（若邻核点则 |K_C| ≥ 2），u₁ 的另一 C-邻居须在 K₀ = {v} 中，与 v 的圈度已满矛盾。圈上每点度恰 2 ⟹ 核-叶边恰 2|L_C| 条、且 2|L_C| + 2·e_KK = 2|K_C|，故

> |L_C| = |K_C| − e_KK ≤ |K_C| ≤ 3，  ℓ_C = |K_C| + |L_C| ≤ 6。

M.2：叶 deg_G = 3，其所在圈用去 2 条；两个圈需 4 > 3，故每叶至多属一圈。
M.3：由 |K_C| = |L_C| + e_KK 两边求和：Σ_C |K_C| = L + CC；又 save = Σ_C ℓ_C − κ = Σ_C (|K_C| + |L_C|) − κ = **2L + CC − κ**。约束：L ≤ c − 1（M.2）；CC ≤ 3（M.0）；L + CC = Σ|K_C| ≤ 3κ（M.1）。∎

### 8.3 定理 M2：ce(G_c) 的精确公式

**定理 M2**。对一切 c ≥ 3：

> ce(G_c) = c − 1 + ⌈(c+2)/3⌉（即 ce = n − 3 + ⌈n/3⌉，n = c + 2）。

又 ce(G_2) = 3（G_2 = K_4）。

**证明**。
(α) **下界（save 的上界）**。由命题 M，任何圈族满足

> save(D) = 2L + CC − κ ≤ 2L + CC − ⌈(L+CC)/3⌉ =: g(L, CC)。

g 对 L 严格递增（L → L+1 时 Δg ≥ 2 − 1 = 1）、对 CC 单调不减（Δ ≥ 1 − 1 = 0），故在可行域 L ≤ c − 1、CC ≤ 3 上

> save(D) ≤ g(c−1, 3) = 2(c−1) + 3 − ⌈(c+2)/3⌉ = 2c + 1 − ⌈(c+2)/3⌉，

于是 ce(G_c) = 3c − max_save ≥ 3c − (2c + 1 − ⌈(c+2)/3⌉) = c − 1 + ⌈(c+2)/3⌉。

(β) **上界（显式构造）**。四种合法圈型（i, j, k 互异叶；SX/SY/XY 记该叶在圈上用的一对边）：
- **E** = x–y–w_1–x：三角形；|K|=3，|L|=0，核-核边 3；
- **C1** = y–w_i–w_1–w_j–y：4-圈；|K|=2，|L|=2（SY, SY），核-核边 0；
- **D** = x–w_i–w_1–w_j–y–w_k–x：6-圈；|K|=3，|L|=3（SX, SY, XY），核-核边 0。
（亦存在型 B、C2、A 及变体，本构造不用。）

令 κ = ⌈(c+2)/3⌉，**d = 3κ − c − 2 ∈ {0, 1, 2}**（= (−(c+2)) mod 3），**e = c + 1 − 2κ**。取族 {E} ∪ {C1 × d} ∪ {D × e}。可行性逐项核对：
- **叶数** 2d + 3e = 2(3κ − c − 2) + 3(c + 1 − 2κ) = c − 1 ✓（恒等式；每叶恰用一次，叶对类型分配：SX 需 e 个、SY 需 2d + e 个、XY 需 e 个，合计 2d + 3e ✓，与 c − 1 个叶作双射即可——每叶三边俱全，无冲突）；
- **e, d ≥ 0**：d 由定义 ∈ {0,1,2}；e = c + 1 − 2κ ≥ (c+1) − 2(c+4)/3 = (c−5)/3，c = 3, 4 直接验证 e = 0, 1，c ≥ 5 时非负 ✓；且 3e ≤ c − 1 ⟺ κ ≥ (c+2)/3 ✓、2d ≤ c − 1 ⟺ κ ≤ (c+1)/2 ✓ 均自动满足；
- **边不重复**：E 独占全部 3 条核-核边；C1/D 只用叶边；各圈叶集两两不交 ⟹ X/Y/S 边两两不同 ✓；
- **容量**：Y 边用量 = 2d + 2e + 1 ≤ c（yw_1 计 1）⟺ 2κ − 1 ≤ c ✓；X 用量 = 2e + 1 ≤ c ✓；w_1 的度用量 = S(2d + 2e) + KK(2) = 2κ ≤ c + 1 ✓。

故这是合法边不相交圈族：L = c − 1、CC = 3、圈数 κ，save = 2(c−1) + 3 − κ，分解部件数

> ce(G_c) ≤ κ + (3c − (2(c−1) + 3)) = c − 1 + κ = c − 1 + ⌈(c+2)/3⌉。∎

(α)(β) 相等，公式成立。数值对照：c = 2..8 的全部精算值 3, 4, 5, 7, 8, 9, 11 与公式逐项相等（§8.5）；c = 9 公式预测 12（运行中精算的独立检验点）。

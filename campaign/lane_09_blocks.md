## 0. 约定与定义

图 G 有限、简单（无重边/自环），n = |V(G)|，c(G) = 连通分量数。ce(G) := 把 E(G) 划分为最少个数的 parts 之数，每个 part 要么是单条边，要么是某个简单圈（长 ≥3）的边集；E(G)=∅ 时 ce(G)=0。

块（block）：极大（按边包含）的、自身无割点的连通子图。由下节引理 1.1，块要么是桥（K₂），要么 2-连通；**块划分边集**：每条边恰属一个块。t(G) = 块数，q = 割点数，b(v) = 含 v 的块数。记号约定：[UNVERIFIED] 标记需 Librarian 核查的文献定位；本文件所有自证引理不依赖外部编号。

## 1. 块工具箱（全部自证，无循环）

**引理 1.1（并集引理）** 若 H₁, H₂ 连通、各自无自身割点、|V(H₁)∩V(H₂)| ≥ 2，则 H₁∪H₂ 无割点。
证：H₁∪H₂ 连通（交非空）。任取 w。因交 ≥2 点，|V(Hᵢ)| ≥ 2，故 Hᵢ−w 非空；由无割点性 Hᵢ−w 连通。若 w 属于两者，H₁−w 与 H₂−w 交 ≥ 2−1 = 1 点，并连通。若 w 只属 H₁，则 H₁−w 与 H₂−w 仍共享 V(H₁)∩V(H₂)（≥2 点，w 不在内）⟹ 并连通。∎

**引理 1.2** 两个不同块至多共享一个顶点。
证：若共享 ≥2 点，并集引理给出一个更大的无割点连通子图，与两块的极大性矛盾（并集严格包含每一块：另一块有本块没有的边）。∎

**引理 1.3（每条边恰在一个块）**
(a) 存在块含 e：若 e 是桥，则 {e} 自身无割点；任何真包含 e 的连通子图 H 中，e 仍是 H 的桥（H−e ⊆ G−e 仍分离两侧端点），而含桥的连通图 H ≠ K₂ 有割点（见 (c) 的引理），故 {e} 极大。若 e 在圈 C 上：C 连通且无割点（删任一点得路），在"含 C 的无割点连通子图"中取边极大者 B；任何真包含 B 的无割点连通子图必含 B ⊇ C，故 B 是全局极大，即块。
(b) 唯一性：若块 B, B′ 都含边 e = uv，则 |V(B)∩V(B′)| ≥ 2，由引理 1.2/1.1 知 B = B′。
(c) 附带引理：含桥 e=uv 的连通图 H ≠ K₂ 有割点。证：H−e 分成两个连通分支 H_u ∋ u, H_v ∋ v；|V(H)| ≥ 3 ⟹ 某侧 ≥2 点，设 |H_u| ≥ 2，则 u 是 H 的割点（H−u = (H_u−u) ⊔ H_v 不连通）。∎

**引理 1.4（v 在 ≥2 块 ⟺ v 是 G 的割点）**（G 连通）
(⟸) G−v 有分支 K₁, K₂；取最短 K₁→v 路的末边 u₁v、最短 K₂→v 路的末边 u₂v。若两条边同属块 B，则 B 内有 u₁–u₂ 路，它必过 v（不同 G−v 分支）⟹ v ∈ B 且 B−v 含分属不同 G−v 分支的 u₁,u₂ ⟹ B−v 不连通 ⟹ v 是 B 的割点，矛盾。故两条边属不同块，v 属 ≥2 块。
(⟹) 设块 B₁ ≠ B₂ 均含 v，由 1.2 交恰为 {v}；取 x ∈ B₁−v, y ∈ B₂−v（每块含边、连通、含 v ⟹ ≥2 点，x,y 存在）。反设 G−v 有 x–y 路 P。断言 H′ := B₁∪P∪B₂ 是无割点连通子图：连通（B₁∩P∋x, P∩B₂∋y, B₁∩B₂∋v）；对任意 w，B₁−w、B₂−w 连通非空，P−w 至多 2 个分支且每支含 x 或 y（w=x 时 P−x 单支含 y；w=y 对称；w=v 时 P−v 两支分含 x,y；其余情形两支分含 x,y），每支与 B₁−w 或 B₂−w 相交，而 B₁−w∩B₂−w ∋ v（w≠v）或经 P−v 桥接（w=v 时 P−v 仍含 x,y 连接两侧）⟹ (H′)−w 连通。但 H′ 严格包含 B₁（y ∉ B₁，P 的末边 ∉ B₁），与 B₁ 极大性矛盾。∎

**引理 1.5（块割树）** 定义关联结构 T：节点 = 块 ∪ {属 ≥2 块的顶点}（由 1.4 即割点），边 = 关联。对连通 G，T 是树。
连通：G 连通 ⟹ 任意两块经"共享割点"链相连（路上相邻边同块或邻块共享中间点）。
无环：反设简单圈 B₁, v₁, B₂, v₂, …, B_k, v_k, B₁（v_i ∈ B_i∩B_{i+1}，下标 mod k；k=2 会给两块两个公共点，与 1.2 矛盾，故 k≥3；节点两两不同）。令 H = ∪B_i。诸 B_i−v₁ 连通非空（B₁−v₁∋v_k；B_i−v₁∋v_i, i≥2），且 B₁−v₁∩B_k−v₁∋v_k、B_i−v₁∩B_{i+1}−v₁∋v_i ⟹ H−v₁ 连通。另一方面 v₁ 属两块 ⟹（1.4 ⟹ 方向对 (B₁,B₂) 的证明）x ∈ B₁−v₁ 与 y ∈ B₂−v₁ 属 G−v₁ 的**不同**分支；而 H−v₁ 是 G−v₁ 中同时含 x,y 的连通子图，矛盾。∎

**引理 1.6（计数恒等式）** 连通 G（无孤立点时取 n_+；含孤立点的分量单独 0 = n_j−1）：T 是树、有 t+q 节点 ⟹ t+q−1 条边 = Σ_{割点 v} b(v)。于是 Σ_B |V(B)| = (n−q) + Σ_v b(v) = n+t−1，即
**Σ_B (|V(B)| − 1) = n − 1（连通）；一般图 Σ_B (|V(B)| − 1) = n − c(G)**（孤立点分量贡献 0 = 1−1 自动吻合）。
**[脚本修正记录]** 初稿写成 n − c − iso，被随机 G(n,p) 检查（V2）否证后修正为 n − c；这正是"数值证据纠正纸面推导"的实例，最终公式已对所有 300 张随机图成立。∎

## 2. Theorem A（块可加性：精确等式）

**定理 A** 对任何图 G：**ce(G) = Σ_{B 块} ce(B)**。

证：
[≤] 每块取最优分解；块边不相交且并成 E(G)（1.3），parts 拼合即 G 的分解。
[≥] 任取 G 的分解 D。每个单边 part 所在边唯一属一块（1.3）；每个圈 part 是无割点连通子图（删点得路），由 1.3(a) 含于某块，且若含于两块则两块共享 ≥3 点与 1.2 矛盾，故属**唯一**块。于是 D 的 parts 按块分组，组内构成该块的分解 ⟹ 组内数 ≥ ce(B)，求和即 k+s ≥ Σ ce(B)。∎

**推论 A′**：任务 (a) 的 ce(G) ≤ Σ ce(Bᵢ) 不仅平凡成立，而且是最优的——**等号永远成立**。块分解把问题无损归约到 2-连通块 + 桥。

## 3. Corollary B/C（转移原理与超额记账；任务 (c) 的精确刻画）

**推论 B（无损转移）** 对 α ≥ 1：
**[每个 2-连通 H 有 ce(H) ≤ α(|V(H)|−1)] ⟺ [每个图 G 有 ce(G) ≤ α(n − c(G))]**。连通图即 ce(G) ≤ α(n−1)。
证：(⟸) 平凡。(⟹) 桥块 ce=1=|V|−1，2-连通块用假设：ce(G) = Σ ce(B) ≤ α·Σ_B(|V(B)|−1) = α(n−c)（引理 1.6）。∎
即：**任何按 (n−1) 计量的界在块归约下零损耗、零折扣**。按简报诚实备注：α=1 的命题对一般图为假（K_{3,n−3} 需 (4/3)(n−3)，n ≥ 10 时 > n−1；该图 2-连通）——本推论不是 n−1 的证明，而是把 n−1 版问题**精确等价**地压到 2-连通情形，并指明超额量全部住在块内。

**推论 C（超额可加性）** ce(G) − (n − c(G)) = Σ_B [ce(B) − (|V(B)|−1)]（由 A + 1.6 逐项相减）。
- n−c 的任何反例 ⟹ 至少一个 2-连通块 ce > |V|−1，且总超额 = 各块超额之和（无抵消、无放大）。
- 若每个非桥块满足 ce(B) ≤ |V(B)|−2，则 ce(G) ≤ n − c(G) − t′（t′ = 非桥块数）：桥贡献 1，2-连通块贡献 ≤ |V|−2，合计 = (n−c−s) + s − t′。
- **松弛量是逐块的**：slack(B) := |V(B)|−1−ce(B) ≥ 0？——不，可为 0（K₂、K₄、K₆，见 Thm G），也可 >0（三角形 slack=1、K₅ slack=2）。**不存在一致正折扣**，见 Thm G。

## 4. Theorem D（合并的充要条件；任务 (b)：割点折扣 = 0）

**定理 D**
(i) **分解中任意两个不同 parts 永不可合并为一个 part。**
证：合并后的 part 的边集必须是 P₁∪P₂ 且为某简单圈的边集（2-正则连通）。两圈情形：共享顶点处并集度 ≥4，不共享则不连通 ⟹ 非圈。圈+单边：单边端点在并集中度 ≥3 ⟹ 非 2-正则。两单边：2 条边非圈。∎
(ii) k ≥ 2 个 parts 可合并为一个 part ⟺ 它们的边集之并是某个简单圈的边集（按定义平凡；非平凡内容在 (i)：配对合并**从不**可行，省 part 只能发生在 ≥3 个 parts 的整体重组，例如 4 条单边重组为 C₄）。
(iii) **割点折扣恰为 0，无条件**：由 Thm A 下界方向，跨块重组不可能（每个 part 整在唯一块内，块间至多共享割点，并集含 cut 点度 ≥4 情形已由 (i) 覆盖）；块内重组已计入 ce(B)。最小见证 bowtie（两个三角形只共享割点 v，两块的圈都过 v）：ce = 2 = 1+1，两圈只在 v 相交（v 处并集度 4），不可合并；脚本已验证 ce = 2。∎

（一句话回答简报 (b)：**可合并的充要条件是并集为单圈；对跨割点的两个圈-parts 永不成立；故"合并省一条"在任何位置都不可能，割点处尤其如此。**）

## 5. Lemma F（奇度下界）

**引理 F** 任何分解中单边数 s 满足 2s ≥ odd(G)（奇度点数），故 ce(G) ≥ odd(G)/2。
证：圈在每个顶点用 0 或 2 条邻边（偶数），故 v 处单边 part 数 ≡ deg_G(v) (mod 2)；奇度点处 ≥1。计关联：2s = Σ_v (v 处单边数) ≥ odd(G)。∎
**推论 F′** 三次图 ce ≥ n/2（全顶点奇度）。Petersen 图：ce ≥ 5 且构造（外 5-圈 + 内五角星 5-圈 + 5 条辐条）给 ce ≤ 7，DP 精确值 **ce(Petersen) = 7**。
**引理 F″（块版奇度下界，略强）** ce(G) ≥ Σ_B odd(B)/2，其中 odd(B) 按 B 内度数计。
证：D 的 parts 整在块内（Thm A 之证），s = Σ s_B；对块 B 用引理 F。注意 Σ_B odd(B) ≥ odd(G)（每点在诸块中的度奇性个数 ≡ deg_G(v) mod 2，G-奇点被计奇数次 ≥1 次），故 F″ 不弱于 F，且可严格更强（两个 K₄ 共享一点：F 给 3，F″ 给 4）。∎

## 6. Theorem E（仙人掌精确公式；任务 3 的对照检查）

**定理 E** 连通 G 的每块是桥或圈（仙人掌）⟹ ce(G) = t(G) = (n−1) − Σ_{圈块 C} (|C|−2)。
证：两类块 ce 均 =1，Thm A ⟹ ce = t。又 n−1 = Σ_B(|V(B)|−1) = #桥 + Σ_C(|C|−1) = t + Σ_C(|C|−2)。∎
检查：树（无圈块）ce = n−1 ✓ 恰等于块贡献和、紧；单圈 C_n：1 = (n−1)−(n−2) ✓（即比 n−1 低 n−2）。**注意对照结论**：仙人掌里"2-连通 ⟹ 有松弛"成立，但对一般块失效——K₄、K₆ 是零松弛 2-连通块（见 Thm G），故简报设想的"块数折扣"在存在稠密块时无法兑现。

## 7. Theorem G（完备图的精确 ce；均匀折扣不存在的一般反例）

**定理 G** **ce(K_n) = n−1（n 偶）；ce(K_n) = (n−1)/2（n 奇，n ≥ 3）。**
证：
上界（Walecki 型分解，经典构造；出处标注 [UNVERIFIED：Walecki 1892 的原始文献定位，构造本身为标准教科书内容，可查 Bondy–Murty *Graph Theory* 2008 的 Hamilton 分解章节——请 Librarian 核实]）：K_{2k+1} 可分解为 k 个 Hamilton 圈（标准旋转构造：固定 ∞，其余 2k 点排正多边形，每步旋转取"之字形"完美匹配对）；K_{2k} 可分解为 k−1 个 Hamilton 圈 + 1 个完美匹配（同构造去 ∞）。故 ce(K_{2k+1}) ≤ k，ce(K_{2k}) ≤ (k−1)+k = 2k−1。
下界（自证）：
- n = 2k+1 奇：每个 part 至多 n 条边（圈 ≤ n，单边 1 ≤ n），m = n(n−1)/2 ⟹ ce ≥ ⌈m/n⌉ = (n−1)/2。
- n = 2k 偶：K_{2k} 全部 2k 个点奇度 ⟹（引理 F）s ≥ k。设 k′ 个圈，则 k′ ≥ (m−s)/(2k)，故
  ce = s + k′ ≥ s + (k(2k−1)−s)/(2k) = (2k−1)/2 + s·(2k−1)/(2k) ≥ (2k−1)/2 + (2k−1)/2 = 2k−1 = n−1（关于 s 递增，s ≥ k）。∎
脚本核验：ce(K₄)=3=n−1、ce(K₅)=2、ce(K₆)=5=n−1，与公式一致。
**战略推论**：每个偶数规模都存在零松弛 2-连通块 ⟹ 简报任务 (c) 设想的"ce ≤ n−1 −（一致块数折扣）"型刻画**不可能成立**；正确的精确刻画是推论 B/C 的逐块记账：折扣 = Σ_B slack(B)，可整体为 0（一个 K_{2k} 即封死）。同时提示：n−1 紧的来源有两种极端——树（全桥）与偶阶完全图（奇度强迫单边）。

## 9. 障碍分析：ear decomposition 攻击为何卡住（诚实记录，非证明）

- 经典事实（自证）：2-连通 ⟹ 无桥 ⟹ 每边在圈上（引理 1.3(c) 的逆否 + 1.3(a)）。Whitney 耳分解：2-连通图 = 圈 + 逐次加耳 [出处：Whitney 1932；教科书定位如 Diestel *Graph Theory* 5th ed. §3.3，编号 [UNVERIFIED] 待核]。耳数 k = m − n（每耳 ℓ 条边、ℓ−1 个新点，两式相减）。
- **攻击尝试**：沿耳归纳证 ce(G_{i+1}) ≤ ce(G_i) + 1。**卡点（定位到不等式）**：新耳 ℓ ≥ 2 条边要用**一个** part 支付，唯一途径是过耳的圈，但它必须经 G_i 中一条已提交给旧 parts 的 u–v 路；旧 parts 不可退款（Thm D(i)：parts 两两不可合并，重组无免费午餐）。反例：K_{2,3} = C₄ + 一条 2-耳，ce = 3 > 1 + ce(C₄) = 2。
- 逐耳上界 ce ≤ 1 + Σℓ_i = 1 + m − n_0 ≤ m − 2：不弱于平凡贪心（取一圈后其余单边），无增量。
- **结构诊断**：本 lane 的 Thm A 把全题精确压到 2-连通块内部，于是剩余困难恰是"覆盖 vs 分解"裂缝：Pyber 覆盖版 n−1 已知（简报），而分解版在块内无任何跨块回旋余地。**"每条边恰分配到一个圈" ⟺ 图 Euler**（Euler 1736，划分边集成圈 ⟺ 全偶度）；结合引理 F，非 Euler 块必须付出 ≥ odd(B)/2 条单边。细注：G Euler **不**蕴含诸块 Euler（两个在某割点处奇度的块拼出偶度割点），故简报所引"欧拉图圈分解 ⟺ 全题"（BM line 180）与块记账的交互需按块逐个处理。

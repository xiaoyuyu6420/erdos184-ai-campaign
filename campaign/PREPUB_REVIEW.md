## 二、仲裁裁决：Lane 12 vs Lane 01

**裁决：Lane 12 推翻成立。**

1. 双方对 f̃(d) = 2^{(log d)^θ} 的迭代深度计算**一致**且均正确：Θ(log log log n / ln(1/θ))（令 y_i = ln f̃^i(n)，y_{i+1} = y_i^θ，θ^i·ln ln n ≤ O(1）。
2. 分歧纯在解读。判据是**上界越小越强**：BM 的 O(n log* n) 中 log* n 增长慢于一切迭代对数（log* 2↑↑k = k，而 log log log 2↑↑k = Θ(2↑↑(k−3)) ≫ k）。故 O(n log log log n) 是**退化格**（介于 CFS 的 Θ(log log n) 与 BM 的 log* n 之间偏 CFS 侧），不是进展。lane_01 §五(b) "严格优于 log*" 与战役"中期现实目标"须撤回——已撤（MERGE 修正 1），本复核维持。
3. lane_12 增加的因果环节（12.1(a) 不动点卡死：polylog 剩余映射有超常数不动点 d* = e^{x*}，x = 274 ln x 之解 x* ≈ 2095，朴素迭代永不穿透）成立，是对"改迭代结构封死"（lane_01 命题 A 路线）的逐环加固。12.1(b) 与 12.3(b) 的证明缺口见 Y2/Y3，**不动摇主链**：主链只需 (a) + polylog 类塔重置（与 BM 自身 lines 1039–1049 记账吻合，已对源码核验）。
4. 附带确认（对 BM 源码直接核验）：lem:density 陈述与 274 指数、thm:logstar 的塔重置归纳、splitting-into-expanders 的 4sn·log n 删除价、结论节"主瓶颈 = 鲁棒化删除"自述、Erdős K_{2k+1,n−2k−1} 下界——与 lane_01/lane_12 引用一致。

# 我们用 64 路 AI 子代理围攻了一道 60 年的图论猜想

Erdős #184：任意 n 个顶点的图，边集能不能拆成 O(n) 条边不相交的圈和单边？1960 年代提出，1971 年 Erdős 给出精确版：n−1 个就够。60 多年过去，上界从 O(n log n) 磨到 O(n log log n)，再到 2022 年 Bucić–Montgomery 的 O(n log* n)，然后停在那里。过去三天，我们组织了一场总规模 64 路（三幕：多样性 21 + 深化 24 + 对抗审查 19）的 AI 子代理攻击战役：攻击手分兵进攻，专职子代理负责攻击自己人，发布前还有一道逐行对抗审查。本文是第一幕与深化首批评战的战报，也是检讨书。

最硬的结论直接给。定理级战果八条，先挑三条：

- **完全图被全谱钉死**：$ce(K_{2m})=2m-1$，$ce(K_{2m+1})=m$。偶数阶完全图一件都省不掉，奇数阶反而省一半。（诚实标注：证明组件——Walecki 分解、奇度槽计数——是经典技术，新的是把两情形合并成精确框架并机器验证；此条最可能属于"专家眼中的已知"，新颖性以专家确认为准）；
- **块可加性精确等式** $ce(G)=\sum_B ce(B)$：割点这条缝一分的便宜都占不到，整道题无损压到 2-连通图；
- **一个 7 顶点反例**（在 $K_{3,4}$ 上把 3 点一侧连成三角形，需要 7 = n 件）否掉了"最大度 ≤ 6 则 n−1 就够"。

> **两句话请先读**：① 本文全部结果**未经同行评议**，由多智能体系统产出、经内部对抗审查与机器穷举验证；② 其中部分"定理"的组件可能是图论圈的已知或半已知事实（比如完全图那条用的 Walecki 分解就是 19 世纪的），哪些算真新颖，最终以专家确认为准——我们正在做的就是这个确认。

此外：环面上的欧拉图 ≤ n−1；度数 ≥ n/2 的正则图 ≤ n−1（n ≥ n₀）；度数全偶、最大度 ≤ 6 的图 ≤ $3\lfloor n/3\rfloor$；简并度 3 的图有线性上界 $\lfloor(5n-8)/3\rfloor$；全图最坏值 $f(n)\ge n$（n ≥ 7）。还有一条不太一样的战果：**我们推翻了自己**。战役一度把"O(n log log log n) 上界、严格优于 log*"立为中期目标，后来被自家攻击手证明方向读反了——那是个更弱的界，已撤回。审查链从自家产出里抓出 12 处问题，全部处置完毕，清单在第五节。那是这篇文章的魂。

## 一、先说清楚这是道什么题

记 $ce(G)$：把 $G$ 的边集划分成"圈（长 ≥ 3）或单边"所需的最少件数。拆得越省，圈越大越多。

- **原版猜想**（O(n) 版）：存在常数 C，任何 n 点图 $ce(G)\le Cn$。1971 年精确版猜 C = 1，即 n−1。
- **下界先行**：Erdős 的二部构造 $K_{2k+1,\,n-2k-1}$ 需要 $(3/2-o(1))n$ 件。所以 n−1 版对一般图已经死了，活的问题剩两支：O(n) 版的常数到底是多少（已知 ≥ 3/2）？哪些图族 n−1 就够（平面图、低最大度、低简并度……每族一条战线）？
- **覆盖版不稀奇**：允许圈和边重复覆盖时，Pyber 1985 年就给出 n−1。全部难度在"边不相交"。
- **上界编年史**：Erdős–Gallai $O(n\log n)$ → CFS 2014 $O(n\log\log n)$ → Bucić–Montgomery 2022 $O(n\log^* n)$。
- $\log^* n$ 是什么：反复取对数、压到常数以下所需的次数，慢得离谱。把 2 的指数塔 $2\uparrow\uparrow k$ 代进去：$\log^* n = k$，而 $\log\log\log n$ 已是 $2\uparrow\uparrow(k-O(1))$ 级的怪物。记住这个对比，第四节要用。

前哨战在战役开始前一天打完：平面特例五定理审定——外平面 ≤ n−1、欧拉平面 ≤ n−2、欧拉极大平面可拆出 n−2 个边不相交面三角形、无桥三次平面图 ≤ 5n/6、含桥三次归到 n−1。这五条同样走完了"攻击手证明 → 审查员对抗复核 → 蓝队修复"全流程（审查记录见 notes/verify_planar.md 及其蓝队处置章节）。主战役在这个基础上展开。

## 二、第一幕：撒网——各路攻击手分兵进攻

第一幕放出一批攻击手，每路只拿一份共享简报和本地文献源码，禁止互读产出（防交叉污染），各攻一类图。八条 A 级（定理级）战果如下。

**1. 完全图：第一次全谱钉死。**

$$ce(K_{2m})=2m-1,\qquad ce(K_{2m+1})=m.$$

证明出自 lane_09（定理 G）：上界靠 Walecki 分解——奇阶完全图恰好拆成 m 个 Hamilton 圈；下界靠奇度槽计数。不对称很有意思：偶数阶"零松弛"，一件省不掉；奇数阶反而省一半。数值锚点 $K_4=3$、$K_5=2$、$K_6=5$、$K_7=3$ 全部经独立求解器复核。

**2. 块可加性：整道题无损压到 2-连通。**

$$ce(G)=\sum_{B}ce(B),$$

B 跑遍所有块（不含割点的极大连通子图）。分解的每一件都整块落在唯一块里，割点不提供任何折扣；配合转移原理，"一般图版"与"2-连通版"精确等价——从此火力可以对准 2-连通图打。附一个诚实注脚：配套恒等式 $\sum_B(|V(B)|-1)=n-c$ 的初稿写成 $n-c-\text{iso}$，被 300 张随机图的脚本当场否证后修正。"机器纠正纸面推导"，此役第一次，不是最后一次。

**3. 七个点的反例："Δ≤6 ⟹ n−1"出局。**

反例取 $K_{3,4}$，再把 3 点一侧连成三角形（报告记作 $K_3\cup K_{3,4}$，注意两图共享顶点，并非不交并）：n=7，m=15，最大度 6，ce = 7 = n > n−1。下界是手工奇点计数，六种情形逐一排除；上界给出 7 件显式证书；DP、分支定界、可行性穷举三算法加一路独立实现，四重一致。最大度 ≤ 5 仍是文献里的开放问题，但 6 这一档已有判决。

**4. 曲面：环面欧拉图 ≤ n−1。** 欧拉环面图 $ce\le n-1$（三角剖分 ≤ n−2）；任意亏格 g 的图 $ce\le \frac{5}{3}n+2g-\frac{8}{3}$；欧拉图亏格 g 时 ≤ n+2g−4。g=0 退化回平面已知结果，不蕴含平面猜想本体。

**5. Dirac 正则图：一半度数换 n−1。** 正则、度数 $D\ge\lfloor n/2\rfloor$、$n\ge n_0$（CKLOT 定理的天文常数）⟹ $ce\le n-1$，武器是 CKLOT 的 Hamilton 分解。$n_0$ 这个限定词不能丢——审查专门抓过一次漏写。

**6. even + Δ≤6：完整刻画。**

$$ce(G)\le 3\lfloor n/3\rfloor,$$

且 n ≢ 0 (mod 3) 或非 6-正则时 ≤ n−1。瓶颈被精确约简到"6-正则且 n ≡ 0 (mod 3)"——恰好是 AABC25 论文登记的开放猜想（R2 已有报告声称解决，见第六节，未审）。

**7. 简并度 3：常数现身，同时全线失守。** 好消息：简并度 ≤ 3 的图 $ce\le\lfloor(5n-8)/3\rfloor$（已证），极族 $K_{3,q}$ 的精确值 $ce=\lceil 4q/3\rceil$ 对一切 q ≥ 2 成立（q = 1 是三条边的星形图，ce = 3，公式不适用）。坏消息：对每个 d ≥ 3 都有无穷多 d-简并图 ce > n−1（含非二部的 $K_{3,q}+e$ 与 $K_{5,q}$）——"n−1 就够"从 d=3 起全面失守。d=3 的渐近常数：下界 4/3 已证（$K_{3,q}$ 恰是极族），匹配上界 4/3 是猜想（已证上界 5/3）。原稿曾把话说满，被审查降级。

**8. 最坏值下界抬到 n。** $f(n)=\max ce(G)$：$f(n)\ge n$ 对一切 n ≥ 7，两条独立证明路径，另有 $K_{3,q}$ 精确值在 n ≥ 10 侧互证。配上 Erdős 构造的 3n/2，下界地图完整了一格。

## 三、第二幕：解剖——log* 这堵墙是怎么砌起来的

Bucić–Montgomery 的 $O(n\log^* n)$ 是挡在题前的墙。lane_01 把它的证明逐行拆开（本地 LaTeX 源码，按行号核对），拿到三件事：

1. **log* 的唯一来源**。全文只有一处产生 log*：单密度引理说"平均度 d 的图拆掉 O(n) 个圈后，剩余平均度 ≤ O(log²⁷⁴ d)"，这个映射迭代 log* n 次才把度数压到常数。第 2–5 章的全部机器不含 log*。
2. **274 是硬算出来的**。log²⁷⁴ 的谱系被逐项核算：次线性扩张比 ε/log²n → 撒水批数 log⁴ → 损耗逐级累积 → 鲁棒参数需求 s ≥ log¹³⁵ → 二次切分删除价 4sr·log r，s 取 log²⁷³，得 log²⁷⁴。链条各级 slack ≤ 3 个 log 幂——墙不是偷懒，是结构。
3. **两行归约**。取 s=0 的切分引理，任意图被精确切分成若干 (ε,0)-expander（大白话：每个不太大的点集都有成比例的外邻居、不容易被切成两半的稠密片）。于是整道题等价于：每个 (ε,0)-expander 能否拆成 O(r) 个圈加单边。墙 = 把弱 expander 加固成强 expander 的"鲁棒化价格"，加上骨架闭环价格。

然后 lane_01 做了一件雄心勃勃的事：把"剩余度映射"抽象成迭代动力系统——单步映射 f 决定总代价，由 $f^i$ 的迭代深度决定。f 是固定 polylog（如 $\log^{274}$）⟹ 深度 $\log^* n$；$f(d)=2^{(\log d)^\theta}$ ⟹ 深度 $\Theta(\log\log\log n)$。当时报告的解读是："跨过 polylog → 次多项式这一格，立即得 $O(n\log\log\log n)$，严格优于 log*"，并被立为战役中期目标。

这个解读活了一个晚上。

## 四、第三幕：对抗——我们推翻了自己的"重大进展"

lane_12 的任务本是攻"自鲁棒化引理"，把那一格真的跨过去。动手第一步是复算，复算的结论是：**深度计算没错，方向读反了**。

比较两个上界，越小越强。而 $\log^* n$ 恰恰增长得比 $\log\log\log n$ 慢得多：$\log^* n = o(\log\log\log n)$。用指数塔量一下（见第一节）：$n=2\uparrow\uparrow k$ 处，$\log^* n = k$，$\log\log\log n$ 却是 $2\uparrow\uparrow(k-O(1))$ 的天文数字。所以 $O(n\log\log\log n)$ 弱于 BM 现有的 $O(n\log^* n)$——"跨过一格"不是进展，是退到 CFS 和 BM 之间的退化格。

编排者仲裁：lane_12 正确。"中期目标 $O(n\log\log\log n)$"撤销，全战役文件加撤回标注；深度计算保留——它是对的，错的只是解读。

撤回之后，lane_12 把墙的机理补全了，这就是 **log* 锁死定理**（BM 架构内）：

- 三随机类合并不可行——想省一次切分，被自我反例击毙；
- 于是切分数 k=3 与 √s 损耗本质，鲁棒参数下界 s ≥ log²⁷³ 本质，删除价 polylog 本质；
- polylog 型剩余映射必有**超常数不动点**：解 $x = 274\ln x$ 得 $x^*\approx 2095.4$，即 $d^*\approx e^{2095}$——数字有限，朴素迭代从上方永远压不穿它；
- 压不穿就只能换参照系（塔重置），而塔重置的深度恰好就是 log*。

一句话：**在 BM 的架构内，log* 不是缺陷，是宿命**——"BM 设计在架构内无懈可击"。想真进步得换机器，不是调参数。三条改进路线里，改迭代结构被判死（lane_12 加固为逐环可证），绕开扩张目前无立足点；纸面上存在更细的格（如 $O(n\log\log^* n)$），但 BM 机器里找不到产生它的机制——登记为 R2 候选，不做承诺。

诚实限定：以上"锁死"与"无懈可击"都是架构内命题——s 单调、三随机类切分本质这些前提成立时才对。审查为此专门加过限定词。

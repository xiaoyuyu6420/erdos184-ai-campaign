## 1. 主定理 R1（奇偶台账定理）——完全证明

**定义 1.1**：对图 G，T = T(G) := {v : deg_G(v) 奇}。**奇偶子图** F ⊆ E(G)：每个 v 满足 deg_F(v) ≡ deg_G(v) (mod 2)。**τ(G)** := 最小奇偶子图的边数（= 最小 T-join 权，单位权；经典对象，见 Edmonds–Johnson 1973 的 T-join 理论；中国邮递员问题的标准归约：min T-join = T 上以最短路距离为权最小权完美匹配，故 τ 可多项式计算）。

**定理 1.2 (R1)**：对任意连通有限简单图 G（**不用 Δ 条件**）：
ce(G) ≤ τ(G) + ⌊(m − τ(G))/3⌋ ≤ ⌊(m + 2τ(G))/3⌋。
从而 **m + 2τ(G) ≤ 3n − 3 ⟹ ce(G) ≤ n − 1**。

*证明*。
(1) 取奇偶子图 F，|F| = τ。令 H := G − F。则每个 v：deg_H(v) = deg_G(v) − deg_F(v) 为偶，H 是偶图（允许 0 度）。
(2) **引理（标准，展开）**：偶图分解为边不相交简单圈。归纳 |E(H)|：H 有边时每个非孤立分量最小度 ≥ 2（偶度 ⟹ 无 1 度），含圈 C（任一非孤立分量取最长迹即得圈）；H − E(C) 各点度仍偶，归纳。
(3) 圈数下界约束：每圈 ≥ 3 边 ⟹ k ≤ ⌊(m − τ)/3⌋。
(4) D := {C_1,…,C_k} ∪ F 的每条边作单边件，是合法分解，件数 Π = k + τ ≤ ⌊(m−τ)/3⌋ + τ = ⌊(m + 2τ)/3⌋。
(5) 判据：⌊(m+2τ)/3⌋ ≤ n−1 ⟺ m + 2τ ≤ 3n − 3（整数运算）。∎

**对偶形式 1.3**：F 奇偶子图 ⟺ G − F 偶图，故 τ = m − maxeven(G)，maxeven := 最大偶子图边数 = 边不相交圈族可覆盖的最大边数（偶图可圈分解，引理）。代入 R1：

> **ce(G) ≤ n−1 ⟸ 存在边不相交圈族覆盖 ≥ (3/2)(m − n + 1) 条边**（即覆盖 ≥ (3/2)β）。

**精确式 1.3'**：对每个奇偶子图 F，分解的单边集恰是奇偶子图，而圈件是 G−F 的边不相交圈族；反之 F 的任一选择 + G−F 的任一圈分解都是分解。故
ce(G) = min_F (|F| + c*(G − F))，其中 F 遍历奇偶子图，c* = 最小圈分解件数。
R1 = 只取 |F| 最小的 F 且用 c* ≤ e/3。**改进 R1 的全部空间在 c* 的更好上界（即长圈/圈合并），见 §3.5。**

**推论 1.4（特例，均为新的一行证明）**：
- G 偶图 ⟹ τ = 0 ⟹ ce ≤ ⌊m/3⌋。Δ≤5 偶图 m ≤ 2n ⟹ ce ≤ ⌊2n/3⌋（重得 P2 的阶；P2 用 2-因子给精确 2⌊n/3⌋，更强）。
- 2-连通立方图：无桥，Petersen 定理（1891，桥立方图有完美匹配）⟹ τ ≤ n/2，且 m = 3n/2 ⟹ ce ≤ 5n/6 ≤ n−1 (n ≥ 6)。注意战役简报中「无桥 cubic 平面 ≤ 5n/6」的平面性在此**不需要**：R1 对一切 2-连通立方图给 5n/6。
- 树：T-join 唯一，τ ≤ n−1，判据 m + 2τ = (n−1) + 2τ ≤ 3n−3 ⟺ τ ≤ n−1 恒真 ⟹ R1 对每棵树判定 ce ≤ n−1，且对路径（τ = n−1）**恰好取等**——R1 在树类上是紧的，与「n−1 无 slack」的已知事实一致。

**定义 1.5（残差类）**：𝓡 := {G : m + 2τ(G) ≥ 3n − 2}。R1 恰对 𝓡 外的一切图判定 n−1。**Δ≤5 猜想被 R1 归约为：𝓡 ∩ {Δ≤5} 内 ce ≤ n−1。**

**命题 1.6（残差类的奇度刻画，新）**：Δ≤5 ⟹ m ≤ 5n/2；若 G ∈ 𝓡 则 3n−2 ≤ m + 2τ ≤ 5n/2 + 2τ ⟹ **τ(G) ≥ (n−2)/2**。又 τ ≥ |T|/2（奇度点都是 F-端点，每条边至多 2 端点）⟹ 残差类 = 「奇点多（|T| 接近 n）或奇点配对距离大（τ 严格大于 |T|/2）」的图。数值注记（§4）：全部已知紧实例恰分两型——**全奇型**（|T| = n：W_6、K6−C4、K6−K3、K6、G*、K_{3,5}）与**冗余型**（τ > |T|/2：K_{3,4}、K_{3,4}+e、K_{3,3}+弦、K_{3,3}+双弦，冗余 1–2）；无一台账平凡（非残差）的紧例。紧与「全奇或冗余 + 稠密」强相关，这是残差类的可操作画像。

## 3. 障碍定位与交换论证的最远推进

### 3.1 台账恒等式：为什么局部交换在储蓄族里天然弱

对分解的任何改动，**ΔΠ = (新失去圈覆盖的边数) − (新获得圈覆盖的边数)**（直接由 Π = m − savings）。吸收一条单边进圈 = −1 件；但从旧圈上拆下弧去补别处，弧的每条边 +1 件（悬径——路径不是合法件，必须碎成单边）。所以：
- **单边进圈是唯一「无悬径」的局部受益**；一切涉及拆圈的移动都要为悬径付费。
- G* 型 sweep 之所以赚（§2.1 的 12 件 → 8 件），是因为每个三角形被「穿越」（2 条边进新圈、1 条边留作单边），付费率 1/3；一般图上保证每个部件都被便宜地穿越是全局性质，不是局部性质。**这就是储蓄族局部交换论证的精确死因**：极小 Π 分解不存在小尺寸改善移动（见 3.2），而把 Π 压到 n−1 所需的重绕（如 G* 的）是 O(n) 尺寸的。

**收尾补充（谱系观察，解释为何没有单一「目标形态」）**：紧实例的最优分解谱系分裂为三类——(i) **无圈型**：W_6、树类，ce = τ + 0，单边集 = T-join 本身；(ii) **匹配+圈型**：G*、K6，F = 完美匹配 + 少量长圈；(iii) **混合型**：K_{3,4}+e = 6-圈 + 4-圈 + 4 单边。三类之间不存在共同的局部结构使得一个统一的交换方向能把任意极小 Π 分解变成 n−1 件。任何「先规范化再交换」的方案必须先在三类之间选择，而选择本身是全局优化——这是 3.2 局部禁形弱到只剩 S1 的结构性原因。

### 3.2 极小 Π 分解的局部禁形（Δ-自由，严格）

**命题 3.2 (S1)**：设 D 极小 Π。则对每条圈边 e = xy ∈ E(C)，单边件子图 M = (V, F) 中**不存在** x 到 y 的路。
*证明*：反设有路 P（|P| ≥ 2，取简单路，避开边 e）。W := (C − e) ∪ P 是闭迹。若 W 是圈：D' = D − C − {P 的件} + {W}：ΔΠ = 1 − |P| ≤ −1 ✗。若 W 非单圈：W 分解为 q ≥ 2 个圈（引理 1.2(2)），q ≤ (|C| − 1 + |P|)/3：ΔΠ ≤ q − 1 − |P| ≤ (|C| − 1 + |P|)/3 − 1 − |P| = (|C| − 4 − 2|P|)/3 ≤ (3 − 4 − 4)/3 < 0 ✗。均与极小性矛盾。∎

**命题 3.3 (未覆盖点的禁形)**：设 D 极小 Π，v 不在任何圈件上（deg(v) ≥ 2 条单边件挂于 v）。则 v 的任意两邻居 u, w 之间在 M 中无路。*证明*：u–v–w 并上该路是简单圈，吞掉 2 + |P| 个单边件：ΔΠ = 1 − (2 + |P|) < 0。∎
（注意：**没有**「u, w 不共圈」的禁形——共圈时拆弧移动 ΔΠ = |弧| − 1 > 0，反而变差（见 3.1 的悬径付费）；所以极小分解允许未覆盖点存在。）

**W=∅ 的收尾结论**：「极小 Π 分解可覆盖所有点」（存在性版本）在数值上无反例（§4：n ≤ 7 共约 907 图次检验——n=6 修正紧 258 全查 + n=6 旧残差集 393 + n=7 紧 140 + 非紧抽样 150，全部 OK），但交换论证给不出存在性证明——3.2/3.3 的禁形在「v 未覆盖且其邻居 M-两两不连且不同圈」时全部失效，且未覆盖点上的任何单步移动（含拆弧型）都被悬径付费挡住。**W=∅ 保持开放，作为条件引理使用时必须显式声明。**

### 3.3 C2（4-正则圈分解）：n ≤ 8 完全证明 + 长圈归约

**猜想 C2（原表述）**：每个 2-连通 4-正则偶阶 n ≥ 6 图 H 有圈分解至多 n/2 − 1 个。

**定理 3.4 (C2-red，长圈归约，完全证明)**：设 H 2-连通 4-正则，n 点，C 为任一圈，n_C = |C|。则 H − E(C) 的每点度 ∈ {2, 4} 全偶，故其非平凡分量全是 Euler 图、可分解为圈（引理 1.2(2)），且每个非平凡分量 ≥ 3 个点。于是
ce(H) ≤ 1 + ⌊(2n − n_C)/3⌋，
从而 **n_C ≥ n/2 + 6 ⟹ ce(H) ≤ n/2 − 1（C2 对 H 成立）**。
*证明*：deg_{H−E(C)}(v) = 4 − 2 = 2（v ∈ V(C)）或 4（否则）；边数 = 2n − n_C；圈件数 ≤ ⌊边数/3⌋；加上 C 自己共 ≤ 1 + ⌊(2n − n_C)/3⌋。解 1 + (2n − n_C)/3 ≤ n/2 − 1 ⟺ n_C ≥ n/2 + 6（n ≥ 6 时整数化无例外：n_C ≥ ⌈n/2 + 6⌉ 且 ⌊·⌋ 取整方向已吸收）。∎

## 6. 结论强度与遗留

### 6.1 三选一判定

**(b) 部分结果 + (c) 障碍分析**：
1. **完全证明**：R1 及其精确式 1.3′；M3-red（命题 3.5）；C2-red（定理 3.4）与 C2 的 n ≤ 8 情形；G*、K6、K_{3,4}、K_{3,5}、W_6、K_{3,4}+e、K_{3,3}+单弦、K_{3,3}+双弦八个 ce 值的独立手工证明（均与机器一致）；n ≤ 7 紧实例的完全同构分类（258 + 140 例，计数逐例吻合）。
2. **障碍（定位到不等式）**：Δ≤5 猜想的剩余难度被 R1 隔离在残差类，并被 M3-red 进一步聚焦为**偶子图长圈**问题；5-正则链的三段独立缺口（§3.6）；储蓄族局部交换的死因 = 悬径付费 + 最优分解谱系三分（§3.1）。
3. **诚实记录的失败/修正**：储蓄框架未复现 Δ≤4 一般定理（W=∅ 缺口维持开放）；s1 预过滤 bug 已披露并修正（遗稿的残差/紧计数是漏报下界）；n=7 Hamilton 2-因子分解（3+4 分裂不可能性）未给出一般证明，以全枚举为准。

### 6.2 遗留与下一步

1. **M3/长圈（头号问题）**：2-连通 4-正则图（n ≥ 10）是否有圈长 ≥ n/2 + 6？弱化：能否证圈长 ≥ c·n（c > 0）然后调 R1 判据的常数？注意 3-正则 expander 的长圈只有 Θ(log n)（启发类比），4-正则 2-连通的线性长圈**不保证存在**——若不存在，M3 框架对残差类失效，需要 τ-交换（下条）补。
2. **τ-交换**：ce = min_F (|F| + c*(G−F)) 中 F 的自由度。残差类上研究 |F| + s 换 c* 骤降的交换是否存在（Gallai–Edmonds/T-join 多面体工具）。这是 M3 失效时的备胎，也是把 T-join 理论正式引入本题的接口。
3. **Petersen 一般形式查证（交 Librarian）**：「偶阶无桥 r-正则图有 1-因子」真伪；若伪，找一个无桥 5-正则无完美匹配的最小反例（数值可查 n ≤ 10）。
4. **C2 的割点版**：4-正则图带割点时 ce ≤ n/2 − 1 是否仍真（瓣分析不够，需数值先探 n ≤ 10 有割点 4-正则图）。
5. **n ≥ 8 的紧族外推**：K_{3,q} 止于 q=5（Δ=5）；n ≥ 9 的 2-连通 Δ≤5 紧实例是否存在（sup ce/(n−1) 是否保持 1）？K_{3,4}+e 的扩张（右部加点的「K_{3,q}+左弦」族）是否保持紧——数值目标 n = 9..12（需 Experimenter）。
6. **撞车监控**：R1/M3-red 是「T-join + 圈分解」的组装，AABC/BM 团队会立刻看到；建议把 R1 + M3-red + K_{3,4}+e 紧族写入战役共享材料。

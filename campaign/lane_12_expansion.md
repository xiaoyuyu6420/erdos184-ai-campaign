## 二、命题 12.1（剩余映射的动力学分类：不动点判据）

**陈述**。设 f: [d₀,∞) → [1,∞)（d₀ ≥ 2）为单步分解引理的剩余平均度映射（Lane 01 命题 A 的设定，此处只需 f 单调不减）。则：

(a) 若存在 d* ∈ (d₀,∞) 使 f(d*) ≥ d*（如一切 f(d) = (log d)^c，c ≥ 1，其不动点 d* 满足 d* = (ln d*)^c 存在且超常数），则朴素迭代 f^i(n) 不必降到 d* 以下；特别地 f 连续、f(d) < d 当且仅当 d > d* 时，f^i(n) → d*，朴素迭代深度 = ∞。

(b) 设 f 进一步满足**塔步条件**：存在单调函数 g 与常数 C > 0，使 f(C·g(t)) ≤ C·g(t/2)（对数塔降一层；t/2 取整不影响）对一切充分大的 t 成立。则任何以 f 为单步映射、总圈数 O(n·T(n)) 的分解，只要其每一步只使用"剩余平均度 ≤ f(当前剩余平均度)"这一信息、且允许以原始 n 为参照重置（塔重置），就有 T(n) ≤ log* n + O(1)；同一设定下若**无塔步条件，(b) 为假**——反例 f(d) = d/2：每步只减半、不满足塔步条件，深度 Θ(log n)，塔重置（参照系选择）改变不了单步映射的下降率。塔步条件恰为 polylog 型映射所满足（BM 的 eqn:Clogi 记账即验证此条件，见证明）。

(c) 若 f(d) ≤ φ(d) 且 φ(d) < d 对一切 d > d₀，φ 单调，则朴素迭代深度 = max{i : φ^i(n) > d₀}；此时深度由 φ 的**自相似结构**决定，与 f 的逐点大小无关。

**证明**。
(a) f 单调不减且 f(d) < d ⟺ d > d*（连续性下解集为区间 (d*,∞)）。对 n > d*：f(n) < n 且 f(n) > f(d*) ≥ d*（n > d* 与 f 增），故 {f^i(n)} 单调下降、以 d* 为下界，收敛于某 L ≥ d*，由连续性 L = f(L)，而 [d₀, d*] 上无 f 的不动点（f(d) ≥ d 仅在 d*，f(d) < d 在 (d*,∞)）——等等，需 f(d) > d 对 d < d*：由 f(d) < d ⟺ d > d* 与 f 连续即得 f(d) ≥ d 对 d ≤ d*。故唯一不动点为 d*，L = d*。所以 f^i(n) ↘ d*，永不降 below d*，朴素深度 = ∞。□（此即 polylog 剩余的卡死现象：f(d) = (ln d)^c 的不动点 d* = e^{x*}，x* 是 x = c ln x 的解，超常数；c = 274 时数值迭代收敛于 x* ≈ 2095.4，注意 x* ≠ c·ln c ≈ 1538——后者只是一阶粗估，不是不动点。）

(b) 正方向即 BM lines 1039–1049 的记账抽象：归纳假设 d_i ≤ C·g(log^{[i]}n)（g 单调），每步 d_{i+1} ≤ f(d_i) ≤ f(C·g(log^{[i]}n))；由**假设的塔步条件**（f(C·g(t)) ≤ C·g(t/2)，当 log^{[i]}n 充分大）得 d_{i+1} ≤ C·g(log^{[i+1]}n)，故深度 = max{i : log^{[i]}n ≥ 阈值} = log* n + O(1)。polylog 型 f（如 f(d) = (ln d)^c）满足塔步条件：取 g(t) = (C·ln t)^c 级函数可直接验证——这正是 BM eqn:Clogi 的内容。反方向：若 f 不满足塔步条件（如 f(d) = d/2），塔重置无从产生塔降，(b) 不适用（见陈述中的反例）；若某步的输入低于塔重置的有效区，(a) 卡死。□

(c) 平凡归纳：d_i ≤ φ^i(n)，φ^i 单调，深度即 φ^i 跌破 d₀ 的步数。□ ∎

**推论 12.1.1（逐点大小与深度脱钩）**。存在 f ≼ g（逐点 f ≤ g，大 d）使 f 的（塔重置）深度 = log* n 而 g 的朴素深度 = Θ(log log log n) ≪ log* n 不成立地"看似更优"——具体地 f(d) = (ln d)^{274} ≪ 2^{(ln d)^θ} = g(d)（d ≥ e^{≈5.6×10³} 处 crossover；解 (ln d)^θ = 274 ln ln d 得 ln d ≈ 5607，θ=0.9；【PREPUB_REVIEW Y8：原稿误写 ln d ≈ 3×10⁷，已更正】），但 f 的深度（命题 12.2）是 log* n = o(g 的深度)。**深度比较必须算动力学，不能比逐点大小。**

**推论 12.1.2（塔重置的不可替代性）**。在命题 (a) 情形，任何"只看当前剩余度"的调度都卡 d*；绕过卡死的唯一 BM 内机制是外部塔参照。因此 polylog 剩余 ⟹ log* 深度，无论参数如何打磨（274 → 136 → … 不变，见第六节）。

## 五、命题 12.4（低 s 窗内切分价格的树模型下界）

**陈述**（部分进展；两个标注的限制见末尾）。设 s = s(n) 满足 8 ≤ s ≤ (ln n)²/(4eps₀)，eps₀ 为常数。存在 n 顶点 (eps₀, 0)-expander 族 G_n，使得**任何**把 E(G_n) 经"递归失败集切分"（BM Lemma line 570 的机制：每次删 |F| ≤ s|U| 条边并分离 U∪N(U)）分解为 (eps′, s)-expander 片的过程，其删除总边数 ≥ c·s·n·log n（c > 0 常数）。

**证明骨架（逐步给出，两处依赖标注）**。

*构造*：取 G_n⁰ = G(n, s+1)-随机正则图的典型实现（或任何满足下面 (P1)(P2) 的图）：
(P1)（小集点扩张）对一切 |U| ≤ n/2 与一切 F ⊆ E，|F| ≤ s|U|：|N_{G−F}(U)| ≥ eps₀|U|/log²n。
(P2)（线性割廉价）存在 |U| = n/2 的集合，其割边 |∂U| ≤ s·n/2。
随机 (s+1)-正则图：(P2) 取 U 为任一半图，∂U ~ (s+1)n/2·(1−o(1)) ≤ s·n/2 对 n ≫ s²？——**此处存疑**：随机正则的半图割宽 ~ (s+1)|U|(1−o(1))，恰好贴着 s|U| 上沿，需要 (1−o(1)) 精细版本 [依赖随机正则图二阶割性质，UNVERIFIED-间接]。安全替代：把基图换成"两个 (s+1)-正则 expander 简体 + 每顶点 1 条随机匹配跨边"的三度拼接，割宽可控 ≤ s|U|（每顶点恰 1 条跨边 ⟹ |∂U| = |U| = n/2 ≤ s|U| 当 s ≥ 2 ✓ 完全初等）。拼接图仍是 (eps,0)-expander 吗——内部是 (s+1)-正则随机图（(P1) 的来源），跨边只增不减邻域 ⟹ (P1) 对拼接图成立（N_{拼接−F}(U) ⊇ N_{半−F}(U∩半) − 跨边删除…严格化：任一 U，其在较大半内的部分由 (P1) 扩张；若 U 均分两半，则每半至少 |U|/2 − s|U|/…——标注 [GAP-12.4a：拼接图 (P1) 的逐情形验证，预计可行但需 1–2 页 bookkeeping]）。

*下界论证*：设切分树 T，节点 = 失败对 (U_j, F_j)。两个关键事实：
（F1）**失败集必大**：若 |U_j| ≤ n/2，则由 (P1)，|N_{G−F_j}(U_j)| ≥ eps₀|U_j|/log²n，与失败定义矛盾。故每个失败集 |U_j| > n/2？——**不对**，(P1) 只对基图整体的 |U| ≤ n/2 成立，切分树深层作用在片上。修正：片 V_j ∖ U_j 是基图导出闭包的子集，(P1) 需要相对化 [GAP-12.4b：(P1) 在"已被切开的诱导子图"上的保持性——随机正则图的诱导子图不保 (P1)]。
（F2，不依赖 F1 的弱版）若所有失败集满足 |U_j| ≥ c₀·(当前片大小)（c₀ > 0 常数），则片大小沿每刀至多乘 (1 − c₀/2)（因片新 = U∪N ⊆ 片旧，且递归两侧片大小和 ≤ 片旧(1+o(1))，深度 ≥ log(n/n₀)/log(1/(1−c₀/2)) = Θ(log n)，而每刀删除 |F_j| ≥ … 需下界 |F_j| ≥ ？——F_j 只需覆盖使 U_j 不扩张的边集，其大小下界来自：∂(U_j) ≥ (P1) 的边版本…（F2 的删除下界也需要 ∂U ≳ s|U|，随机正则成立 [同 UNVERIFIED]）⟹ 每层删除总量 ≥ c·s·(层内片大小和) ≥ c·s·n ⟹ 总删除 ≥ c·s·n·Θ(log n)。∎（骨架）

**诚实标注**：

- [GAP-12.4b] (P1) 在深层片上的相对化未完成——这是"树模型"限制的根源：树模型下每一刀的失败集条件参照**原图**定义还是**片**定义，BM 是后者（片内的 (eps,s)-expander 条件，line 571），而我的 (P1) 是原图全域性质。完成相对化 ⟹ 命题完全成立；失败 ⟹ 下界需要全新机制。

## 六、BM 机器的 s-参数核算（逐行重读；两项负结果）

**6.1 s 的单调性（正结果，完全证明）**。检查 thm:decompexander-explicit（lines 974–983）及其全部被调件对 s 的依赖：
- lem:decompexander（line 962）条件 s ≥ log²⁷³n，**下界型**；内部 s′ = √(s·eps)/(24 log n) 随 s 增而增，s′ 的一切下游条件（thm:pathconnect 需 ≥ log¹³⁵，line 674；lem:expandintorandom2 需 ≥ 2log²⁴，line 841；prop:red-blue-robust-both 需 ≥ 8log¹³，line 521）均下界型。
- lem:partitionedgesintoexpanders（line 624）条件 s ≥ 2¹²eps⁻¹k²log⁴n，下界型。
- lem:sparseconnect（line 923）、lem:template（line 432）、cor:lovasz（line 947）：不含 s。
- 骨架边数 2⁹n·log¹⁰n（line 930）：不含 s。
**结论**：对任意 s ≥ log²⁷³n，thm:decompexander-explicit 成立且剩余 = 4sn·log n + 2¹²n·log¹⁰n + O(n)。s 是**自由购买参数**，价格函数 P(s) = 4sn log n 线性于 s。BM 取 s = log²⁷³n 是使"删除价 = 机器最低需求"的最便宜选择——**在机器需求 s_min = log²⁷³ 给定的前提下，BM 的参数已是最优；一切改进空间在压 s_min，而 s_min = (log¹³⁵)² 由三片切分的 √s 损耗决定（谱系表第 9 行，Lane 01 已算：273 = 2×135+3）。**

**6.2 三随机类合并不可行（负结果，架构内完全证明）**。我试探的省 s 路线：lem:decompexander 用 k=3 边切分（lines 964）把 G 分为三个边不交 (eps/4, s′)-expander、配三个随机顶点类 V₁,V₂,V₃，代价是 s′ = √(s·eps)/(24 log n)（√s 损耗）。设想：取消三片，用一个 G + 三组对族的一次 Aharoni–Haxell 应用（matching 自动跨组边不交），省掉 √s 损耗 ⟹ s_min 从 log²⁷³ 降到 log¹³⁵。
**击毙**：三组闭环路 Q_P（line 966）必须满足：Q_P 内部顶点 ∈ V_i 且 Q_P 避开路径 P 的全部顶点（P ⊆ V(H_i) = V ∖ V_i），这样 P∪Q_P 才是真圈。合并方案的两个变体：
- 变体 A（一次 path-connect，V = V₁∪V₂∪V₃ = V(G)）：闭环路内部顶点无约束 ⟹ Q_P 可穿过 P 的内部顶点 ⟹ P∪Q_P 只是闭游走，Lovász 路径分解的圈化失败。
- 变体 B（共用单个 V₁，把 H_i 全部安置在 V ∖ V₁ 上）：与 V₁ 关联的边（~1/3·|E|）无法进入任何 H_i ⟹ 每步剩余 ~ |E|/3 ⟹ f(d) ≳ d/3，迭代无进展——正是 Lane 01 命题 C 的"胖储备库支"。
**结论**：三互斥随机类 + 三片边池是"路径族覆盖全部边"与"闭环路避开对应路径族顶点"两个硬约束的必然推论，√s 损耗在本架构内锁死。（BM 的设计无可指摘；这也把 Lane 01 命题 C 从"架构假设"进一步坐实了一环。）

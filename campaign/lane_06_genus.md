## 2. 定理与证明（分层；GAP 显式标注）

约定：图简单有限；"分解"= 边不相交圈（简单圈）+ 单边划分边集；亏格 g = **定向**亏格（非定向见 §5 警告）；嵌入默认 cell（2-cell）且取最小亏格嵌入（此时为 cell 嵌入，标准，Mohar–Thomassen）。

### 2.0 引理 L6.0（块归约；BHK 亏格可加）

**引理 L6.0**：(i) f_ce(G) ≤ Σ_{块 B} f_ce(B)，且 G 连通时 Σ(|V(B)|−1) = n−1（与 notes/attack_planar.md 引理 0 逐字相同，无曲面内容）。(ii)（Battle–Harary–Kodama–Youngs 1962）定向亏格对块可加：g(G) = Σ_B g(B)。

*用途*：带 g 的逐块界相加时 Σg(Bᵢ) = g(G) 保真（定向情形）。∎

**警告（非定向）**：非定向亏格对块不可加 [Stahl–Beineke 1977]，故本文一切含 g 的陈述限定定向；非定向版本需单独论证（§6 遗留）。

### 2.1 定理 L6.1（普适剥离界；显式常数线性）

**定理 L6.1**：任何 n 点 e 边图：f_ce(G) ≤ e/3 + 2(n−1)/3。特别地，定向亏格 g 简单图（e ≤ 3n−6+6g，Euler 公式 + 面度 ≥ 3）：

  **f_ce(G) ≤ (e + 2n − 2)/3 ≤ 5n/3 + 2g − 8/3。**

*证明*：贪心剥离边不相交圈 C₁,…,C_k 直到剩余 R = G − ∪E(Cᵢ) 无圈（森林，|E(R)| ≤ n−1）。取 {Cᵢ} 为圈对象、R 的每条边为单边对象：对象数 = k + |E(R)|。由 Σ|Cᵢ| = e − |E(R)| 且 |Cᵢ| ≥ 3 得 k ≤ (e − |E(R)|)/3，故对象数 ≤ (e − |E(R)|)/3 + |E(R)| ≤ e/3 + 2(n−1)/3。e 的界：cell 嵌入 Euler 公式 n − e + f = 2 − 2g 与 2e = Σ_f deg(f) ≥ 3f 联立得 e ≤ 3n − 6 + 6g。∎

*诚实备注*：此论证是"稀疏图 O(n)"级别的平凡观察，**极可能属民间已知**；战役记录中平面/曲面图无显式常数线性界，故存档。g=0 给出 **f_ce(平面) ≤ 5n/3 − 8/3**（如已知请交叉审查员标记）。

### 2.2 定理 L6.2（Eulerian 亏格 g 图）

**定理 L6.2**：G Eulerian（各点偶度）、定向亏格 g、含圈。则 f_ce(G) ≤ ⌊e/3⌋ ≤ n−2+2g。精化：
(i) 若 e ≤ 3n−7+6g，则 f_ce(G) ≤ n+2g−3；
(ii) 若 e = 3n−6+6g（G 为 S_g 三角剖分），则 f_ce(G) ≤ n+2g−4。

*证明*：Eulerian ⟺ 边集可划分为边不相交圈（Euler 分解定理；教科书结果，如 Diestel §1.8）。取该分解：对象数 = 圈数 c ≤ ⌊e/3⌋（每圈 ≥ 3 边，整除向下取整）。
(i)：e ≤ 3n−7+6g ⟹ ⌊e/3⌋ ≤ ⌊(3n−7+6g)/3⌋ = n+2g−3。
(ii)：e = 3n−6+6g ⟹ Euler 公式给 f = 2n−4+4g，2e = Σdeg(face) ≥ 3f 取等 ⟹ 全部面为三角形（三角剖分）。简单三角剖分 ⟹ δ ≥ 3；Eulerian ⟹ δ 偶 ⟹ **δ ≥ 4**。G 2-连通（所有面边界为简单圈 ⟹ 无割点；否则某面边界游走重复经过割点，非简单圈）。由 **Dirac 周长定理**（G.A. Dirac, *Some theorems on abstract graphs*, Proc. London Math. Soc. (3) **2** (1952) 69–81；陈述：2-连通图含长 ≥ min{n, 2δ} 的圈。第二轮核验：论文存在性、年份、期刊卷期已确认 [Semantic Scholar 条目；arXiv:2212.06897 (Kostochka et al. 2022) 转述为 "the classical paper of Dirac from 1952"]；定理在该文中的精确编号/页码仍待 Librarian 终核）：存在圈 C，ℓ = |C| ≥ min{n, 2δ} ≥ min{n, 8}。n ≥ 7（e = 3n ≤ C(n,2)）：
- n = 7：ℓ ≥ 7；Eulerian 图去掉圈 C 的边仍 Eulerian（各点度减 0 或 2）⟹ E(G)−E(C) 分解为 ≤ ⌊(e−7)/3⌋ 个圈 ⟹ 总对象 ≤ 1 + ⌊(3n−13+6g)/3⌋ = 1 + (n+2g−5) = n+2g−4；
- n ≥ 8：ℓ ≥ 8 ⟹ 总对象 ≤ 1 + ⌊(3n−14+6g)/3⌋ = n+2g−4。∎

*兼容性检查（g=0）*：g=0 时 e ≤ 3n−6。情形 (i)（e ≤ 3n−7）：⌊e/3⌋ ≤ n−3，强于平面审定定理 B 的 n−2（子情形改进，相容）。情形 (ii)（e = 3n−6，平面三角剖分）得 n−4，即下面的推论。

**推论 L6.2′（附带的平面精化）**：欧拉平面三角剖图满足 f_ce ≤ n−4（n ≥ 8）。

*n < 8 的排除与核查（第二轮修正：原遗稿论证有误，结论保持）*：欧拉平面三角剖分的对偶是 3-正则二部平面图（对偶点度 = 原面长，全偶 ⟹ 二部）。**遗稿原论证 bug**：它写"对偶点数 f = n 必为偶 ⟹ n = 7 不存在"——三角剖分面数为 f = 2n−4，恒为偶，该论证对任何 n 都无排除力。**排除证明（n = 7）【原第二轮组合论证作废，由审查员独立证明替换；PREPUB_REVIEW Y1】**：作废原因：原论证写"外边总数 = 3·4−6 = 6 > 4"——12−6 = 6 是**辐条端点计数**而非外边数（外边实为 3 条，3 ≤ 4 无矛盾）；且"6-面无弦"未经论证。**审查员独立证明（发布稿引用此版）**：设 G 为 n=7 的欧拉平面三角剖分，e = 3·7−6 = 15，Σdeg = 2e = 30。三角剖分 ⟹ δ ≥ 3；Eulerian ⟹ δ 偶 ⟹ 每点度 ∈ {4, 6}（度 ≤ n−1 = 6）。30 ≠ 7·4 ⟹ 度列必为 **(6¹, 4⁶)**：唯一的 6 度点 v 与其余全部 6 点相邻（universal）。三角剖分中 v 的 6 个邻居按嵌入循环序 u₁,…,u₆ 构成圈 C₆（v 的 link：每个面 vuᵢuᵢ₊₁ 给出边 uᵢuᵢ₊₁）；v 关联的 6 个三角形面沿 link 排布一圈，恰填满 C₆ 的内部区域 ⟹ G−v 的其余 3 条边全部画在 C₆ 外部且两两不交叉 ⟹ **G−v 是外平面图**（全部顶点共外面）。但 G−v 每点度 = 4 − 1 = 3（3-正则：C₆ + 3 条互不交叉的外部弦，三棱柱型）。而外平面图**至少有两个度 ≤ 2 的顶点**（标准事实：2-连通外平面图的对偶是树；一般情形取外面边界上度最小的两点或对 1 度点归纳）——与 3-正则矛盾。故 n=7 的欧拉平面三角剖分不存在。∎**穷举双确认**（脚本 euler_triangulation_small_n.py，networkx/Boyer–Myrvold 判平面性）：n=4:0、n=5:0、n=6:15（全部八面体，度序列 (4,4,4,4,4,4)）、n=7:0。n=6 八面体 f_ce = 2 = n−4 ✓（审定笔记 §3.3 已知事实，佐证推论）。∎

### 2.3 定理 L6.3（Eulerian 环面：P 级，本 lane 头条）

**定理 L6.3**：G Eulerian、可嵌入环面（定向亏格 ≤ 1）。则 **f_ce(G) ≤ n−1**；若 G（某连通分支）是环面三角剖分则该分支 f_ce ≤ n−2。

*证明*：按连通分支处理（Eulerian 图的分支仍是 Eulerian，且各分支分别可嵌入环面或平面）。
- **情形全图 e ≤ 3n−1**：Euler 分解给出 c ≤ ⌊e/3⌋ ≤ ⌊(3n−1)/3⌋ = n−1 个圈对象，完成。（此处无需 2-连通、无需逐块——Euler 分解对全图直接成立。）
- **情形全图 e = 3n**：各分支满足 eᵢ ≤ 3nᵢ 且总和 = 3n ⟹ 每分支 eᵢ = 3nᵢ，即每分支为环面三角剖分（平面分支不可能：其 eᵢ ≤ 3nᵢ−6）。Euler 公式 nᵢ−eᵢ+fᵢ = 0 ⟹ fᵢ = 2nᵢ，2eᵢ = 6nᵢ = Σdeg(face) ≥ 3fᵢ = 6nᵢ 取等 ⟹ 全部面为三角形 ⟹ 分支 2-连通（面边界全为简单圈则无割点）、简单 ⟹ δ ≥ 3，Eulerian ⟹ **δ ≥ 4**。Dirac 周长定理：圈 C，ℓ ≥ min{nᵢ, 2δ} ≥ min{nᵢ, 8} ≥ 7（nᵢ ≥ 7，由 eᵢ = 3nᵢ ≤ C(nᵢ,2)）。分支 − E(C) 仍 Eulerian ⟹ 分解为 ≤ ⌊(3nᵢ−ℓ)/3⌋ ≤ ⌊(3nᵢ−7)/3⌋ = nᵢ−3 个圈。分支对象 ≤ 1 + (nᵢ−3) = nᵢ−2。合计 ≤ Σ(nᵢ−2) ≤ n−2 ≤ n−1。∎

*兼容性检查*：g=0（欧拉平面图）时定理给 n−1，弱于已审定的平面 n−2 ✓ 不蕴含 P（欧拉环面图类真包含欧拉平面图类，但结论只对前者给 n−1）。
*锐性*：不声称锐。数值上欧拉实例都很小（K_{4,4}=2、K₇=3、C₃□C₃=2、C₄□C₄=2，见 §4），n−1 的真实 gap 可能很大。

### 2.5 定理 L6.5（Hamilton 提升引理；5-连通环面应用）

**定理 L6.5**：G 定向亏格 g、2-连通、含 Hamilton 圈 C。则 f_ce(G) ≤ 1 + (e−n)/3 + 2(n−1)/3 ≤ 4n/3 + 2g − 5/3。

*证明*：H = G − E(C) 有 e−n 条边；对 H 用 L6.1（剥离界）：f_ce(H) ≤ (e−n)/3 + 2(n−1)/3；C 自身 1 个对象；合计 ≤ 1 + (3n−6+6g−n)/3 + 2(n−1)/3 = (4n+6g−5)/3。∎

**推论 L6.5′**：每个 5-连通环面图 f_ce ≤ 4n/3 + 1/3（Thomas–Yu 1997 ⟹ Hamiltonian）。任何未来"某曲面图类皆 Hamilton"的结果自动获得对应 4n/3+O(g) 界。注意：即使有了 Hamilton 圈，残余项 2(n−1)/3 是**平面 GAP-A/B 的同源卡点**（残余图 H 无"省 1 容量"），4n/3 不可经此路线压到 n−1+c。

### 2.6 定理 L6.6（下界：f(g) 的必要阶 + 环面锐例）

**定理 L6.6**：任何形如"一切定向亏格 g 图 f_ce ≤ n−1+f(g)"的普适界必须满足 **f(g) ≥ ⌈(4g−4)/3⌉**（g ≥ 2；g=1 时下界为 0）。

*证明*：战役审定数据：K_{3,m}（n = m+3 个点）需要 ≥ (4/3)m 个对象。Ringel 公式（Ringel《Map Color Theorem》1974，标准）：定向亏格 genus(K_{a,b}) = ⌈(a−2)(b−2)/4⌉ ⟹ genus(K_{3,m}) = ⌈(m−2)/4⌉。取 m = 4g+2：genus 恰为 g，对象 ≥ (4/3)(4g+2) = (16g+8)/3，n−1 = 4g+4，故超出量 ≥ (16g+8−12g−12)/3 = (4g−4)/3，整数化 ≥ ⌈(4g−4)/3⌉。∎

**环面锐例（数值确认，§3）**：f_ce(K_{3,4}) = 6 = n−1、f_ce(K_{3,5}) = 7 = n−1、f_ce(K_{3,6}) = 8 = n−1（求解器 EXACT，最优性双向验证；与战役下界 (4/3)(n−3) 吻合）。即：**若 L6-C1（一切环面图 ≤ n−1）为真则它已锐**；但 L6-C1 蕴含 P（环面类 ⊇ 平面类），现状开放。**g=2 窗口（第二轮完备）**：f_ce(K_{3,7}) = 10 = n−1+1、f_ce(K_{3,8}) = 11 = n−1+1、f_ce(K_{3,9}) = 12 = n−1+1（三者 EXACT）、f_ce(K_{3,10}) = 14 = n−1+2（构造：大点集划分 {3,3,2,2}，各 K_{3,3}=C₆+3单边、K_{3,2}=C₄+2单边，合计 4+4+3+3 = 14；下界 ⌈40/3⌉ = 14 夹死；证书由 fce_extra.py 独立验证）。五例全部 = ⌈4m/3⌉：模式 f_ce(K_{3,m}) = ⌈4m/3⌉ 在 genus ⌈(m−2)/4⌉ = 2 允许的整个 m ∈ {7,8,9,10} 上成立；超出量 max(0, ⌈m/3⌉−2) 在窗口内从 1 升至 2，且在 m = 4g+2 = 10（L6.6 下界实例）达到 ⌈(4g−4)/3⌉。

#### 2.7.1 定理 L6.7（skewness 墙；复现确认，不变）

**(a)** 对一切 m ≥ 3：**sk(C_m□C_m) ≥ m−2**，且 sk(C_m□C_m) ≤ m（删一行 m 条边得柱面梯阵 C_m□P_{m−1}，平面）。故 sk(C_m□C_m) = Θ(m) = **Θ(√n)**（n = m²）。**(b)** 精确值：sk(C₃□C₃) = 2、sk(C₄□C₄) = 4、sk(C₅□C₅) = 5（穷举证明无更小删除集 + 行删除证书，脚本 skewness_grid.py；第二轮全部复现 ✓，行删除证书 m=3..6 全平面 ✓）。

*证明 (a)*：上界如述。下界：设 |F| ≤ m−3。删 k 条边至多"击中" k 行与 k 列（每条边恰属一行一列），k ≤ m−3 ⟹ 至少 3 个整行、3 个整列完好。其并集含 C₃□C₃ 的细分（3 行 3 列的弧拼接，9 条弧两两边不交、内部点非交叉点）。**C₃□C₃ 抽象非平面**（Boyer–Myrvold 判定 ✓）。Kuratowski：平面图的子图平面 ⟹ G−F 非平面。故 sk ≥ m−2。∎

#### 2.7.2 裁决修正（取代遗稿 L6.7′"路线否定"）

遗稿称 skewness 墙把"剥 handle 归约平面"判死刑。**这是账本层面的误判**：sk(G) = Θ(√n) 说明"平面化需要删 Θ(√n) 条**边**"，但删掉的边若恰好并成圈，每个圈只值 **1 个对象**——skewness 墙杀死的只是"把删除边按单边记账"的路线（P + 单边账本 ⟹ n−1+Θ(√n)，无用）。圈账本剥离每步删的边集恰是一个非收缩圈（1 对象），**不受 skewness 墙约束**。剥 handle 路线的真正死点在别处：见 2.7.5 的 GAP-CL（点分裂两难）。

#### 2.7.3 引理 A（非收缩圈存在性；自足证明，新增）

**引理 A**：G 可 2-cell 嵌入定向曲面 S_g（g ≥ 1）。则 G 含一个简单圈 C，使 C 在该嵌入的像非收缩（非零伦）。

*证明*：cell 嵌入使 S_g 成为 CW 复形 X：0-胞腔 = V(G)，1-胞腔 = E(G)，2-胞腔 = 各面（开圆盘，cell 性）。标准 CW 事实：π₁(X) 由 π₁(X¹) 生成（2-胞腔的附着只添加关系，不添加生成元；Hatcher《Algebraic Topology》Prop 1.26 型命题 [编号 UNVERIFIED，教科书标准内容，交 Librarian 核]）。π₁(S_g) ≅ ⟨a₁,b₁,…,a_g,b_g | ∏[aᵢ,bᵢ]⟩ ≠ 1（g ≥ 1），故存在 G 的闭游走 W 非零伦。任意闭游走可依次剥出简单圈（标准：Diestel §1.8 型命题）：W 的边序列 = 简单圈 C₁,…,C_m 的依次连接，于是 [W] = [C₁]⋯[C_m]；若每个 [Cᵢ] = 1 则 [W] = 1，矛盾。故某个 Cᵢ 非零伦。∎

（注：遗稿引用的"所有圈可缩 ⟹ 嵌入落在圆盘内"的模糊表述由本引理替代，不再需要。引理 A 无需"抽象非平面"假设——cell 性 + g ≥ 1 即足。）

#### 2.7.4 引理 B（切割账本：删圈 ⟹ 顶点分裂不可避免；新增）

**引理 B**：X 嵌 S_g（2-cell），C 为嵌入下非收缩的简单圈。令 X′ = X − E(C)，则 f_ce(X) ≤ 1 + f_ce(X′)，且：
(i)（C 非分离）X′（顶点集为 V(X) ∖ V(C) 加上 V(C) 每点的两个分裂副本 v⁺, v⁻，边集为 E(X′)，v 的每条非 C 关联边按其像离开窄带的一侧接至 v⁺ 或 v⁻）可嵌入 S_{g−1}；故 |V(X′)| = |V(X)| + |V(C)|，f_ce(X′) 沿用此图的分解；
(ii)（C 分离，两侧亏格 a + b = g）X′ 的边集按像分两侧得 X_a′ ⊔ X_b′（共享 V(C) 的副本顶点），X_a′ 嵌 S_a、X_b′ 嵌 S_b，f_ce(X′) ≤ f_ce(X_a′) + f_ce(X_b′)；|V(X_a′)| + |V(X_b′)| = |V(X)| + |V(C)|。

*证明*：C 作为 X 的简单圈是合法圈对象，故 f_ce(X) ≤ 1 + f_ce(X′)。拓扑部分：取 C 的正则邻域 N ≅ C × (−1,1)，充分窄使 N ∩ (V(X) ∖ V(C)) = ∅。**关键点（消除"横穿段"）**：cell 嵌入中每条边像为简单弧且位于面边界上；边像（除其在 V(C) 处的端点段外）与 C 的像集有正的最小距离（紧性），故可取 N 再窄些使一切不与 V(C) 关联的边像与 N 不交。于是与 N 相交的边像仅是 V(C) 关联边在 v 处的初始段。(i) C 非分离 ⟹ 切 S_g 沿 C 得带边曲面 Σ，∂Σ = C⁺ ⊔ C⁻，亏格 g−1（曲面分类标准结果，Mohar–Thomassen《Graphs on Surfaces》Ch.4 [标准]）。把 X′ 的像放入 Σ：每个 v ∈ V(C) 的关联非 C 边的初始段出 N 时落在 C⁺ 或 C⁻ 上，把该边接至 v 的副本 v⁺ 或 v⁻（副本放在 ∂Σ 上）；合并（初始段 + 中段 + 另一端初始段）后每条边仍是一条简单弧，弧间除共享副本/内部顶点外不交（原嵌入的弧不相交性 + 副本分配一致性）。cap 掉两个边界圆盘得 S_{g−1}，X′ 的像与之不交于圆盘内部（X′ 只触 ∂Σ）⟹ X′ ⊂ S_{g−1}。顶点数：|V(X)| − |V(C)| + 2|V(C)| = |V(X)| + |V(C)|。∎（无需引入额外"贴边"或"横穿段"顶点；遗稿第二轮草稿中的匹配构造与保守账 e(X′) 均删除。）
(ii) 分离情形：切得 Σ_a ⊔ Σ_b（亏格 a, b，标准），X′ 的边像按落入哪一侧分流（每条边的像完全在唯一一侧，因为边像连通且与 N 只交于 V(C) 关联的初始段）；两侧各自按 (i) 处理并 cap。f_ce(X′) ≤ f_ce(X_a′) + f_ce(X_b′)：X′ 的边集 = E(X_a′) ⊔ E(X_b′)，两侧分解拼合即 X′ 的分解（共享副本顶点不妨碍边不相交性）。∎

#### 2.7.5 定理 L6.8（条件剥离定理；严密版，取代遗稿 L6.7″ 的未闭合骨架）

**定理 L6.8**：设平面猜想 P 成立（一切平面图 f_ce ≤ n−1）。设 G 承认**完全非分离剥离序列**：存在圈序列 γ₁, …, γ_m 与图列 G = X₀ ⊃ X₁ ⊃ … ⊃ X_m，使每个 γᵢ ⊆ X_{i−1} 是（当前图在 S_{g−i+1} 的最小亏格 cell 嵌入下的）非收缩圈且**在 S_{g−i+1} 中非分离**，X_i = X_{i−1} − E(γᵢ)，且 X_m 是平面图。则

  **f_ce(G) ≤ n + g + c·(g^{3/2}·√n + g²)**，

其中 c 为绝对常数，其存在性依赖 edge-width 型界 ew(G) ≤ c₀·√(g·n)（最小亏格 cell 嵌入下最短非收缩圈长；Mohar–Thomassen 系 [Th90b]，**常数 c₀ 未核实 [UNVERIFIED]**）。特别地 m ≤ g。

*证明*：逐步：γᵢ 非收缩 ⟹ 引理 A 保证其存在性框架；γᵢ 非分离 ⟹ 引理 B(i) 给 X_i 嵌 S_{g−i}，顶点数 n_{i} = n_{i−1} + |V(γᵢ)|，且 f_ce(X_{i−1}) ≤ 1 + f_ce(X_i)（γᵢ 是圈对象）。m ≤ g（每步亏格严格 −1，嵌入亏格 ≥ 0）。**支付 = m ≤ g 个圈对象**；**顶点账**：|V(γᵢ)| = ew(X_{i−1}) ≤ c₀·√((g−i+1)·n_{i−1}) ≤ c₀·√(g·(n+D)) [UNVERIFIED]，累计 D ≤ c₀·g·√(g·(n+D))，自洽求解：若 D ≤ n 则 D = O(g^{3/2}√n)；若 D > n 则 D = O(g²)。终局 X_m 平面，顶点数 n + D ⟹ P 给 f_ce(X_m) ≤ n + D − 1。合计 f_ce(G) ≤ m + (n + D − 1) ≤ n + g + C·(g^{3/2}√n + g²)。∎

*g=0 检查（目标 (c)）*：g=0 时平凡（m=0，f_ce ≤ n−1 即 P）✓。

**分离步为何进不了账（第二轮自我纠错记录，诚实保留）**：遗稿初稿与本 lane 第一稿曾声称分离步也可 O(g) 计（势 Ψ = Σ(g(X)+1)）。**该论证方向反了**：Ψ ≥ 0 只给分离步数的下界；且存在"洋葱"结构——嵌套的分离非收缩圈 γ₁ ⊃ γ₂ ⊃ …，每次平面侧分离支付 1 而主片亏格不变，剥离被迫付 Θ(n) 次（洋葱图本身真值 f_ce 小，不反例化 f_ce 界，但反例化"剥离记账"）。**分离步的 O(g) 记账 = 开放问题**（见 GAP-CL 第二半）。

#### 2.7.6 GAP-CL（剥离路线的复合墙；本 lane 收尾的核心新 GAP）

**GAP-CL①（点分裂）**：删圈保 1-对象则顶点分裂不可避免（引理 B，+ew/步）——"删圈后顶点集不变仍嵌低亏格曲面"的一般论证未证得也未排除。**[GAP]**
**GAP-CL②（分离步记账）**：一般图的剥离序列必含分离步（存在图使某阶段所有非收缩圈皆分离）。平面侧分离链（洋葱）使朴素记账达 Θ(n)。**问题：证明以下至少之一**：(a) 总存在好的剥离序列（分离步总数 O(g)）；(b) "全分离片"（所有非收缩圈皆分离的可嵌入 S_k 图）有直接界 f_ce ≤ n − 1 + c·k；(c) 分离步支付可用其他结构（如分离圈族整体成圈覆盖）吸收。**[GAP]**
**复合后果**：GAP-CL① + ② 任一解决 ⟹ P ⟹ f_ce ≤ n + O(g) + c·g^{3/2}√n 型显式条件界（g=0 还原 P）；两者都解决 ⟹ P ⟹ n − 1 + O(g) 型线性 f(g)。结合下界 L6.6（f(g) ≥ ⌈(4g−4)/3⌉），线性 f(g) 的窗口为 [⌈(4g−4)/3⌉, O(g)]。任何此类引擎同时作用于平面类（平面 ⊆ 环面），即引擎必须在 P 的邻域内工作（与 GAP-GEN 一致）。

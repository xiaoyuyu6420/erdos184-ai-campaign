## 1. 定理 S（完全证明）：split 图族精确值，紧性下界

**定理 S**。对一切 k ≥ 1：**ce(K₃ ∨ Ī_k) = k + ⌈k/3⌉ + 1**。其中 K₃ ∨ Ī_k = 三角形 A = {a₁,a₂,a₃} ∨ 独立集 B（|B| = k）；n = k+3，m = 3k+3，degeneracy = 3，且 k ≥ 2 时 δ = 3（自为 3-核）。

机器对照（targeted_out.txt [3][8]）：k = 1..9 全部 ce = k + ⌈k/3⌉ + 1（k=7,8,9 给 n = 10,11,12，在穷举域之外）；tight 当且仅当 3 ∤ k。τ：k ≥ 2 时 τ = k，τ(K₃∨Ī₁) = τ(K₄) = 2。

### 1.1 上界：ce ≤ k + ⌈k/3⌉ + 1

K_{3,k} 按块分解（lane_08 T3c 的构造）：k = 3m：m 个 K_{3,3}（每个 = C₆ + 3 单边 = 4 件）⟹ 4m = ⌈4k/3⌉；k = 3m+1（m ≥ 1）：(m−1) 个 K_{3,3} + K_{3,4}（2 C₄ + 4 单边 = 6 件）⟹ 4m+2 = ⌈4k/3⌉；k = 3m+2：m 个 K_{3,3} + K_{3,2}（C₄ + 2 单边 = 3 件）⟹ 4m+3 = ⌈4k/3⌉。A-三角形是与上述边不交的一个圈件（+1）。k = 1 的图是 K₄ 本身：C₄ + 2 单边 = 3 件 = k + ⌈k/3⌉ + 1（不走"K_{3,1} + 三角形"的加法，那会给出错误的 4）。故对一切 k ≥ 1：ce ≤ ⌈4k/3⌉ + 1 = k + ⌈k/3⌉ + 1（⌈x + 整数⌉ = ⌈x⌉ + 整数）。∎

### 1.2 下界：ce ≥ k + 1 + ⌈k/3⌉

由 (E1) 只需证任何边不交圈族 F 的 savings ≤ 2k + 2 − ⌈k/3⌉。对圈 C ∈ F 记：b = b(C) := |C ∩ B|，a = |C ∩ A|，e₂ = e₂(C) := C 中 A-A 边数，e₁ := C 中 A-B 边数。

**(i) 结构恒等式**：C 的每点在 C 中度 2；B 独立 ⟹ e₁ = 2b；A 侧计度：2a = e₁ + 2e₂ ⟹ **a = b + e₂**。于是 savings(C) = |C| − 1 = e₁ + e₂ − 1 = **2b + e₂ − 1**，且由 a ≤ 3 得**每圈 b + e₂ = a ≤ 3**。可能圈型：(b,e₂) ∈ {(1,1) △, (1,2), (2,0) C₄, (2,1) C₅, (3,0) C₆, (0,3) A-△}（(1,0) 需重边，排除）。

**(ii) 三个全局容量约束**：Σ_C b(C) ≤ k（B 点度 3，每圈吃 2 条 ⟹ 至多属 1 圈）；Σ_C e₂(C) ≤ 3（A-A 边共 3 条）；记 B := Σb，S := Σe₂，c := |F|，则 **c ≥ ⌈(B+S)/3⌉**（由 (i) 逐圈 b+e₂ ≤ 3）。

**(iii) 合计**：savings(F) = Σ(2b + e₂ − 1) = 2B + S − c。
- 若 S = 0：savings ≤ 2B − ⌈B/3⌉ ≤ 2k − ⌈k/3⌉（f(B) = 2B − ⌈B/3⌉ 递增）≤ 2k + 2 − ⌈k/3⌉。
- 若 S ≥ 1：savings ≤ 2B + S − ⌈(B+S)/3⌉；右端关于 B、S 单调不减（B 方向增量 ≥ 2−1 = 1 > 0，S 方向增量 ≥ 1−1 = 0），故在 (B,S) = (k,3) 取最大：2k + 3 − ⌈(k+3)/3⌉ = 2k + 3 − (⌈k/3⌉ + 1) = **2k + 2 − ⌈k/3⌉**。

故 ce ≥ (3k+3) − (2k+2−⌈k/3⌉) = k + 1 + ⌈k/3⌉。∎

**推论 S′（4/3 常数的逐点紧性）**。对 n = k+3 ≥ 4 且 n ≢ 0 (mod 3)：存在 3-degenerate 图（split 族）使 ce = φ(n)。故 T3b 若真则常数 4/3 不可再降，且极值结构是「3-核 + 三角形混合核」型。n ≡ 0 (mod 3)（n ≥ 6）时 split 给 φ(n) − 1，机器证实这就是真实 max（§5），即猜想 D（§6）。

## 2. 剥除演算（完全证明）：d ≤ 3 顶点的件数成本

设 G 3-degenerate，v 的度 d ≤ 3，G′ := G − v。以下「替换」指：取 G′（或溶解图）的最优分解 D，修改含特定边的件。

**引理 A(a)（d ≤ 1）**：ce(G) = ce(G′) + d。*证*：v 的边都是桥（d=1 时：过它的圈须再用 v 的另一条边）；桥不能在任何圈件中，件数精确相加。∎

**引理 A(b)（d = 2，N(v) = {x,y}）**：
- x, y 在 G′ 的不同分量 ⟹ vx, vy 都是桥 ⟹ ce(G) = ce(G′) + 2。
- x, y 同分量：**ce(G) ≤ ce(G′) + 1**；且 G″ := G′ + xy 仍 3-degenerate（度-中性替换：含 xy 的子图 H 换 xy 为 xv+vy 落回 G，x 处度数 −1+1 = 0；即 lane_08 引理 2.3 的 d=3 版，该证明对任意 d 成立），故 ce(G) ≤ ce(G″) + 1 ≤ φ(n−1) + 1。
*证*：xy ∈ E(G′) 时，D 中含 xy 的件 P：P = {xy} 时换成三角形 {xy, xv, vy}（0 件净增，两条新边全覆盖）；P 为圈 C 时换成 C − xy + xv + vy 再补 {xy} 单边件（净 +1；**注意必须补 {xy}，见 §2.4 勘误**）。xy ∉ E(G′) 时溶解 G″：D″ 中 xy 所在件：单边 ⟹ 拆成 {xv},{vy}（净 +1）；圈 ⟹ 替换补 {xy} 单边（净 +1）。∎

**引理 A(c)（d = 3，N(v) = {x,y,z}）**：
1. N(v) 跨 G′ 的 t ≥ 2 个分量（t ∈ {2,3}）：t = 3 时三条 v-边全为桥，ce(G) = ce(G′) + 3；t = 2 时恰一个分量含 2 个邻居（鸽笼），其余邻居边为桥：分量可加 + A(b) ⟹ ce(G) ≤ ce(G′) + 2。两种情形合并 ce(G) ≤ ce(G′) + 3，且由 φ 的超可加性（引理 φ1/φ2 + 三分支不等式，§2.3）**不经 +cost 会计、直接经分量归纳闭合**。
2. N(v) 全在一个分量，且某对 xy ∈ E(G′)：xy 所在件为单边 ⟹ 换三角形 {xy,xv,vy} + {zv}（净 +1）；为圈 ⟹ 换 C − xy + xv + vy + {xy} + {zv}（净 +2）。故 **ce(G) ≤ ce(G′) + 2**（+1 当且仅当某条 N-边在某个最优分解中是单边件）。
3. 一般情形（N 独立、同分量）：对任一对 xy，**ce(G) ≤ ce(G − v + xy) + 2**（D″ 中 xy：单边 ⟹ {xv},{vy},{zv} 净 +2；圈 ⟹ 替换 + {zv} 净 +1）——但 +1 档需要「xy 在某最优分解的圈件中」，且**此时不能援引归纳**：G″ 未必 3-degenerate。
故无条件地：ce(G) ≤ ce(G′) + 3，即 ce(G) ≤ φ(n−1) + 3；要落到 φ(n) 需省出 β(n) 以外的成本。∎

**引理 P4′（d=3 溶解的反例，回答上轮遗留）**：存在 3-degenerate G 与 deg-3 顶点 v（N(v) 独立），使得**全部三对** pair-dissolve G − v + xy 都有 degeneracy 4。*证（构造 + 机器证书）*：取 G − v = K₅ − xy（顶点 x,y,p,q,r）+ 新点 z ~ {p,q,r}，v ~ {x,y,z}（n = 7）。剥 v（度 3）、剥 z（度 3）后剩 K₅ − xy（3-degenerate ⟹ deg(G) = 3 ✓）；N(v) 独立 ✓；对 (x,y)：加 xy 得 K₅ ⊇；对 (x,z)：{x,z,p,q,r} 导出 K₅ − xz ⊇；对 (y,z) 对称。机器：degen = 3，三次溶解全部 = 4（targeted_out.txt [7]）。同型更小例：K₅−e + v(x,y,z)（n=6，[7b]）。随机扫描：3000 个随机 3-degenerate 图中 0 例——病态需要 K₅−e 型 9 边 5 点稠密子图，稀有但存在。∎（lane_08 引理 2.3 的 deg-2 溶解**不受影响**。）

**引理 A 路线对「ce(K₃∨Ī_k) 逐 B 剥除」的应用检查**：split 的 B 剥除属 A(b) 同分量情形 ⟹ ce(G) ≤ ce(G′) + 1，而真值 cost = ⌈4k/3⌉ − ⌈4(k−1)/3⌉ ∈ {1,2}——演算上界与真值差 1 的来源是三角形替换只有当 xy 是单边件时才 0 成本。

### 2.3 φ 的两个加法引理（残差公式，完全证明）

φ(n) = (4n − 6 − ρ(n))/3，ρ(n) := n mod 3。则：
- **φ1**：φ(a) + φ(b) + 2 ≤ φ(a+b+1)（a,b ≥ 2）。*证*：两边乘 3 通分：左 = 4(a+b) − 12 − ρa − ρb + 6 ≤ 4(a+b) − 6 − ρ(a+b+1) = 右 ⟺ ρ(a+b+1) ≤ ρa + ρb + 6，恒真（ρ ≤ 2）。∎
- **φ2**：φ(a) + φ(b) ≤ φ(a+b) − 1（a,b ≥ 3）。*证*：⟺ ρ(a+b) ≤ 3 + ρa + ρb，恒真。∎
（三分支剥除用：φ(a)+φ(b)+φ(c) + 3 ≤ φ(a+b+c+1)：左 ≤ (4(a+b+c) − 18)/3 + 3 = (4n − 13)/3 ≤ (4n − 8)/3 ≤ φ(n)。∎）

### 2.4 勘误（lane_08 定理 T2，情形 (iii)(α)）

lane_08 §2 引理 2.2/定理 2.1 的 (α) 情形（uw ∈ E(G′)）写道：件 P ∋ uw 为圈 C 时「C′ := (C ∖ {uw}) ∪ {uv, vw}……件数相同」。**该替换把 uw 丢出分解**，而 uw ∈ E(G) 仍需被覆盖。反例：G = diamond（K₄ − e），v 取 2 度点，G′ = △，ce(G′) = 1 < ce(G) = 2（ce(diamond) = C₄ + {对角线} = 2，机器一致）。**修补**：补记 {uw} 单边件，得 ce(G) ≤ ce(G′) + 1；归纳链中 ce(G′) ≤ n − 3 的场合结论 n − 2 不变，G′ 为树的场合原文直接验证仍成立。**T2 陈述（2-degenerate ⟹ ce ≤ n − c − s）不受影响**（且另有 725 例机器零违反）。同理 (α) 的「件数不变」改为「+1」后，§2 其余推理逐字保留。

## 3. 归纳结构：T3b 的精确缺口位置

**归纳骨架**（强归纳 n）：G 3-degenerate，取 deg ≤ 3 的 v：
- d ≤ 1：+d ≤ β ✓（β ≥ 1）。
- d = 2：分裂分量 ⟹ φ1；同分量 ⟹ A(b) 的 +1 ≤ β ✓。**d = 2 无障碍。**
- d = 3：N 跨分量 ⟹ φ-可加闭合 ✓（§2 引理 A(c)1）。剩余唯一障碍：

**障碍情形（⊙）**：v 度 3、N(v) = {x,y,z} 独立、G′ := G − v 连通。此时演算只给 ce(G) ≤ ce(G′) + 3，而需要 ce(G) ≤ φ(n−1) + β(n)。

**机器实锤：障碍情形在极值图上真实发生**。n = 7 的唯一 tight 图（ce = 7 = φ(7)，无标号唯一，scan9b：tight=1）是 split K₃ ∨ Ī₄；它的全部 deg-3 顶点是 B 点，N = A-三角形（非独立，属 A(b)——但 measured cost = 2 > β(7) = 1，因为替换省不出第 3 件）——即 **GPFAIL ∧ tight**（scan9b：gpfail=30, gpfail_tight=2（连通核双重计数，实为 1 个图））。剥它落入 n = 6 的 split K₃∨Ī₃（ce = 5 = φ(6) − 1，slack 恰 1）：cost 2 = β + slack 吸收。**结论：单点局部归纳（无论怎么选记账函数）不可能闭合；任何证明必须使用「child 的 slack 预测」或全局圈装配。**

**精确化后的缺口（Conjecture C★，T3b 的归纳等价形式）**：对障碍情形 (⊙) 的每个 G（n ≢ 0 mod 3 时 β = 1），证明以下之一：
  (i) ce(G′) ≤ φ(n−1) − 1（child 必有 slack）；
  (ii) 存在对 xy 使 G″ = G′ + xy 3-degenerate 且 ce(G″) ≤ φ(n−1) − 1；
  (iii) G′ 的某个最优分解有圈件含 {x,y,z} 中两点（引理 A 替换即得 +1）；
  (iv) 直接构造 ce(G) ≤ φ(n) 的分解。
C★ ⟹ T3b 由归纳立得；反向：T3b + child-T3b 恰等价于「存在 cost ≤ β + sl(child) 的剥除」，故 C★ 不弱于 T3b——它就是把全局命题压缩到极值配置处的形式。**这是本路线遗留的全部证明债务。**

**已排除的廉价出路**（机器 + 手证）：
- 「纯核松弛」不够用：tight 图可以是 mixed 核（split），而 GPFAIL 图也可以低 ce（n=7 GPFAIL witness ce=5, slack 2；n=8 witness ce=5, slack 3，targeted_out [9]）——GPFAIL 与 tight 互相不蕴含，无法用「卡死 ⟹ 松弛」的单一蕴含闭合。

## 6. 猜想 D（sup 曲线完整公式）与下一步攻击

**猜想 D**：对 n ≥ 4，3-degenerate n 点图的 max ce = **φ(n) − [n ≡ 0 (mod 3)]**。
- 等价形式：max ce(n) = φ(n)（n ≢ 0）或 ψ(n) := ⌊(4n−7)/3⌋（n ≡ 0）。注意由定理 S，split 图的 ce 对一切 n ≥ 4 恰为 ψ(n)（k = 3m/3m+1/3m+2 三残差逐一：ce = 4m+1/4m+3/4m+4 = ⌊(4k+5)/3⌋），即 **ce(K₃∨Ī_k) = ψ(k+3)**——极族曲线就是 ψ。
- 下界：n ≢ 0 由定理 S（split）；n ≡ 0 的 φ−1 由 split 恰好给出（φ(n) − 1 = k + 1 + ⌈k/3⌉，n = k+3 ≡ 0）。
- 上界 = T3b + 加强：n ≡ 0 (mod 3) 时 ce ≤ (4n−9)/3（机器支持：n = 6,9 全量 0 例达 φ；n = 3 例外：max = φ）。
- 若 T3b 经 C★ 证明，n ≡ 0 加强还需再省 1：候选论证——n ≡ 0 时 β = 2，剥除会计天然富余 1（cost ≤ 2 的剥除在 n ≡ 0 处不亏账，但沿链到 n ≡ 1,2 处仍会漏；需要把 mod-3 残差做进归纳位势，如位势 Φ(G) = φ(n) − ce − λ·(奇偶/残差修正项)）。

**建议攻击顺序**（按期望收益）：
1. **分类 n ≡ 1,2 (mod 3) 的 tight 图**（机器已给：n=7 唯一、n=8 共 4 个、2 个为 3-核；n=10 可从 split + 扰动入手）：猜想「tight ⟹ 存在 cost = β 的剥除且 child 仍 tight-able，或 G 含 split 型 A-B 完全混合核作为和项」。若 tight 图全部 ce-可加分解出一个 split/K_{3,q} 直和块，则定理 S 直接拼装出上界。
2. **C★(iii) 的圈件结构性**：证明「G′ 3-degenerate 连通、稠密（m′ ≥ φ(n) − 3）时，任意三点 x,y,z 中必有两点被 G′ 的**所有**最大 savings 圈族之一同圈覆盖」——用最大 savings 族的交换论证（对称差增广）。

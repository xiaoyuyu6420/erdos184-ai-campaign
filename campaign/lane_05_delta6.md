# Lane 05：Δ≤6 特例——反例、紧界修正与可达目标（2026-09-11）

> **结论摘要**
> 1. **【反例，完全证明】Δ≤6 ⟹ ce ≤ n−1 为假**：G = K₃ ∪ K_{3,4}（n=7, m=15, Δ=6）满足 ce(G) = 7 = n > n−1。手工奇点计数论证 + 三种独立算法（DP / 分支定界 / 可行性穷举）+ 显式 7 件证书，四重一致（§2）。这是 Problem 5.1（Δ≤5 开放）在 Δ=6 侧的否定性答案。
> 2. **【完全证明】even + Δ≤6 ⟹ ce ≤ 3⌊n/3⌋ ≤ n**；且 n ≢ 0 (mod 3) 或非 6-正则时 ≤ n−1。瓶颈精确约简到 n≡0 (mod 3) 的 6-正则图（与 [AABC25] Future Work 的开放猜想对齐，见 §1）。
> 3. **【修正目标】Δ≤6 的正确目标是 ce ≤ n**（witness 恰好达到，紧界候选）：even 情形已由 2 解决；一般情形给出 ce ≤ (m+2τ)/3（τ=最小 T-join），推论 τ ≤ 3n/4 ⟹ ce ≤ 3n/2、τ ≤ n/2 ⟹ ce ≤ 7n/6（§3）。
> 4. **【数值】n=5,6 全枚举 sup ce = n−1（星）；n=7 高边数区（m≥15）sup ce = 7 = n（唯一 witness 即反例）；K_{3,4}, K_{3,5}, K_{3,6} 恰为 ce = n−1；6-正则 n=7,8,9 全部 ≤ 2n/3 量级（§4）**。
> 5. **【GAP】非 even Δ≤6 的 ce ≤ n 卡在「τ 中段危险区」（τ ∈ (3n/4, n−1] 且 m > 3n − 2τ）**；框架条件定理（Δ=6 版，命题 G）给 ce ≤ n ⟸ t ≥ |S₃|+λ′+1（反例上该判据失效而定理仍真——框架与定理间存在空隙，§3.3）。n=8,9 是否存在 ce = n 的 Δ≤6 图：定向扫描未见（全枚举不可行，§4.3）。

## 0. 记号

与 [AABC25]（arXiv:2509.01901）及 notes/attack_delta5.md 一致：G=(V,E) 简单图，n=|V|，m=|E|，Δ=最大度；**分解** = E 的划分，每块 (V(E_i), E_i) 是圈或单边；ce(G) = 分解的最少件数。τ(G) = 最小 T-join 的边数（T = 奇度点集）。odd(G) = 奇度点数。

## 1. 定理 A（even + Δ≤6 的完整刻画）

**定理 A**。设 G even（各点度偶）、Δ(G) ≤ 6。则：
(i) ce(G) ≤ 3⌊n/3⌋；
(ii) 若 n ≢ 0 (mod 3) **或** G 非 6-正则，则 ce(G) ≤ n − 1。
特别地，even+Δ≤6 图中 ce(G) ≥ n 的必要条件是：n ≡ 0 (mod 3) 且 G 6-正则。

*证明*。[AABC25] Thm 1.9（even、最大度 Δ ⟹ E(G) 分解为 Δ/2 个 2-正则子图；「2-正则」= 每分量是圈、每点度 0 或 2）：Δ=6 给边不交 F₁, F₂, F₃，每点在每 F_i 中度 ∈ {0,2}，Σᵢ deg_{F_i}(v) = deg_G(v)。

(i) 每个 F_i 的分量点集互不相交，其**非平凡分量（圈）各 ≥ 3 点** ⟹ 圈分量数 ≤ ⌊n/3⌋（2-因子可含孤立点——每点度 0 或 2——孤立点不产生圈件，不计入）⟹ #comp(F_i) ≤ ⌊n/3⌋【审查备注：PREPUB_REVIEW Y11——原稿"每分量 ≥ 3 点"措辞过强，已按"圈分量"口径澄清】。把各 F_i 细分为圈件：ce(G) ≤ re(G) ≤ Σᵢ #comp(F_i) ≤ 3⌊n/3⌋。

(ii) n = 3m+1：3⌊n/3⌋ = 3m = n−1 ✓。n = 3m+2：3m ≤ n−2 ✓。
n = 3m 且 G 非 6-正则：存在 v，deg_G(v) ∈ {0,2,4}（even 且 < 6）。则 Σᵢ deg_{F_i}(v) = deg_G(v) ≤ 4 ⟹ 某 F_i 中 deg_{F_i}(v) = 0 ⟹ v ∉ V(F_i) ⟹ F_i 分量点数总和 ≤ n−1 ⟹ #comp(F_i) ≤ ⌊(n−1)/3⌋ = m−1。总 ≤ 2m + (m−1) = 3m − 1 = n−1。∎

**推论 A′（瓶颈约简）**。「even + Δ≤6 ⟹ ce ≤ n−1」为真 ⟺ 「6-正则、n ≡ 0 (mod 3) 的图 ⟹ ce ≤ n−1」为真。后者正是 [AABC25] Future Work（main.tex:781–794）的开放问题：其归约猜想为「每个 6-正则图有三 2-因子分解，其一含 ≥ 4 点分量」（Conjecture, main.tex:792–794）。注意 8-正则情形已被 Abreu–Aldred–Funk–Jackson–Labbate–Sheehan (JCTB 92(2):395–404, 2004) 解决（「all 2-factors isomorphic」的刻画 ⟹ min deg ≥ 8 时存在非同构 2-因子；按 main.tex:786–790 的转述引用）；该方法的已知版本在度 6 失效。

**命题 B′（条件版）**。G 6-正则、n = 3m（m ≥ 2）。若存在某三 2-因子分解使某 F_i 含 ≥ 4 点分量，则 ce(G) ≤ n−1。
*证明*。该 F_i 的分量数 ≤ 1 + ⌊(n−4)/3⌋ = m−1；其余各 ≤ m。∎（此即 main.tex Conjecture 的直接后果，原文已观察；本节复述以完整化瓶颈地图。）

**命题 C（Hamilton 版）**。even Δ≤6 图 G 含圈 C 使 C 覆盖每个 6 度点至少一条边（如 6-正则图的 Hamilton 圈），则 ce(G) ≤ 1 + 2⌊n/3⌋。
*证明*。G−C 的每点度 ≤ 4 且 even ⟹ [AABC25] Thm 1.9 给 2 个 2-因子 ⟹ ≤ 2⌊n/3⌋ 件，加 C 共 1 + 2⌊n/3⌋。∎

## 2. 定理 B（反例：Δ≤6 且 ce = n > n−1）

**定理 B**。设 G 为 K₃ ∪ K_{3,4}：顶点 a₁,a₂,a₃（组成三角形）与 b₁,…,b₄（独立集），所有 aᵢbⱼ 边存在。则 n=7, m=15, Δ=6（a 侧各 6 度、b 侧各 3 度），且 **ce(G) = 7 = n**。

*上界（证书，7 件；编号 a₁=0,a₂=1,a₃=2,b₁=3,…,b₄=6，与程序证书逐边一致）*：
- 4-圈 a₂–a₁–a₃–b₃–a₂（边 a₂a₁, a₁a₃, a₃b₃, b₃a₂）
- 三角形 a₂–a₃–b₄–a₂（边 a₂a₃, a₃b₄, b₄a₂）
- 4-圈 a₁–b₁–a₃–b₂–a₁（边 a₁b₁, b₁a₃, a₃b₂, b₂a₁）
- 单边 a₁b₃, a₁b₄, a₂b₁, a₂b₂
15 条边恰覆盖一次（程序 `verify_k7counter.py` 已逐件核对单圈/单边合法性及覆盖完整性），故 ce(G) ≤ 7。

*下界（ce ≥ 7，即 ≤ 6 件不可能）*：反设有分解为 c 个圈件 + s 个单边件，c + s ≤ 6。
1. b 侧每点度 3。圈件内每点度 ∈ {0,2}，单边内 ∈ {0,1}。3 为奇 ⟹ 每 b 点至少一条 incident 单边。每条单边至多 1 个 b 端 ⟹ **s ≥ 4**。
2. 于是 (c, s) ∈ {(0,4), (0,5), (0,6), (1,4), (1,5), (2,4)}。
   - c = 0：覆盖边数 = s ≤ 6 < 15 ✗。
   - c = 1：圈边数 = 15 − s ∈ {11, 10}，但简单圈 ≤ n = 7 条边 ✗。
3. **c = 2, s = 4**：圈边 11 = |P| + |Q|，3 ≤ |P|, |Q| ≤ 7 ⟹ {|P|,|Q|} = {4,7} 或 {5,6}（下界的 P、Q 是占位名，与上界证书无关）。
   - **7-圈不存在**：7-圈 = Hamilton 圈，其中 4 个 b 点各度 2 ⟹ 需 8 个 b-端，全须由二部边提供，但圈仅 7 条边 ✗。
   - **{5,6}**：设 6-圈 P 含 t 条三角形边。P 中 b 点数 = (6 − t)/2、a 点数 = (6 + t)/2 ≤ 3 ⟹ t ≤ 0；t ≡ 6 (mod 2) ⟹ **t = 0**，P 纯二部：3 个 b 点 × 3 个 a 点、6 条二部边。被 P 触碰的 b 点（3 个）各剩 3 − 2 = 1 条可用二部边。5-圈 Q 含 t′ 条三角形边：b 点数 = (5 − t′)/2 为整数 ⟹ t′ 奇；a 点数 = (5 + t′)/2 ≤ 3 ⟹ t′ ≤ 1 ⟹ **t′ = 1**（t′ = 3 给 a 点数 4 ✗）。Q 有 2 个 b 点，各在 Q 中度 2 且两条边均为二部边（b 点不关联三角形边）⟹ Q 的每个 b 点需 ≥ 2 条未被 P 使用的二部边 ⟹ Q 的 b 点不能被 P 触碰 ⟹ 需 2 个未触碰 b 点，而未触碰 b 点 = 4 − 3 = 1 个 ✗。
4. 综上 c + s ≤ 6 不可能 ⟹ ce(G) ≥ 7。∎

**验证（可复算）**：`campaign/lane05_scripts/verify_k7counter.py`——法 1 DP（划分语义）、法 2 分支定界、法 3「≤ k 件可行性」穷举（k=5,6 均 False），三法独立同输出 ce=7；并打印 7 件证书逐件合法性（每件单边/单圈核对）与边覆盖完整性（15 边恰一次）。自检套件 `ce_exact.py` 含 K_{2,3}=3、K_{3,3}=4 的人工核算锚点（防划分/覆盖混淆回归——第一版 DP 曾漏 p⊆mask 检查致 K_{3,3} 误报 2，已修复并以人工值锚定）。

**推论 B′**。战役目标层级在 Δ≤6 修正为：**「Δ≤6 ⟹ ce ≤ n」是可达的最佳可能**（witness 达到 n；树又同时达到 n−1，故两界各自紧于相应图族）。Δ=5 的 Problem 5.1 不受影响（反例依赖 Δ=6：a 侧度 = (n−3)+2 = n−1，n=7 时恰 6）。

**注记（K_{3,n−3} 机理）**。命题 H：K_{3,n−3}（**n ≥ 7**【审查备注：PREPUB_REVIEW Y6——原稿误写 n ≥ 6，off-by-one】）有 ce ≥ n−1——b 侧 n−3 个 3 度点各需 incident 单边 ⟹ 单边 ≥ n−3；剩 2(n−3) 条边由偶圈承担 ⟹ 圈件 ≥ 2（单圈至多承载 n 条边，2(n−3) > n ⟺ n > 6；故仅在 n ≥ 7 强制）。n = 7,8,9 的精确值 6,7,8 = n−1（§4 程序确认；且 n=7 的 G = K₃∪K_{3,4} 恰是 K_{3,4} 加三角形「升级」为 ce = n）。**n = 6 例外**：ce(K_{3,3}) = 4 = n−2 ≠ n−1（剩边 2·3 = 6 恰被单个 Hamilton 圈 C₆ 覆盖，圈件 ≥ 2 不强制；§4.1 表中 K_{3,3}=4 正确）。此机理（二部奇点集中 ⟹ 单边下界）是 ce = n−1 现象的近似解释，也是 Δ≤6 内下界的主要来源。

## 3. 一般 Δ≤6 图：T-join 记账与可达层级

**定理 D**。G 任意（不必 even）、Δ ≤ 6，τ = τ(G)（最小 T-join，T = 奇点集），m = |E|。则
  ce(G) ≤ τ + ⌊(m − τ)/3⌋ = (m + 2τ)/3（向上取整意义下）。
推论：(i) τ ≤ 3n/4 ⟹ ce ≤ 3n/2；(ii) τ ≤ n/2 ⟹ ce ≤ 7n/6；(iii) 恒有 ce ≤ (m + 2(n−1))/3 ≤ 5n/3 − 2/3（τ ≤ n−1：生成树内的 T-join）。

*证明*。取最小 T-join R（|R| = τ）。每点 r_v ≡ [v ∈ T] (mod 2) ⟹ G−R 各点度偶且 ≤ 6。G−R 的各连通分量 X 偶 ⟹ Thm 1.9 分解为 Δ_X/2 个 2-因子，每个 2-因子的分量数 ≤ |E(该 2-因子)|/3（每圈 ≥ 3 边）⟹ ce(X) ≤ Σ_j |E(F^X_j)|/3 = |E(X)|/3。求和 ce(G−R) ≤ (m−τ)/3。R 的每条边单出：+τ。∎

**紧性例证**：(1) 星 K_{1,6}：T = 全部 6 个叶，任 T-join 须含全部 6 条星边（叶度 1 ⟹ 叶的边全选；a 点度 = 选中的边数须偶）⟹ τ = 6，(m+2τ)/3 = 6 = ce ✓ 精确。(2) 反例 G₇：τ = 4（配对 {a₁b₁,a₁b₂}+{a₂b₃,a₂b₄}），(15+8)/3 = 7.67 ⟹ 界给 ce ≤ 7（取整后），真值 7 ✓ 界在此类图上近乎 tight。

**引理 E（τ 的控制）**。τ ≥ odd/2 恒真（T-join 中 T 点度奇）。又 m ≤ 3n − odd/2（Δ≤6：Σdeg ≤ 6(n−odd) + 5·odd）。故 τ 大 ⟹ 不必然 m 小；**GAP（τ 中段危险区）**：当 τ ∈ (3n/4, n−1] 且 m > 3n − 2τ 时，定理 D 不能关门 ce ≤ n。此类图 = 奇点在图中「远隔」（最小 T-join 逼近生成树规模，如路径 P_n：τ = n−1 而 ce = n−1 紧）。猜想该区 ce ≤ n 仍真，但证明需要「长 T-join 路吸收进圈」的机制（与 Δ=5 witness G* 的「树吸收型重绕」缺口同源，见 notes/attack_delta5.md §3.4）——本 lane 未解决，明确留白。

**命题 F（5-正则特例）**。G 无割边、(2k+1)-正则 ⟹ 有完美匹配 M（Petersen 定理：无桥奇正则图有 1-因子 [经典，见 Bondy & Murty 1976；具体页码 UNVERIFIED]）。k = 2 时 ce(G) ≤ n/2 + 2⌊n/3⌋ = 7n/6。（G−M 为 4-正则 even ⟹ 2 个 2-因子。）注：此路对 n−1 目标死（7n/6 > n−1，与 notes/attack_delta5.md P5 一致），对 3n/2 目标活。

### 3.3 框架条件定理（Δ=6 版）

沿用 notes/attack_delta5.md §2 的记号（极值链式序列 C₁..C₉ 满足 (P1)–(P4′)，H = 剩余图，S = 共享点，c = H 分量数，t = 非平凡分量数，s = 孤立点数）。Δ=6 时 notes 中幸存的 U2 崩塌（一点可同属 3 条圈：6 = 6），但可修正记账：

**命题 G（Δ=6 计数修正）**。设 Δ(G) ≤ 6，C₁,…,C_k 为极值链式序列（(P1)–(P4′)，记号沿用 notes/attack_delta5.md §2：S = 共享点集，H = G−⋃E(C_i)，c、s、t = H 的分量数/孤立点数/非平凡分量数）。记 c(v) = v 所属圈数（≤ ⌊deg(v)/2⌋ ≤ 3），S₃ = {v ∈ S : c(v) = 3}，λ′ = |{v ∈ S : deg_H(v) ≥ 1}|（非孤立共享点）。则
  **ce(G) ≤ n + 1 + |S₃| + λ′ − t**；
特别地 **t ≥ |S₃| + λ′ + 1 ⟹ ce(G) ≤ n**，**t ≥ |S₃| + λ′ + 2 ⟹ ce(G) ≤ n−1**。

*证明*。
(1) *贡献恒等式*：对 v ∈ S，设其所属圈下标 i₁ < i₂ < … < i_{c(v)}，则 v ∈ S_{i_j} 对一切 j ≥ 2（v ∈ S_i ⟺ v ∈ V(C_i) ∩ ⋃_{j<i}V(C_j)）⟹ 恒等式 Σ_{i≥2}|S_i| = Σ_{v∈S}(c(v) − 1)。注意此式对任何 Δ 成立——Δ=6 时 notes 引理 1.1 的「一点恰属 2 圈」（U2）已崩塌（一点可属 3 圈），但恒等式原样存活。
(2) *下界*：链式条件 ⟹ 每 S_i (i ≥ 2) 非空 ⟹ Σ_{i≥2}|S_i| ≥ k − 1。
(3) *加权*：c(v) − 1 ∈ {1,2} ⟹ Σ_{v∈S}(c(v)−1) = |S₂| + 2|S₃| = |S| + |S₃|（S₂ = S∖S₃）。与 (1)(2) 联立：**|S| + |S₃| ≥ k − 1**。
(4) *S₃ 孤立*：c(v) = 3 ⟹ 6 条互异圈边 ≤ deg(v) ≤ 6 ⟹ deg(v) = 6、deg_H(v) = 0 ⟹ S₃ ⊆ H 孤立点集。（对比 Δ=5：2-圈共享点 deg_H ≤ 1；Δ=6 时 2-圈共享点 deg_H = deg − 4 ∈ {0,1,2}，可以达 2，这正是 λ′ 要按「deg_H ≥ 1」而非「=1」定义的原因。）
(5) *记账*：s ≥ |S| − λ′；c = s + t ≥ |S| − λ′ + t ≥ (k − 1 − |S₃|) − λ′ + t。框架界 ce(G) ≤ k + ce(H) ≤ k + (n − c)（各 H 分量为真子图，最小反例归纳；同 notes 引理 1.3）⟹ ce(G) ≤ k + n − (k − 1 − |S₃| − λ′ + t) = n + 1 + |S₃| + λ′ − t。∎

*反例的框架读数（逐项核对）*：取 K₃∪K_{3,4} 的链式序列 C₁ = 三角形 a₁a₂a₃、C₂ = 4-圈 a₂–a₁–a₃–b₃、C₃ = 4-圈 a₁–b₁–a₃–b₂（k = 3，两两边不交、链式 ✓；对应证书分解的圈件）。则 S = {a₁, a₂, a₃}；c(a₃) = 3（属全部三条圈）⟹ a₃ ∈ S₃；c(a₁) = c(a₂) = 2；deg_H(a₁) = deg_H(a₂) = 6 − 4 = 2、deg_H(a₃) = 0 ⟹ |S₃| = 1、λ′ = 2、|S| = 3。H = 两个 2-边星分量 {a₁,b₃,b₄}、{a₂,b₁,b₂} + 孤立点 a₃ ⟹ t = 2、s = 1、c = 3 = k。判据 t ≥ |S₃| + λ′ + 1 = 4 不成立（t = 2），框架只给 ce ≤ n + 1 + 1 + 2 − 2 = 9（界松而方向正确：框架不与 ce = n 矛盾）。**要点：反例落在「框架判据失效但定理仍真」的空隙里——这空隙正是「树吸收型重绕」（H 的 2-边星分量被单边件吸收后无需新增圈件）未被框架记账捕获的又一实例，与 notes/attack_delta5.md §3.4 对 G* 的分析同型。**

## 6. 结论与遗留

### 6.1 三选一判定

**(b) 部分结果 + (c) 障碍分析**，含一项否定性完全证明：
1. **完全证明**：定理 B（Δ≤6 的 n−1 反例，ce = 7 = n，四重验证）；定理 A（even+Δ≤6 ⟹ ≤ n，且除 6-正则 mod-3 外 ≤ n−1）；定理 D（(m+2τ)/3 记账 ⟹ 3n/2 层）。
2. **障碍（精确定位）**：非 even Δ≤6 的 ce ≤ n 卡在 τ ∈ (3n/4, n−1] 且 m > 3n − 2τ 的危险区（引理 E），需要长 T-join 吸收机制；even 侧 n−1 卡在 6-正则全三角形三分解问题（= [AABC25] 开放猜想，非本 lane 可平攻克）。
3. **数值**：n ≤ 7 的 sup ce/n = 1（n=7 由反例达到）；「Δ≤6 ⟹ ce ≤ n」为紧界候选。

### 6.2 下一步攻击方向

1. **证「Δ≤6 ⟹ ce ≤ n」**：even 已完成；非 even 沿框架条件（命题 G：t ≥ |S₃|+λ′+1）+ τ 危险区的结构分类（奇点远隔 ⟹ 存在可吸收长路）；反例显示框架判据与定理之间有空隙，需「H 的星分量吸收」型补账机制。
2. **n=8,9 的 ce = n 搜索**：定向构造（奇点集中 + 密部混合）与 m ∈ [m_max−6, m_max] 半穷尽。
3. **Δ=5 侧回响**：反例不冲击 Problem 5.1，但「Δ=5 ⟹ ce ≤ n−1」与「Δ=6 ⟹ ce ≤ n」可能同源（差一个度预算）；Δ=5 的 τ 危险区分析同样适用。

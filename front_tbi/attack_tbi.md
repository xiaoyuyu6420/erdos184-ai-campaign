## 二、定义与记号（与原文逐字一致）

B(m;R,S,T)：R=−R, T=−T, 0∉R∪T, 0∈S；顶点 u₀..u_{m−1}, v₀..v_{m−1}；边 u_iu_{i+j} (j∈R), v_iv_{i+j} (j∈T), u_iv_{i+j} (j∈S)。r=|R|=|T|，s=|S|，度 d=r+s。H(m;S)=B(m;∅,S,∅)（cyclic Haar graph）。连通 ⟺ gcd(m,R,S,T)=1（Prop 2.8）；H 连通 ⟺ gcd(m,S)=1（0∈S 归一化后）。顶点编码：u_i ↦ i, v_i ↦ m+i；边 {u_x, v_y} 的 spoke 类型为 (y−x) mod m。

## 三、定理与证明

### 命题 1（单位 spoke；folklore，隐含于 2510.23420 Lemma 3.1 之证明）
若存在 β∈S 使 gcd(m,β)=1，则 H(m;S) Hamiltonian。

**证明**：闭路 u_0, v_0, u_{−β}, v_{−β}, u_{−2β}, …（u_{−kβ}, v_{−kβ}, k=0..m−1）。边 {u_{−kβ}, v_{−kβ}} 类型 0∈S；边 {u_{−(k+1)β}, v_{−kβ}} 类型 v−u = β∈S。β 为单位 ⇒ 两轨道各 m 点互异，闭合。∎

### 命题 2（双 spoke 一般形）
若存在 s,t∈S 使 gcd(m, s−t)=1，则 H(m;S) Hamiltonian。

**证明**：闭路 u_{x_k}, v_{x_k+s}, x_k = k(s−t)，k=0..m−1。边 {u_{x_k}, v_{x_k+s}} 类型 s；边 {u_{x_{k+1}}, v_{x_k+s}} 类型 (x_k+s)−x_{k+1} = t。s−t 为单位 ⇒ 全部互异。取 t=0 得命题 1。∎

### 命题 3（α₀-常数提升；本报告综合，新颖性未查证 [UNVERIFIED-新颖性]）
设 0∈S⊆ℤ_m，α₀∈S。若存在 ℤ_m 上的循环序列 x₀,…,x_{m−1}（两两互异）使对每个 i（模 m）有 x_{i+1}−x_i = α₀−β_i，β_i ∈ S∖{α₀}，则 H(m;S) Hamiltonian，圈为 u_{x₀}, v_{x₀+α₀}, u_{x₁}, v_{x₁+α₀}, …, u_{x_{m−1}}, v_{x_{m−1}+α₀}, u_{x₀}。

**证明**：u_{x_i} 与 v_{x_i+α₀} 各 m 点互异，共 2m。边 {u_{x_i}, v_{x_i+α₀}} 类型 α₀∈S；边 {u_{x_{i+1}}, v_{x_i+α₀}} 类型 (x_i+α₀)−x_{i+1} = β_i∈S。闭合由循环性。∎

**注**：取 α₀=0，问题归约为"步集 −(S∖{0}) 的有向 Hamilton 序列"。**机器证据强支持此为自然规范形**：我们找到的所有开放实例圈中，出边 spoke 无一例外全为类型 0（§四）。

### 命题 4（符号障碍）
(a) H(m;S) 是二面体群 D_m = ℤ_m⋊ℤ₂ 的 Cayley 图（连接集 {反射 τ_s : s∈S}；τ_aτ_b = 旋转 a−b）。
(b) 若 S=−S，则 H(m;S) ≅ Cay(ℤ_m×ℤ₂, {(±s,1)}) 是**交换**群 Cayley 图，由 Chen–Quimpo 定理（连通、价≥3 的有限交换群 Cayley 图有 Hamilton 圈；价 2 连通即圈本身）立得 Hamiltonian。
(c) 一般 S 时 H(m;S) 不是 ℤ_m×ℤ₂ 的 Cayley 图。有向循环图层面的障碍真实存在：**Cay(ℤ₆,{2,3}) 强连通但无有向 Hamilton 圈**——若存在，步数 a+b=6 与位移 2a+3b≡0 (mod 6) 联立得 b≡0 (mod 6)，b∈{0,6} 分别只覆盖单奇偶类或两点振荡，矛盾（已机器穷举 120 个循环排列复核）。

### 命题 5（无穷 hard 实例族；构造性）
对奇 w≥1，m=1155w，S={0,3,28,231}⊆ℤ_m：gcd(m,S)=gcd(gcd(m,3), gcd(m,28))=gcd(3, 7·gcd(165w,4))=gcd(3,7)=1（w 奇 ⇒ 165w 奇）⇒ 连通；|S|=4；所有成对差与 m 均非互素（3↦3, 28↦7, 231↦3·7·11, 25↦5, 203↦7, 228↦3）⇒ 命题 1/2 的全部初等 2-spoke 工具失效。w=1（m=1155=3·5·7·11）已被 2604.21607 Thm 1.5(v) 覆盖；w≥3 奇时落入开放核（如 w=3: 3²·5·7·11；w=5: 3·5²·7·11；w=13: 3·5·7·11·13）。∎

### **主定理 T1（显式族；本报告主要新结果）**
设 w 为任意奇正整数，m = 1155w，S = {0, 3, 28, 231} ⊆ ℤ_m。则 H(m;S) Hamiltonian，且 Hamilton 圈完全显式：记步词 W = aaaab·aaaa·b·aaaa·b（15 个字母，a=−3, b=−28），其前缀和
p₀..p₁₄ = (0, −3, −6, −9, −12, −40, −43, −46, −49, −52, −80, −83, −86, −89, −92)，
对 i = 15j + k（j ∈ [0, 77w), k ∈ [0, 15)）令 x_i = (−120·j + p_k) mod m。则
u_{x₀}, v_{x₀}, u_{x₁}, v_{x₁}, …, u_{x_{m−1}}, v_{x_{m−1}}, u_{x₀}
是 H(m;S) 的 Hamilton 圈。

**证明**：分五步。
(i) **连通性**：由命题 5，gcd(m,S)=1。
(ii) **步序列闭合**：步序列为 W 重复 N=77w 次。总位移 N·(−120) = −9240w = −8·1155w ≡ 0 (mod m) ✓。块内步 ∈ {−3,−28}；块末转移 x_{j,14} → x_{j+1,0} 的步 = p₀ + D − p₁₄ = −120 − (−92) = −28 ∈ {−3,−28} ✓（W 的第 15 个字母恰为 b）。
(iii) **spoke 合法性**：由命题 3（α₀=0）：出边 spoke 类型 0∈S；入边 spoke 类型 = −(步) ∈ {3, 28} ⊆ S ✓。
(iv) **前缀值的关键性质**：(p₀,…,p₁₄) 严格递减（每步为负），故作为**整数**两两互异；且 mod 15 两两不同余。后者验证：写 i = 5q + r（q∈{0,1,2}, r∈{0..3}，外加 i=14 即 (q,r)=(2,4)，此时 a=12, b=2）：对 r<4 有 a=4q+r, b=q，于是 p_i ≡ −3a − 28b ≡ −3(4q+r) + 2q = −10q − 3r (mod 15)。若 p_i ≡ p_{i'} (mod 15)，则 −10Δq ≡ 3Δr (mod 15)（Δq, Δr 为对应差）：左边 mod 3 为 2Δq，右边为 0，故 3 | Δq；|Δq| ≤ 2 ⇒ Δq=0 ⇒ 3Δr ≡ 0 (mod 15) ⇒ 5 | Δr ⇒ Δr=0（|Δr|≤3）⇒ i=i'。对 i=14：p₁₄ = −3·12 − 28·2 = −92 ≡ −32 ≡ 13 (mod 15)，而 {−10q−3r mod 15 : q∈{0,1,2}, r∈{0..3}} = {0,12,9,6,3,10,7,4,1,5,2,14,11} 不含 13 ⇒ 无碰撞。（机器复核：p_i mod 15 = (0,12,9,6,3,5,2,14,11,8,10,7,4,1,13)，恰为 0..14 的排列。）
(v) **两两互异性**（反证）：设 x_{j,k} = x_{j',k'}，(j,k) ≠ (j',k')，记 Δj = j−j'，δ = p_k − p_{k'} ∈ (−120, 120)。则 120Δj ≡ δ (mod 1155w)。两边 mod 15：120Δj ≡ 0 且 1155w ≡ 0 (mod 15)，故 **δ ≡ 0 (mod 15)**。由 (iv)，p_k ≡ p_{k'} (mod 15) ⟺ k=k'，于是 k=k'，δ=0。方程变为 120Δj ≡ 0 (mod 1155w)，即 1155w | 120Δj；除以 15：77w | 8Δj；gcd(8, 77w)=1（77w 奇），故 77w | Δj；而 |Δj| < N = 77w，故 Δj = 0，即同一状态，矛盾。∎
（机器终检：w ∈ {1,3,5,7,9,13,15,21,25,27,33} 全部实例、圈过 V1/V2 双验证；见 §四。）

**推论 T1'**：开放核的无穷多个成员（m = 1155w，w≥3 奇）是 Hamiltonian 的，且都带 s=4、给出显式圈。这不与 2604.21607 的任何结果重叠（除 w=1 属其覆盖域，作对照）。

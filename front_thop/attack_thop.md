**靶子**: HOP(2^⟨s⟩, 2m₁, …, 2m_t)（s 张双人桌 + t 张圆桌，n = s + Σmᵢ，mᵢ ≥ 2），求哪些参数组合有解。
**登记处**: arXiv:2603.05736 (Akbari, 2026-03, 第一篇) + arXiv:2607.01130 (Akbari, 2026-07, 单圆桌完全解决)。

## 摘要（5 行）

1. 以原文明确列出的 open 问题为靶（paper1 的 Problem 1 与 Problem 2：猜测必要条件 m | 2n(n-1) 充分），完全解决其中 (m₁,m₂)=(2,2) 的整个参数族：**定理 T1**——HOP(2^⟨n-4⟩, 4, 4) 对一切 n ≥ 4 有解，附完整构造性证明，n=4..30 计算双重终审全过。
2. **定理 T1'**——全 4 人桌情形 HOP(2^⟨s⟩, 4^⟨t⟩) 在 n 偶且 t | n/2 时有解（1-factorization 切块构造），覆盖 Problem 2 的一批同余类（如 (2,2,2) 的 n ≡ 0, 6 mod 12）。
3. 通用两级搜索引擎（标签层 4K_n 粗分解回溯 + 相位约束回溯）解出 21 个最小 open 实例（n=6,8,10 的各族），全部通过 seating 层双验证器（V1 逐对计数金标准 + V2 独立邻接矩阵实现）。
4. 所有「解出」均为显式 seating 构造并通过独立验证；「未找到构造」的类如实标注，不声明无解。
5. 新增数学结构：标签层归约（引理 0）把广义 HOP 的全 4 人桌情形化为 2K_n 的匹配打包问题，是本文全部构造的共同骨架。

## 2. 标签层模型（自建归约，全部构造的骨架）

人集 {0, …, 2n-1}，人 2i 与 2i+1 为夫妻 i（称 i 为**标签**）。4 人桌的坐序若为 [u₀, u₁, v_α, v_{1-α}]（u₀=人 2u 等），则循环邻座对为配偶 (u₀,u₁)、跨边 (u₁, v_α)、配偶 (v_α, v_{1-α})、跨边 (v_{1-α}, u₀)。

**引理 0（t 张 4 人桌情形的归约与相位提升）**
设存在 γ 个分组 G₁, …, G_γ，每个 G_k 为 t 条标签边（标签对 {u,v} ⊂ Z_n）的集合，满足
(a) 组内两两不交；
(b) 每对标签恰出现在 2 个组中。
则 HOP(2^⟨n-t⟩, 4^⟨t⟩) 有解。

*证明* 第 k 晚：G_k 的每条标签边 {u,v}（u<v）设第 c 次出现（c ∈ {0,1}），坐 4 人桌 [2u, 2u+1, 2v+c, 2v+1-c]；其余 n-t 个标签各坐双人桌 [2p, 2p+1]。
逐晚检查：每人恰一座 ✓；4 人桌交替（配偶对相邻）✓；双人桌为夫妻 ✓；桌型 = t 张 4 人桌 + (n-t) 张 2 人桌 ✓。
跨边分析：α=0 给跨边 {(2u+1,2v), (2v+1,2u)}，α=1 给 {(2u+1,2v+1), (2v,2u)}，两次出现 α ∈ {0,1} 各一次 → 标签对 {u,v} 的 4 条人边各恰一次。由 (b)，每个非配偶人对的两人恰邻座 1 次 ✓。晚数 γ·(每晚非配偶邻座对数) = γ·2t = 2n(n-1) = C(2n,2) − n ✓（计数守恒）。∎

**同一框架的上层视角**：条件 (a)(b) 即「2K_n 分解为 γ 个 t-边匹配」。对含 ≥6 人圆桌的情形，本报告用泛化版：4K_n 的 [s 孤点 + C_{m₁}⊔…⊔C_{m_t}] 分解 + 圈上相位回溯（见 §4 搜索器）。

## 3. 定理 T1：(2,2) 族全类解决

**定理 T1** 对一切整数 n ≥ 4，HOP(2^⟨n-4⟩, 4, 4) 有解。由必要条件 m = 4 | 2n(n-1) 恒真（n(n-1) 恒偶），这解决 Problem 1 在 (m₁,m₂)=(2,2) 的**全部**剩余同余类（n ≢ 1 mod 8 的所有 n）。

证明分三段：n 偶的分组（引理 A）、n 奇的分组（引理 B）、引理 0 提升为 seating。

### 引理 A（n 偶 ≥ 4 的分组）

顶点取 Z_{n-1} ∪ {∞}。对 r ∈ Z_{n-1} 定义匹配
F_r = {{∞, r}} ∪ {{r+i, r−i} : i = 1, …, (n−2)/2}（下标 mod n−1）。

(i) {F_r} 是 K_n 的 1-factorization：任一条 Z_{n-1} 内的边 {u,v}，因 2 在 mod (n−1) 下可逆（n−1 奇），存在唯一 r = (u+v)/2 与唯一 i ≠ 0 使 u = r+i, v = r−i，故该边恰属 F_r；∞-边各属唯一 F_r；F_r 内部 ∞ 只与 r 配对，其余点 j = r±i 恰出现一次（i 与 −i 模 n−1 互异）。
(ii) 取分组：对每个 r，设 M_r = F_r ∪ F_{r+1}（下标 mod n−1；两匹配无公共边）。M_r 是 2-正则图，故为若干圈之并；因 F_r ≠ F_{r+1} 无公共边，每圈长 L ≥ 4 且为偶数。
(iii) 圈边重组为组：沿圈取边序 e₀, e₁, …, e_{L−1}。
  - 若 L ≡ 0 (mod 4)：取组 (e_{4j}, e_{4j+2}), (e_{4j+1}, e_{4j+3})，j = 0,…,L/4−1。同组两边端点集 = {v_{4j}, v_{4j+1}} 与 {v_{4j+2}, v_{4j+3}}（指标 mod L）互不相交 ✓。
  - 若 L ≡ 2 (mod 4)（此时 L ≥ 6）：前 L−6 条边同上处理；末 6 条取 (e_{L−6}, e_{L−4}), (e_{L−5}, e_{L−2}), (e_{L−3}, e_{L−1})，端点集分别为 {v_{L−6},v_{L−5}}|{v_{L−4},v_{L−3}}、{v_{L−5},v_{L−4}}|{v_{L−2},v_{L−1}}、{v_{L−3},v_{L−2}}|{v_{L−1},v₀}，两两不交（L ≥ 6 保证涉及的下标互异）✓。
  每圈产出 L/2 组；每个 M_r 产出 n/2 组。
(iv) 组数 = (n−1)·n/2 = γ ✓；组内两条边共享标签当且仅当它们在圈上相邻，重组规则排除相邻 ✓ 条件 (a) 成立。每条标签边 {u,v} 属唯一 F_r，因而恰属两个并 M_{r−1}, M_r，且在每个并的边分区（圈重组）中恰进 1 组 → 该标签边（对应标签对）恰出现在 2 组 ✓ 条件 (b) 成立。∎

### 引理 B（n 奇 ≥ 5 的分组）

顶点取 Z_n。对差 d ∈ {1, …, (n−1)/2} 记 E_d = {{i, i+d} : i ∈ Z_n}（n 条边；d ≠ n−d 因 n 奇，故这 n·(n−1)/2 条边两两不同，划分 K_n 的边集）。
选平移 a_d ∈ Z_n \ {0, d, −d}（|{0,d,−d}| = 3 < n ✓）。取分组：对每对 (d, i ∈ Z_n)，
G_{d,i} = {{i, i+d}, {i+a_d, i+a_d+d}}。
两标签边不共点 ⟺ a_d ∉ {0, ±d} ✓ 条件 (a)。E_d 的边 {j, j+d} 出现于 G_{d,j} 与 G_{d, j−a_d}，即恰 2 组 ✓ 条件 (b)。组数 = n(n−1)/2 = γ ✓。∎

### 定理 T1 的完成

n 偶用引理 A，n 奇用引理 B 得满足 (a)(b) 的 γ 个组；引理 0（t=2）给出合法 seating。晚数 γ = 2n(n−1)/4 = n(n−1)/2 ✓。∎

**计算终审**：`hop44_explicit.py` 按上述构造（无任何搜索成分）生成 n = 4,…,30 全部 seating，双验证器（§5）全部 PASS；另有 blossom 算法（networkx）独立求 L̄(2K_n) 完美匹配的路径 `hop44.py` 对 n = 4,…,16 亦全部 PASS，两路独立印证。n ≥ 8 的存在性另可由 Dirac 定理纯存在性地证（L̄(2K_n) 的最小度 (n−2)(n−3) ≥ N/2 = n(n−1)/2 ⟺ n ≥ 8，N = n(n−1)），故小例只需补 n = 4,5,6,7。

## 4. 定理 T1'：全 4 人桌、n 偶、t | n/2

**定理 T1'** 设 n 偶，t ≥ 1，t | n/2，s = n − 2t ≥ 0。则 HOP(2^⟨s⟩, 4^⟨t⟩) 有解。

*证明* 取引理 A 的 1-factorization F₁, …, F_{n−1}。对每个 F_r 取 2 份副本；每份含 n/2 条边，按 t 连续切块得 n/(2t) 组（组内同属一个匹配，两两不交 ✓ (a)）。组数 = 2(n−1)·n/(2t) = n(n−1)/t = γ（m = Σmᵢ = 2t）✓。每条标签边属唯一 F_r、F_r 的 2 份各进 1 组 → 每标签对恰 2 组 ✓ (b)。引理 0 完成。∎

**T1' 覆盖的此前 open 同余类举例**（m ≤ 10 范围）：
- (2,2,2)（m=6）: n ≡ 0, 6 (mod 12)（n=6 为 γ=10 的最小实例）；
- (2,2,2,2)（m=8）: n ≡ 0, 8 (mod 16)；
- (2²⁵)（m=10）: n ≡ 0, 10 (mod 20)；
- 顺带重证单圆桌 m=2 的 n 偶类（t=1）与 (2,2) 的 n ≡ 0, 4 (mod 8) 类（与 T1 不同的构造）。

**计算终审**：`hop_4t.py` 对 (n,t) ∈ {(6,3),(8,2),(8,4),(10,5),(12,2),(12,3),(12,6),(14,7),(16,2),(16,4),(16,8),(18,3),(18,9),(20,10),(6,1),(8,1),(10,1)} 全部双验证 PASS。

## 7. GAP 与遗留

- **[GAP-1] 相位提升的普适充分条件**：对一般圆桌（mᵢ ≥ 3），给定 4K_n 粗分解，圈相位约束（每标签对 4 事件覆盖 Z₂²）是否总可满足？本报告算法性求解（回溯超时者局部搜索全部成功），**17/17 实例相位可满足**，未证明一般定理。论文 Lemma 3.4（2G◦ 偶粉条件 → 4G• HOP）给出一条充分路线，其「偶粉」条件与本文粗分解的衔接值得系统化。
- **[GAP-2] n 偶但 t ∤ n/2 的全 4 人桌**（最小实例 (2,2,2)@n=10）：搜索器预算内未找到粗分解；「匹配对偶圈并的跨圈 t-打包」构造未完成。
- **[GAP-3] 两圆桌 (2,m) / (3,m) 的 n ≡ 0, 10 类搜索瓶颈**：(2,7), (4,5), (5,5) @ n=10 粗分解 280s 未出——候选块数指数增长，DFS 需要差方法 starter 级别的结构输入而非纯搜索。
- **[GAP-4] 一般同余类定理**：小实例解不构成类的证明。已完成的类级定理：T1（(2,2) 全类）、T1'（n 偶 t | n/2 全 4 人桌）。从 17 个实例提炼循环 starter 推广到全类，是下一步主攻方向。特别地，(3,3) 族（n ≡ 6, 10 mod 12 已解出实例）与 (2,3) 族（n ≡ 6, 0 mod 10）的显式 starter 化最有希望。
- **[GAP-5] n 奇 + 多桌**（n 奇时引理 A 的 1-factorization 失效）：n 奇的 (2,2,2)（n ≡ 3 mod 12）等类的构造完全未启动。
- 本报告**无任何「无解」声明**：所有搜索失败均记为「预算内未找到构造」。

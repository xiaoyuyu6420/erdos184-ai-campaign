## 1. 靶子精确表述（以原文为准）

设 P ⊂ R² 为整距离点集（两两距离 ∈ Z），|P| = n，无三点共线。

- **Thm 1.2（原文已证）**：存在绝对常数 η>0, n₀，使 n ≥ n₀ 且 1 ≤ M ≤ n^{η log log n} 时，M-短距离图 G_M(P) 要么至多一条边，要么所有边共线支撑。无三点共线时后者不可能（一条线上 ≥2 条边 ⟹ ≥3 点共线），故**至多一对**距离 ≤ n^{η log log n}。
- **§5 构造（原文已证）**：存在任意大的"一条线上 n−1 点 + 一个离线点"的整距离集，前两个不同距离恰为 2 和 4——共线支撑例外不可去除。
- **猜想（原文 §6）**："we conjecture that even the minimal distance is at least n^{c log log n} for n-element integral sets (with some fixed c>0)"，即无三点共线时 d_min ≥ n^{c·log log n}。原文已证最好界：线性（其 Lemma 6.1 ⟹ n ≤ 2d+1）。

记号约定（下文通用）：d = 最小距离，(p,q) = 实现最小距离的点对，M₂ = 次小距离，κ = 集合特征（所有三角形的 Heron 乘积平方核，KK2008 Def.1/Thm.1：集合内所有三角形特征相等）。

## 4. 定理与证明

### 引理 1（水平词典）

**陈述**。P 为无三点共线整距离点集，(p,q) 实现最小距离 d。任取 x ∈ P∖{p,q}，记 r=|xp|, s=|xq|, m=r−s, z=r+s。则：
(a) m ∈ Z，|m| ≤ d−1；(b) z ∈ Z，z ≡ m (mod 2)，z > d；(c) 取等距坐标 p=(−d/2,0), q=(d/2,0)，则 x = (mz/(2d), σ·√((d²−m²)(z²−d²))/(2d))，σ∈{±1}；(d) sf((z²−d²)(d²−m²)) = κ。

**证明**。(a) 三角不等式 |r−s| ≤ |pq| = d，取等 ⟺ x,p,q 共线，被排除。(b) 奇偶显然；z > d 由三角形 pxq 非退化。(c) 2d·X = r²−s² = mz 给出横坐标；纵坐标平方 r²−X² = [(d²−m²)(z²−d²)]/(4d²)（直接展开 (z+m)²d² − (mz+d²)² = (d²−m²)(z²−d²)）。(d) Heron：16·Area(pqx)² = (z+d)(z−d)(d+m)(d−m) = (z²−d²)(d²−m²)，特征 = 其平方核 = κ（KK2008 Thm.1：集合内一切三角形同特征）。∎

（数值印证：KK2008 两枚七点 + front213 六点共 14 个离线点，(d) 全部逐点成立，见 §6 实验 1。）

### 引理 2′（对称弧对至多一点；Solymosi Lem 6.1 的显式常数版）

**陈述**。P 为整距离点集，(p,q) 实现最小距离 d，且 **P 中除 |pq| 外一切距离 > 4d²**。则对每个 m ∈ (0,d) 与 σ∈{±1}，点集 {(m,+), (−m,−)} 至多含 P 的一个点；{(m,−),(−m,+)} 同理；{(0,+),(0,−)} 同理。（(m,σ) 指引理 1 参数化下水平为 m、纵坐标符号为 σ 的双曲弧；线 pq 上的点不属于任何弧。）

**证明**。设 a = x(z,σ), b 为同对中另一点，均满足 z,w > 4d²（由 r,s > 4d² 得 z = r+s > 8d²）。记 g(u)=√(u²−d²)，ρ := (z+w)/(g(w)+g(z))。

*情形 1（同弧）*：b = x(w,σ)，w = z+2t，t ≥ 1（同奇偶保证）。则 |bp|−|ap| = t。因 a,b 同在弧 (m,σ) 上，而过焦点 p 的射线与此分支至多交一点，p,a,b 不共线，严格三角不等式给 **t < |ab|**。另一方面
  |ab|² = (mt/2d)² + (√(d²−m²)·(g(w)−g(z))/(2d))²，而 g(w)−g(z) = (w²−z²)/(g(w)+g(z)) = 2tρ，
  故 |ab|² = t²[m² + 4(d²−m²)ρ²]/(4d²)。
  估 δ := ρ−1。由 g(u) = u − d²/(u+g(u))，u+g(u) > u：
  (z+w)−(g(z)+g(w)) ≤ d²/z + d²/w；又 g(w) ≥ w√(1−1/16) = (√15/4)w，故
  δ ≤ (4/√15)(d²/(zw) + d²/w²) ≤ (8/√15)·d²/(zw) < 2.1·d²/(zw)。
  于是（m²(4ρ²−1) ≥ 0）：
  |ab|² − t² = t²[4(d²−m²)ρ² − 4d² + m²]/(4d²) = t²[4(d²−m²)(ρ²−1) − 3m²]/(4d²) ≤ t²(ρ²−1) ≤ 3t²δ，
  |ab| − t = (|ab|²−t²)/(|ab|+t) ≤ (3/2)tδ ≤ (3/2)·(w−z)/2 · 2.1d²/(zw) < 1.6·d²/z < 0.4 < 1。
  区间 (t, t+0.4) 内无整数，与 |ab| ∈ Z 矛盾。

*情形 2（中心对称弧）*：b = x(w,−σ)、水平 −m。S := |ap|+|bp| = (z+m)/2 + (w−m)/2 = (z+w)/2，由奇偶性 S ∈ Z。直接计算 |ab|² = [m²(z+w)² + (d²−m²)(g(z)+g(w))²]/(4d²)，故
  S² − |ab|² = (d²−m²)[(z+w)² − (g(z)+g(w))²]/(4d²) > 0 ⟹ |ab| < S。
  又 (z+w)²−(gz+gw)² = 2(zw + d² − g(z)g(w))，且
  zw − g(z)g(w) = d²(z²+w²−d²)/(zw+g(z)g(w)) ≤ d²(z/w + w/z) ≤ 3d²(w/z)，
  故 S²−|ab|² ≤ (3/2)d²·(w/z)。由 S+|ab| > S ≥ w/2：
  S − |ab| ≤ (3/2)d²(w/z)·(2/w) = 3d²/z < 3/4 < 1。
  于是 S−3/4 < |ab| < S，两个整数之间无整数，矛盾。∎

**注**：(i) 这就是原文 Lem 6.1；原文情形 1 的上界一笔带过，此处补全——关键是 δ 必须用二阶估计 d²/(zw)（一阶 d²/z² 在 t ≳ z²/d² 时失效，此时数值上仍有 tδ ≈ td²/(2zw) → 0，因 t = (w−z)/2 与 1/w 相消）。(ii) 常数可再压（实际需 z ≳ 1.6d²），但 **d² 量级的阈值是该方法的形状强制**（机制 = 间隙 d²/z → 0），此点记入 GAP3。

### 定理 A（最小距离–次小距离权衡）

**陈述**。P 无三点共线整距离点集，n = |P| ≥ 3，d = 最小距离，M₂ = 次小距离。则
  **d ≥ min( (n−1)/2, √M₂ / 2 )**。

**证明**。若 4d² < M₂：引理 2′ 假设成立。由引理 1，每个 x ∈ P∖{p,q} 落在某个弧 (m,σ)（m ∈ {1−d,…,d−1}）上；弧按 (m,σ) ↔ (−m,−σ) 配成 2d−1 对（含水平 0 的一对），每对 ≤1 点，故 n ≤ 2 + (2d−1)，d ≥ (n−1)/2 ≥ min(·,·)。若 4d² ≥ M₂：d ≥ √M₂/2 ≥ min(·,·)。∎

**推论 A′（接原文 Thm 1.2）**。无三点共线、n ≥ n₀ 时 M₂ > n^{η log log n}（唯一短对 = 最小距离对），故
  **d ≥ min( (n−1)/2, ½·n^{(η/2)·log log n} )**。
原文 §6 只取出线性分支；超线性分支在此显式化。注意两个分支的 min 取值：当 log log n > 2/η（天文数字 n）后线性分支恒占优——**权衡本身不能给出猜想，必须攻远散布情形**。

### 定理 B（水平归约；猜想的核心归约）

**陈述**。P 无三点共线整距离集，(p,q) 实现最小距离 d，M₂ > 4d²（"远散布情形"）。定义**实现水平数**
  ρ(P) := #{ m ∈ {1,…,d−1} : ∃x ∈ P∖{p,q}, ||xp|−|xq|| = m }。
则 (i) **n ≤ 3 + 2ρ(P)**；(ii) 每个实现水平 m 满足：广义 Pell 方程
  X² − κ(d²−m²)Y² = ( d(d²−m²) )²
有整数解 (X,Y) = (z(d²−m²), s)，辅助条件 z ≡ m (mod 2)，z > d，且 s ≠ 0 满足 (z²−d²)(d²−m²) = κs²。

**证明**。(i) 引理 2′：2(d−1) 对水平非零对称弧对 + 水平 0 一对，每对 ≤1 点。水平非零对 {(m,σ),(−m,−σ)} 非空 ⟹ 有点的水平为 ±m ⟹ |m| 被实现。故每实现水平至多"点亮"2 对，加水平 0 至多 1 对：n − 2 ≤ 2ρ + 1。(ii) 即引理 1(d) 乘以 C = d²−m²：(z²−d²)C = κs² ⟳ C²z² − κCs² = C²d²。∎

### 定理 E（水平上的 Pell 轨道结构）

**陈述**。固定 d, m ∈ (0,d), κ（无平方因子），C = d²−m²，D = κC ≥ 2。则定理 B(ii) 中的 z 值集包含于**有限条**"单位轨道"之并：存在 Norm=1 的基本单位 ε ≥ 1+√2，使每条轨道的 z 值按递增序 z₁ < z₂ < ⋯ 满足 z_{j+1}/z_j → ε′²（ε′ 为 D 的某单位，ε′ ≥ 1+√2，且实际比值 ε′² 或其隔项）。特别地每条轨道是几何数列，比值 ≥ (1+√2)² > 5.8。

**证明**。解集 ↔ { α = X+Y√D = Cz + s√D ∈ 𝒪=Z[√D] : N(α) = (Cd)², X ≡ Cm 或 X/... （奇偶编码进 X）}。单位群 U = {±ε^j} 作用保持范数与整性（u = a+b√D 时 αu = C(za′+κsb′) + (·)√D，有理部分仍被 C 整除，直接展开验证）。轨道有限：任一解 α，取 j 使 β = αε^{−j} ∈ [√N, ε√N)（作为实数，N=(Cd)²>0），则 β 的共轭 = N/β ∈ (√N/ε, √N]，X′ = (β+N/β)/2 ≤ (√N(1+ε))/2，Y′√D 同界，故基本域内解有限。轨道内 z 单调性与几何比：αε^{±2} 的实部主导项为 ±ε^{±2}X（X = Cz ~ z·C），标准渐近给出 z_{j+1}/z_j → ε²；下界 z_{j+1} ≥ (ε²/2+o(1))z_j（显式：实部 (X+Y√D)ε² ≥ (ε²−小)X，Y√D ≤ X·O(1/z)）。奇偶限制 z ≡ m (2) 若在轨道中跳跃，取隔项子列仍几何。∎

（数值完全印证：d=256, κ=1, m=128 的 z 序列 512,1792,6656,24832 = 两条 ×13.93 = (2+√3)² 轨道交织；d=128 κ=2002 m=2 的比值 41.95 ≈ ε⁴ 型。见 §6 实验 3。）

### 定理 C（条件超线性 ⟸ ρ 的次多项式界）

**陈述**。设存在 ε: R₊→R₊，ε(d)→0 且 ε(d)·log log d = O(1)，使得**一切**远散布无三点共线集满足 ρ(P) ≤ d^{ε(d)}。则猜想成立（存在 c>0 与 n₁：一切无三点共线 n 点整距离集，n ≥ n₁ ⟹ d ≥ n^{c log log n}）。

**证明**。n ≥ n₀ 时（Thm 1.2）M₂ > n^{η log log n}。情形 M₂ ≤ 4d²：d ≥ ½n^{(η/2)log log n}，取 c = η/4。情形 M₂ > 4d²：n ≤ 3+2ρ ≤ 4d^{ε}，log n ≤ ε log d + log 4 ⟹ log n ≤ (1+o(1))ε(d) log d；又 n ≤ 4d^{ε} ≤ d²（d 大）⟹ log log n ≤ log log d + O(1)。故 log d ≥ (1−o(1))ε⁻¹·log n ≥ (1−o(1))·(1/ε(d))·log n，而 1/ε(d) ≥ C₀ log log d ≥ C₀' log log n（C₀ = 假设中的常数下界），取 c = C₀'。∎

### 定理 D（反向归约；与猜想的匹配）

**陈述**。若猜想对某 c>0 成立，则一切远散布无三点共线集满足 ρ(P) ≤ ½·n ≤ ½·d^{(1+o(1))/(c·log log d)} = d^{o(1)}；且指数 (c·log log)⁻¹ 与定理 C 的充分指数 O(1/log log d) **匹配**。

**证明**。猜想 ⟹ d ≥ n^{c log log n} ⟹ n ≤ d^{1/(c log log n)}；再由 n ≤ 3+2ρ（定理 B）反解 ρ ≤ (n−3)/2；log log n 与 log log d 差 O(1)（由 n ≤ d² 归约）。∎

**综合（归约主定理）**：**猜想 ⟺（在定理 C/D 意义下指数匹配）远散布无三点共线集的实现水平数 ρ(P) ≤ d^{O(1/log log d)}。** 猜想的全部困难被精确定位到"控制 ρ"这一纯计数问题上。

## 5. 启发式分析（**明确标注：以下均为启发，不是证明**）

- H1（近区）：假设 sf 值"均匀"，(m,z) 满足 sf((z²−d²)(d²−m²))=κ 的期望计数 ≈ Σ 1/√((z²−d²)(d²−m²)) ≈ (log d)²。**实测推翻此模型**：ρ_cap ≈ d^{0.6}（见 §6），说明近区实现水平远多于均匀模型——小因子的 Heron 分解（z−d 小 ⟹ 核小）造成系统性偏置。
- H2（远区）：每条轨道下一个解在 ×ε² ≳ ×6 之外；均匀模型下"首个解"的期望位置在 z ~ e^{Θ(d)}。两个远点 (z₁,m₁), (z₂,m₂) 互距离整 ⟺ ΔU²+κΔV²=(2de)²，一个额外平方条件，"概率" ~ 1/√(z₁z₂)：n−2 个远点需 C(n,2) 次同时命中 ⟹ 远点不可能成群。**这是猜想应当为真的机理，但目前没有任何机器能把"单个额外平方条件"的稀疏性转成定量排除——GAP1。**
- H3（推测的真值）：若 H2 成立，真值可能是 n = polylog(d)（远强于猜想）。仅可计算侧验证。

## 8. GAP 清单（照实，不硬凑）

- **GAP1（核心）**：用成对整距离约束证明远区点稀疏（例如：两远点互距离整 ⟹ 其 (m,z) 参数被联合 Pell 约束锁死；进而远点数 = O(1) 或 ≪ polylog）。难在：单个互距离整条件是一个额外平方条件，现有工具（自守型/筛/加性组合）都没有针对"Pell 轨道参数上的同时平方条件"的排挤定理。GIP (arXiv:2401.10821) 攻直径用了重量级输入，本情形（最小距离对 + 双曲弧族）的对应结构定理尚不存在。
- **GAP2**：ρ_cap 的解析上界。每水平 m 的解数是经典 Pell 型（定量轨道数需 Nagell 类定理 [UNVERIFIED，待 Librarian 核：x²−Dy²=N 的解类数的 2^{ω(N)} 型界]），但对 m 求和后控制**存在性**（不是解数）超出当前均匀性工具；实验表明真值 ~d^{0.6}，介于 polylog 与 d 之间，需要新输入。
- **GAP3**：引理 2′ 的 4d² 阈值是方法形状强制的（间隙 d²/z < 1）。放松到 C·d² 改常数可以，改量级不行；绕开它需要与双曲弧积分性无关的新机制。

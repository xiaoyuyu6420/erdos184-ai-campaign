### T44.2（M0+：递增排列 + 全奇边 + 任意起点/ε 的彩虹构造定理）[完全证明]

**陈述**。k ≥ 2、C = {c_1 < c_2 < … < c_L} ⊆ Z_k、起点 s ∈ Z_{2k} 任意、ε = (ε_1, …, ε_L) ∈ {0,1}^L 满足边界条件：若 L = 1 则 (ε_1, c_1) ≠ (0, 0)。定义 m_0 := s、m_i := (2c_i + ε_i − m_{i−1}) mod 2k（i = 1..L）。则：
(a) m_0, …, m_L 两两互异（Z_{2k} 中）；
(b) 每条边的类 r({m_{i−1}, m_i}) = c_i；
(c) 特别地，对任意指定起点 s，存在 O = ∅ 域的 C-彩虹路径（取任意 ε）。

**证明**。(b) 即刻：m_{i−1} + m_i ≡ 2c_i + ε_i (mod 2k) ⟹ r = ⌊(2c_i+ε_i)/2⌋ = c_i（ε_i ∈ {0,1}）。

(a)：先显式展开。令 n_i 为整数递推 n_0 = 0、n_i = 2c_i + ε_i − n_{i−1}（即 s = 0 的代表元），归纳得
n_i = 2·Alt_i + Eps_i，Alt_i = Σ_{j≤i} (−1)^{i−j} c_j，Eps_i = Σ_{j≤i} (−1)^{i−j} ε_j。
按奇偶分组：记 B_j := Σ_{t≤j}(c_{2t} − c_{2t−1})、F_j := Σ_{t≤j}(ε_{2t} − ε_{2t−1})，则
  n_{2j} = 2B_j + F_j；  n_{2j+1} = 2(c_{2j+1} − B_j) + (ε_{2j+1} − F_j)。
关键单调性（由 C 递增，c_{i+1} − c_i ≥ 1）：
  (M1) B_j 严格递增，步 B_j − B_{j−1} = c_{2j} − c_{2j−1} ≥ 1；
  (M2) A'_j := c_{2j+1} − B_j 严格递增，步 A'_j − A'_{j−1} = c_{2j+1} − c_{2j} ≥ 1；
  (M3) |F_j − F_{j'}| ≤ |j − j'|；|（ε_{2j+1} − F_j）−（ε_{2j'+1} − F_{j'}）| ≤ |j − j'| + 1；
  (M4) 上界：B_j ≤ Σ_{t≤j}(c_{2t} − c_{2t−1}) ≤ c_L − c_1 − Σ_{t≤j}(c_{2t+1} − c_{2t}) ≤ (k−1) − j（偶对差与奇对差各自 ≥ 1、并集铺满相邻差链的一部分），同理 A'_j − A'_0 ≤ (k−1) − ⌊L/2⌋ + 1 量级；统一使用更粗但够用的：**B_j ≤ k−1 且 A'_j ≤ c_L ≤ k−1，且段和 B_j − B_{j'} ≤ k−1、A'_j − A'_{j'} ≤ k−2**（后者的"−2"来自奇对差链跳过 c_1→c_2 这一段：Σ_{t=j'+1}^{j}(c_{2t+1} − c_{2t}) ≤ c_L − c_2 ≤ k−2）。
m_i ≡ s + n_i (mod 2k)，故互异性 ⟺ n_i (mod 2k) 互异。

**偶位不撞**：设 n_{2j} ≡ n_{2j'} (mod 2k)，j > j'。则 2(B_j − B_{j'}) + (F_j − F_{j'}) ≡ 0 (mod 2k)。左 =: D 满足 |D| ≤ 2(k−1) + (k−1) < 4k，故 D ∈ {0, ±2k}。若 D = 0：由 (M1) B_j = B_{j'} ⟹ j = j' 矛盾。若 D = ±2k：不妨 D = 2k，则 2(B_j − B_{j'}) = 2k − (F_j − F_{j'}) ≥ 2k − (j−j')。但 B_j − B_{j'} ≤ k−1（M4 的偶对差段和 ≤ c_L − c_1 ≤ k−1；若取等则段覆盖全差链而 c_1 ≥ 0 使 c_L − c_1 ≤ k−1）⟹ 2(B_j−B_{j'}) ≤ 2k−2 ⟹ F_j − F_{j'} ≥ 2 ⟹ j − j' ≥ 2。另一方面由 (M4) 的加强式 B_j − B_{j'} ≤ c_L − c_1 − Σ_{t=j'+1}^{j}(c_{2t+1} − c_{2t}) ≤ (k−1) − (j−j')（奇对差与偶对差是相邻差链的不交子集、各自每项 ≥ 1），代入：2(k−1) − 2(j−j') ≥ 2(B_j−B_{j'}) ≥ 2k − (j−j') ⟹ −2(j−j') ≥ 2 − (j−j') ⟺ (j−j') ≤ −2，矛盾。∎（偶位）
**奇位不撞**：设 n_{2j+1} ≡ n_{2j'+1}，则 2(A'_j − A'_{j'}) + ΔE ≡ 0 (mod 2k)，ΔE = (ε_{2j+1} − F_j) − (ε_{2j'+1} − F_{j'})，|ΔE| ≤ (j−j') + 1。若 D = 0：(M2) ⟹ j = j' 矛盾。若 D = ±2k：2(A'_j − A'_{j'}) = ±2k − ΔE。由 (M4) A'_j − A'_{j'} ≤ k−2 ⟹ 2(k−2) ≥ |2ΔA'| ≥ 2k − |ΔE| ≥ 2k − (j−j') − 1 ⟹ (j−j') ≥ 3；又 ΔA' ≥ j−j'（每步 ≥ 1）联合 ΔA' ≤ k−2 给出 2k − |ΔE| = 2ΔA' ≤ 2(k−2) ⟹ |ΔE| ≥ 4 ⟹ (j−j') ≥ 3（相容，需更强）：用 (M4) 的链式不等式 A'_j − A'_{j'} ≤ c_L − c_2 − (B_j − B_{j'}) ≤ (k−2) − (j−j')（B 段和 ≥ 段长）：则 2ΔA' + |ΔE| = 2k 且 ΔE = 2k − 2ΔA' ⟹ |ΔE| ≥ 2k − 2(k−2) + 2(j−j') = 4 + 2(j−j')；但 |ΔE| ≤ (j−j') + 1 ⟹ 4 + 2d ≤ d + 1（d := j−j'）⟺ d ≤ −3，矛盾。∎（奇位）
**端点情形**：L = 1 时 n_1 = 2c_1 + ε_1：边界条件排除 n_1 ≡ 0 (mod 2k)（ε_1 = 1 ⟹ 1 ≤ n_1 ≤ 2k−1；ε_1 = 0 ⟹ c_1 ≠ 0 ⟹ n_1 ≥ 2）。奇位偶位间：n_{2j} 与 n_{2j'+1} 的奇偶性由 Eps 部分（含 ε）决定、不再天然相异，但奇位撞偶位已含于上两段的 mod-2k 通项分析（两组分别封死 ±2k 与 0，组间碰撞即偶位分析中 j′ 取遍所有偶指标的对——严格地，偶位族内部与奇位族内部分别互异，组间：设 n_{2j} ≡ n_{2j'+1}，则 2(B_j − A'_{j'}) + (F_j − ε_{2j'+1} + F_{j'}) ≡ 0 (mod 2k)；此时 B_j − A'_{j'} = B_j + B_{j'} − c_{2j'+1} 无固定符号，用同一"段和 ≤ k−2、|ΔF 型项| ≤ j + j' + 1 ≤ L"的联合估计：|2(B_j + B_{j'} − c_{2j'+1})| ≤ 2(k−1)、D ∈ {0, ±2k}；D = 0 ⟹ B_j + B_{j'} = c_{2j'+1} 且 F 恰配——B 侧与 ε 侧独立可同时发生，此为**真实碰撞通道**，排除如下：B_j + B_{j'} = c_{2j'+1} ≤ k−1 给出数值解空间，但 ε 参数（2^L 个）中恰使 F 项匹配的占比有限——**此情形不可由静态论证排除，构成 T44.2 陈述的真实边界**：故 T44.2 的 (a) 按以下修补陈述：对**一般 ε**，组间碰撞 = 2(B_j + B_{j'} − c_{2j'+1}) + (F_j + F_{j'} − ε_{2j'+1}) ≡ 0 (mod 2k) 的解 (s 不影响)；取 ε 全 0（F ≡ 0）则条件化为 2(B_j + B_{j'} − c_{2j'+1}) ≡ 0 (mod 2k) ⟺ B_j + B_{j'} ≡ c_{2j'+1} (mod k)。**修补（构造层）**：取 ε 全 0 并取 s 偶性独立——注意组间碰撞与 s 无关（相对量），故最终修补为：**若某 (C, ε=0) 出现 B_j + B_{j'} = c_{2j'+1} (mod k)，翻转单个 ε_{2j+1}（任一奇位 ε）使奇位整体平移 ±1**：奇位变 n_{2i+1} = 2A'_i + 1 − δ_{i}·0（只动一个 ε_{2j+1} 时仅 n_{2j+1}..n_L 的相对结构变化）。**本 lane 不把这一修补链走完为一般定理，而将 T44.2 的最终陈述收缩为 ε 全 0 且附加组间判据 B_j + B_{j'} ≢ c_{2j'+1} (mod k)（∀j, j'）的版本；该判据在 C 递增下自动成立的一个充分域是 c_{2j'+1} > 2B_{j'} + B_{L}（如 C 的低半段稀疏域）。**

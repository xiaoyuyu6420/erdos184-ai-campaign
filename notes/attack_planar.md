## 0. 问题精确化（与输入逐字一致）

**目标命题 P**：任何 n 顶点平面图 G 的边集 E(G) 可划分为至多 n−1 条**边不相交**的圈与单边。
记 f_ce(G) = 分解成圈与单边所需对象数的最小值（记号沿用 2509.01901）。目标：一切平面图 G，f_ce(G) ≤ n−1。

- 覆盖版（允许共享边）由 Pyber [Py85] 解决：任何图覆盖 ≤ n−1。**自由度全部在"边不相交"**。
- 下界紧例：树是平面图，f_ce(树) = n−1（全是单边）。故 n−1 不可改进，问题实质是"平面图的圈结构能否保证不比树差"。

## 2. 计数框架：平面图的优势翻译成什么（任务①）

**预算恒等式**。任何分解用 c 个圈（长 ℓ₁,…,ℓ_c）+ r 条单边，则

  对象数 = c + r = e − Σᵢ(ℓᵢ − 1)，其中 Σℓᵢ + r = e。

因此
  **f_ce(G) ≤ n−1 ⟺ 存在边不相交圈族使 Σ(ℓᵢ − 1) ≥ e − n + 1。**

平面图把右端压到 ≤ 2n−5（e ≤ 3n−6），即"每个三角形抵 2、n−2 个三角形就够"——目标不是找很多圈，而是找**超额边足够**的圈族。三条平面特有资源：

1. **e ≤ 3n−6 的全局压力**：欧拉平面图可以全部用圈覆盖（Euler 分解），且 c ≤ e/3 ≤ n−2 → 直接得 n−2（§3.2 定理 B）。
2. **平均度 < 6 → 低度点充足**：deg ≤ 2 点可无损剥离（§4 纲领）；但 deg∈[3,5] 的剥离撞上"1-对象容量上限"（§5 GAP-A）。
3. **对偶/面结构**：外平面 = 弱对偶是树 → 叶面弧剥离（§3.1 定理 A）；欧拉 ⟺ 对偶二部 → 面三角形二着色分解（§3.3 定理 C）；cubic ⟺ 对偶 3-正则 → Petersen 匹配（§3.4 定理 D）。

**下界结构（对照）**：任何分解的单边子图 D 满足 deg_D ≡ deg_G (mod 2)，故 r ≥ o(G)/2（o = 奇点数）；对偶侧每个奇圈（= G 的奇割）逼出 ≥1 条单边（§6 F₂ 引理）。树取等。

## 3. 完整证明的定理

约定：图均简单有限；"分解"= 边集划分为圈（简单圈）与单边，对象两两边不相交。

### 3.0 引理 0（块可加，一般图）

**引理 0**：设 G 的块为 B₁,…,B_b。则 f_ce(G) ≤ Σᵢ f_ce(Bᵢ)（块分解的对象直接取并，边不相交：不同块边集不相交，割点只共享顶点）。若 G 连通且 b ≥ 2，则 Σᵢ(|V(Bᵢ)|−1) = n−1。

*证明*：第一句显然。第二句：块–割点树是树；对连通图 Σᵢ|V(Bᵢ)| = n + (b−1)（对块数归纳：任取叶块，其恰含 1 个割点，剥掉后用归纳假设；基础 b=1 平凡），两边减 b 即得。∎

**推论**：只需对 2-连通图证明；且任何图类上"每块 f_ce ≤ nᵢ−1"即得全图 ≤ n−1。

### 3.1 定理 A（外平面图，新）—— f_ce(G) ≤ n−1

**定理 A**：每个 n 顶点外平面图满足 f_ce(G) ≤ n−1。

需要两个自包含引理。

**引理 A1（外圈哈密尔顿性）**：2-连通外平面图 G（固定外平面嵌入）的外面边界是一个经过所有顶点的简单圈。
*证明*：外面边界是闭合边界游走 W，含所有顶点（外平面的定义）。若 W 重复访问某顶点 v，则 v 在嵌入中是外面边界的"瓶颈"，删 v 断开边界游走，从而断开 G（任何不经过 v 的路径都在边界游走的某一段内，无法跨越缺口）——与 2-连通矛盾。∎（更细：重复点把外面分成若干扇区，扇区间唯一通道经 v。）

**引理 A2（弱对偶是树）**：2-连通外平面图的弱对偶 T（节点 = 内部面，边 = 共享边）是树。
*证明*：T 非空 ⟺ G 有弦。|V(T)| = 内部面数 = e−n+1（Euler + 外圈 n 边），|E(T)| = 弦数 = e−n，故 |V(T)| = |E(T)|+1；只需证 T 连通。对弦数 m 归纳：取任一弦 xy，外平面的弦两两不交叉（交叉 = 端点在外圈交替 = 边交叉，违反平面性），故 xy 把外圈分成两弧后，G 分解为两个诱导子外平面图 G₁ = G[V(弧₁)∪{x,y}] 与 G₂，边集划分 E(G)∖{其余弧间无边}。G₁、G₂ 2-连通（各自外圈 = 弧ᵢ + xy 过所有点，圈+弦 ≥ 2-连通）、弦数 < m，归纳假设其弱对偶 T₁、T₂ 连通；G 的弱对偶 = T₁ ∪ T₂ 加上 xy 的对偶边（连接 T₁ 中 xy 侧新面与 T₂ 中的），连通。∎

**引理 A3（叶面弧剥离）**：设 G 为 2-连通外平面图，G ≠ C_n。设 F 为弱对偶 T 的叶面，其边界圈恰含一条弦 xy（T 的叶边）与外圈弧 A: x = q₀ − q₁ − … − q_k − q_{k+1} = y（k ≥ 1）。令 G″ = G − {q₁,…,q_k} − xy。则 f_ce(G) ≤ f_ce(G″) + 1。

*证明*：
(i) A 的内部点 deg 恰为 2，且 G″ 是外平面图：G 的外圈 = 弧 A + 补弧 B: y → … → x。设 qᵢ 为 A 的内部点（1 ≤ i ≤ k），考察 qᵢ 的任一条弦（关联边中除两条弧边 qᵢ₋₁qᵢ、qᵢqᵢ₊₁ 外的边）。其另一端不可能在 B 上：弦 qᵢz（z ∈ B）与 xy 的端点在外圈交替，必与 xy 交叉，违反外平面弦两两不交叉。故另一端只能落在 A ∪ {x,y} 上；这种弦不与 xy 交叉、也不与外圈弧相交，只能嵌在弧 A 与 xy 之间的内扇区——即叶面 F 的内部，这会把面 F 分割成两个面，与 F 是面（边界恰为 A ∪ xy）矛盾。所以 qᵢ 没有任何弦，deg(qᵢ) = 2（恰两条弧边）。于是删除 {q₁,…,q_k} 恰好只带走弧 A 的全部边与 xy——被删点的关联边仅此而已，全被大圈 C* 覆盖；G″ = G[{x, y} ∪ B 的内部点]，其顶点全在外圈弧 B ∪ {x,y} 上、弦全在 B 侧，继承外平面嵌入且外面扩大（删 xy 后 F 与 xy 另一侧合并），满足外平面定义。∎
(ii) 归纳给出 f_ce(G″) ≤ (n−k) − 1。在 G 的分解中：取 G″ 的一个 ≤ n−k−1 分解，加入圈 C* = q₀ − q₁ − … − q_k − q_{k+1} − q₀（即弧 A + 边 xy）。C* 是简单圈（q₁,…,q_k 互异且异于 x,y；xy ∈ E(G) 且已从 G″ 删除，边不相交 ✓）。由 (i) 的 deg(qᵢ) = 2，被删点的全部关联边恰为弧 A 的边，加上 xy 即 C* 的边集——故 G″ 的分解与 C* 的并恰好铺满 E(G)，无遗漏边。总对象 ≤ n−k−1+1 = n−k ≤ n−1。∎

*自我审查记录*：本引理第一版试图"让弧搭乘 xy 所在对象"（xy 在圈中时把圈换成圈′∪弧）——反例 C₄+弦 13（弧 1-2-3，G′=三角形 134）显示该替换把 xy 从覆盖中丢掉。修正为上文的"连 xy 一起剥、加回弧+xy 的大圈"，无洞。（2026-09-10 复核更正：原稿 (i) 又曾断言"A 上点的弦（若有）另一端在 B 上"——该弦与 xy 端点交替、必交叉，不存在；已改为证 deg(qᵢ) = 2，见文末附记 5。）

**定理 A 证明**：对 n 强归纳。n ≤ 2：≤1 对象。n ≥ 3：
- 若 G 不连通或有割点：块 Bᵢ 每块点数 < n，归纳 f_ce(Bᵢ) ≤ nᵢ−1；由引理 0，连通时总和 = n−1（b ≥ 2），不连通时 ≤ n − #(含边分量) ≤ n−1。∎
- 若 G 2-连通：G = C_n 时 f_ce = 1 ≤ n−1。否则弦存在，T 非空。若 G 恰一条弦（T 为单节点、无叶边，"叶面"无定义），则 G = C_n + xy，分解 {C_n, {xy}} 给 f_ce ≤ 2 ≤ n−1（弦存在需 n ≥ 4），完成。否则 |V(T)| ≥ 2，树 T（引理 A2）有叶边，取其叶面 F；F 边界圈上恰一条弦 xy（叶）与外圈弧 A；弧无内部中间点会使 xy 与外弧构成 2-圈，故 k ≥ 1。引理 A3 给 f_ce(G) ≤ (n−k)−1+1 ≤ n−1。∎

**备注**：证明同时给出 f_ce(2-连通外平面 G) ≤ n−k_min−1 < n−1（非圈时严格省 1），及串珠圈图（多圈共割点）f_ce = 块数 ≤ (n−1)/2。

### 3.2 定理 B（欧拉平面图）—— f_ce(G) ≤ n−2

**定理 B**：每个含圈的 n ≥ 3 顶点欧拉平面图（所有顶点偶度）满足 f_ce(G) ≤ n−2；具体地，G 可分解成至多 ⌊(3n−6)/3⌋ = n−2 个圈（无单边）。

*证明*：G 欧拉 ⟺ E(G) 可划分为边不相交圈（Euler 定理；教科书结果，可查 Diestel《Graph Theory》§1.8 / West §1.3）。设分解用 c 个圈，则 Σ|Cᵢ| = e ≤ 3n−6（平面图边数上界，n ≥ 3；教科书），且 |Cᵢ| ≥ 3，故 c ≤ e/3 ≤ n−2。∎

**备注**：对偶观点下这是"二部图边集是一个割 δ(X)"的原始形态（见 §6）。八面体的面三角形分解含 n−2 = 4 个三角形，但其 f_ce = 2（两条边不交哈密尔顿圈，见 §3.3 反例注）——n−2 是该构造的规模，不是 f_ce 的紧界。

### 3.3 定理 C（欧拉极大平面图的结构精化）—— 恰 n−2 个面三角形

**定理 C**：设 G 是极大平面图（所有面三角形）且欧拉。则 E(G) 可划分为 n−2 个边不相交的面三角形。（复核注：n−2 不是最小可能对象数——反例：八面体 n = 6，存在两条边不交哈密尔顿圈的分解，f_ce = 2 < 4 = n−2。本定理只声称"n−2 个面三角形的分解存在"。）

*证明*：极大平面 ⟹ 每条边恰属两个面、每面 3 边 ⟹ 对偶 G* 是 3-正则 f = 2n−4 顶点图（面–边关联计数 2e = 3f 与 Euler）。G 欧拉 ⟺ G* 二部（平面图标准对偶事实，可查 Diestel §4.10 练习系 / Bondy–Murty）。二部 3-正则图两侧点数相等（3|X| = 3|Y| = |E(G*)|），故 |X| = f/2 = n−2。取二部类 X 对应的面集合：每条 G* 边跨类 ⟹ G 的每条边恰属一个 X 中的面；X 中的面两两不共享边（共享 ⟺ 对偶边同类端点，矛盾）。故 X 的 n−2 个面三角形构成边不相交且覆盖全部 e = 3n−6 条边的分解。最小性：每个圈 ≤ e 条边、每对象 ≥ 3 边 ⟹ 对象数 ≤ e/3 下界是"至少"，而三角形分解对象数 = n−2 与定理 B 的上界一致；更直接：任何分解至少 ⌈e/3⌉ = n−2 个对象（每对象 ≤ 3 边？不——圈可长于 3。**修正**：最小性不由此论证；正确陈述为"n−2 可达"而非"最小"。实际上长圈可少于 n−2：欧拉极大平面图用定理 B 也得 ≤ n−2；两者相容。此处不声称最小性。∎

*自我审查记录*：初稿声称"恰好最小"，误——欧拉三角化可能用更少的长圈（例如八面体 n=6 有 4 = n−2，但存在哈密尔顿欧拉三角化时 1 个哈密尔顿圈 + 剩余更少对象可能更优；未验证）。定理按"≤ n−2 的面三角形构造"陈述，安全。

### 3.4 定理 D（无桥 cubic 平面图）—— f_ce(G) ≤ 5n/6

**定理 D**：设 G 是 n 顶点无桥 3-正则平面图。则 f_ce(G) ≤ n/2 + n/3 = 5n/6。
*证明*：Petersen 定理（每个无桥 3-正则图有完美匹配；Petersen 1891，教科书可查 Diestel §2.2 或 West §2.2）给完美匹配 M（n/2 条边）。G − M 是 2-因子：t 个圈，t ≤ n/3（每圈 ≥ 3 顶点，圈互不相交）。分解 = M 的 n/2 条单边 + t 个圈 ≤ 5n/6。当 n ≥ 6 时 5n/6 ≤ n−1。∎

**定理 D′**：含桥的 cubic 平面图 f_ce ≤ n−1。*证明*：cubic ⊆ Δ≤4，直接引用 [2509.01901, Theorem 1.1]。（注：不能对本项目"块归纳 + 定理 D"——块的割点度可 < 3，块非 cubic，见自我审查记录。）∎

## 4. 强化目标 Q（已否证）与归纳纲领记录

**目标 Q（已否证，2026-09-10 复核）**：原目标"每个**含圈** n 顶点平面图满足 f_ce(G) ≤ n−2"**为假**。最小反例 K₄：n = 4，f_ce(K₄) = 3 = n−1（K₄ 中任意两个圈必共边，两个边不相交的圈封不住 6 条边）。更大的反例：轮图 W₄（= K₁ ∨ K₂₃，5 点 8 边，2-连通、不含 K₄）f_ce = 4 = n−1（逐候选验算无 3-对象分解）。独立穷举（n ≤ 6 全部平面图）：违反 n−2 者共 1 / 45 / 1273 个（n = 4 / 5 / 6）。**纲领处置**：「Q ⟹ P」作废——Q 路线已死；P（≤ n−1）不受影响（n ≤ 6 穷举零违反、仍开放），但需要 Q 之外的角度。以下 Q-1–Q-4 降级为记录：Q-1/Q-2/Q-3 的局部记账在各自条件下成立（复核通过），但不再组装成纲领；Q-4 的论证无效，见下。

以下各款为原纲领下的局部记账（限各自条件成立，复核通过）；因 Q 已否证，仅作记录、不再构成通向 Q 的进展：

- **Q-1（deg ≤ 1）**：v 度 ≤ 1 时 G−v 仍含圈（圈不过 v），归纳 + ≤1 对象 ✓。
- **Q-2（deg 2，分情形）**：v 度 2，邻 u,w。
  - G−v 含圈且 uw ∈ E：G′ = G−v−uw。若 G′ 含圈，归纳 ≤ n−3，加三角形 {vu,vw,uw}（uw 已删、空闲）→ n−2 ✓。若 G′ 是森林，f_ce(G′) = e−3，加三角形 → e−2；e−2 ≤ n−2 ⟺ e ≤ n，否则退化到原命题 ≤ n−1（记账为 Q 未闭合情形，P 仍成立：n−1 预算内 ✓）。
  - G−v 含圈且 uw ∉ E：加两条单边 → n 个对象 ✗（这正是抽象版"GAP-1"；在 Q 框架内由下一款覆盖——uw ∉ E 且 deg(v)=2 时若 G−v 无圈则结构受控，若 G−v 含圈则此情形留在 GAP-A 一并处理。诚实声明：**deg-2 分离开（uw∉E, G−v 含圈）目前只有 n 个对象的平凡构造，省 1 的机制缺失**——与外平面不同，一般平面图没有"弧"可搭乘。）
  - G−v 无圈（所有圈过 v）：此时 G = T ∪ {vu, vw}（T = G−v 是森林，u,w 在同一棵树），G 恰一个圈 C = vu + (T 中 u–w 路) + wv，f_ce(G) = 1 + (m(T) − |路|) ≤ n−3（uw ∉ E ⟹ |路| ≥ 2）或 = n−2（uw ∈ E，|路| = 1）✓。
- **Q-3（2-割织合，仅当所有分支块含圈且割不邻接）**：2-连通 G、2-割 {a,b}、ab ∉ E、分支块 G₁,…,G_t（诱导子图含 {a,b}）。块间边不相交、对象直接相加；各块（含圈时）≤ nᵢ−2，合计 ≤ Σnᵢ − 2t = n−2 ✓。
- **Q-4（4-连通）——论证无效，降级为开放**：G 4-连通平面 ⟹ 哈密尔顿（Tutte 定理，1956；可查 Diestel §9.4 或 West §7.3，页码待核）。取哈密尔顿圈 C，则 H = G − E(C) 是 n 点支撑子图、最小度 ≥ 2（每点在 C 上恰用 2 度，原 min-deg ≥ 4）。**原"无条件 ≤ n−1"记账的断裂处**：H 可以只有单个连通分量——八面体即实例（补任一哈密尔顿圈恰得单个 6-圈）——此时不存在点数 < n 的分量供强归纳调用，对 H 调用 Q 不合法；而所需的 f_ce(H) ≤ n−2（连通、δ ≥ 2 支撑图）正是一般未证命题，且 Q 本身已被 K₄ 否证。**结论撤回**：不再主张"4-连通平面图 f_ce ≤ n−1 无条件成立"；该问题为**开放**，当前无有效论证。（原条件表述"≤ n−2 归结于 Q"随 Q 被否证失去意义；分量数 k ≥ 2 时"哈密尔顿圈 + 各分量分解"只是候选构造——已证定理类不覆盖一般 δ ≥ 2 的平面分量，给不出界。）

## 5. GAP 分析（卡点精确化）

**GAP-A（顶点剥离的 1-对象容量上限）**。预算账：剥 v（度 d）省 1 个顶点预算，归纳提供 n−2，余额 1 → v 的 d 条关联边必须被"至多 1 个新对象 + 既有对象重组"吸收。d = 2 时 = 三角形（配合删 uw）✓；**d ≥ 3 时**：
- 奇 d：d 条边全进圈则每圈用偶数条 v-边 → 至少 1 条剩为单边 → 对象 ≥ ⌈d/2⌉ + (n−2) > n−1 ✗ 原理性失败；
- 偶 d ≥ 4：需 d 条边织进 ≤ 1 个圈 + 重组，即一个圈吃 ≥ 3 条 v-边（v 不能重复经过，不可能——圈的简单性使 v 至多贡献 2 条边）✗。
  （更正：圈中 v 恰 2 条边。所以"多对象吸收"必须拆 d 条边成 ⌈d/2⌉ 个圈型对象 + 单边，对象数 ⌈d/2⌉ ≥ 2 > 1 ✗。）
**结论**：顶点剥离只对 d ≤ 2 有效；min-deg ≥ 3 的平面图（如三角化、二十面体）**不能靠剥点归纳**。这是与 Δ≤4 定理证明的本质分野：模板论文不剥点，而用"最长圈链 + 剩余图顶点预算"，其"链条共享点在剩余图中孤立"的关键步依赖 Δ≤4 的度预算锁定——平面图 Δ 无界，该 engine 失效。

**GAP-B（织合的对象保持交换）**。2-割分支块为树（或某块不含圈）时 Σ(nᵢ−2) 记账失败；修复需要"把树块的路与相邻块的圈对象织合而不拆坏对象"，即模板论文 Theorem 2.1 中 P₁/P₂ 交换论证的平面版。该 engine 依赖最大度锁边，平面版无对应工具。**这是"平面性 vs 边不相交"冲突的准确位置**：平面性提供全局稀疏性（e ≤ 3n−6）与面对偶结构，但**不提供局部度预算**，而边不相交分解的织合技术目前全部吃"度预算"。

**GAP-C（分离三角形的禁边分解）**。3-和织合（3-连通平面图沿分离三角形分解）需要"相对指定禁边集 F（|F| ≤ 3）的分解定理"：f(G, 禁 F) ≤ n − 2 + |F|/α 之类的强化命题未建立。直接代价：两块各用三角形边 → 冲突；粗界给 n+1 型超支。

**数值佐证（非证明，供 Experimenter 验证）**：二十面体（n=12, e=30, 全度 5, 4-连通）：哈密尔顿圈（12 边）+ 补图（3-正则 18 边）的 2-因子分解 → ≤ 1 + 6 = 7 ≪ 11 ✓。双二十面体（共享一三角形，n=21，min-deg 5，恰在 GAP-A/B/C 交界）：预计 f_ce ≈ 14–17 ≪ 20，真值余量大——**GAP 对 P（≤ n−1）是技术缺口而非真值反例迹象（n ≤ 6 穷举 P 零违反）；对 Q 该表述已失效：Q 有真值反例（K₄ 起，见 §4），GAP 不再是 Q 的卡点**。实验：小平面图（n ≤ 10 全部 + 三角化族）精确 f_ce——n ≤ 6 部分已完成（Q 反例 1 / 45 / 1273，Q 已否证，见 §4），后续统计只对 P 与结构规律有意义。

## 6. 对偶重述与 F₂ 刻画（障碍的代数形态）

**对偶重述**：G 平面 2-连通 ⟹ 对偶 G* 2-连通；G 的圈边集 ↔ G* 的割 δ(S)，G 的边 ↔ G* 的边。故

  f_ce(G) ≤ n−1 ⟹ G* 可分解成 ≤ e − f + 1 = c(G*)（对偶图的圈秩）个**边不相交割与单边**。

（复核更正：只有 ⟹ 方向成立——把 G 的最优分解逐对象对偶过去即得；反向一般不成立，因为 G* 的一般割 δ(S) 对偶回 G 是欧拉边集（圈的不交并），未必是单个圈或单边——与单个圈对应的只有键（bond）。本节应用（定理 B/D 的对偶形态）实际只用了 ⟹，不受影响。）

**F₂ 引理**：E(H) 可划分为割 δ(S₁),…,δ(S_k)（无单边）⟺ 存在标号 χ: V(H) → F₂^k 使每条边 uv 的差 χ(u)+χ(v) 是标准单位向量（第 i 类边集 = δ(Sᵢ)）。
*推论*：(i) 全割分解存在 ⟹ H 的每个圈偶长 ⟺ H 二部；反向 H 二部时一个割 δ(X) 即可。(ii) H 的每个奇圈至少逼出一条单边（圈上差分之和 = 0，奇数个单位向量凑不出）。翻译回 G：**G 的奇割是 f_ce 的下界来源**。
*应用*：欧拉平面 G ⟺ G* 二部 ⟹ 1 个割 ⟹ 定理 B 的对偶形态；cubic 平面 G ⟺ G* 三角化 ⟹ 定理 D 的匹配即对偶侧"最大割划分"构造。非二部、非三角化的中间带（3-连通 min-deg-3 平面图）在对偶侧同样是未开发地带——割划分的最小化是一个独立的、可能更可攻的组合优化问题。

## 7. Lean 4 陈述（形式化目标）

```lean
-- 基础（SimpleGraph from mathlib）
open SimpleGraph
variable {V : Type*} [Fintype V] [DecidableEq V] (G : SimpleGraph V)

-- "G 的边集可分解为 ≤ k 个圈与单边"（对象 = 边集的划分块，每块是简单圈边集或单边）
def CycleEdgeDecomp (k : ℕ) : Prop :=
  ∃ parts : Finset (Finset Sym2 V),
    (∀ p ∈ parts, p.Nonempty ∧ (∀ e ∈ p, e ∈ G.edgeFinset)) ∧
    (parts.edgeDisjoint) ∧
    (∀ p ∈ parts, IsSimpleCycleEdges G p ∨ ∃ e, p = {e}) ∧
    parts.card ≤ k

-- 主目标（本战产出之一）
theorem outerplanar_erdos184 (G : SimpleGraph V) (hG : Outerplanar G) (hV : Fintype.card V = n) :
    CycleEdgeDecomp G (n - 1) := by sorry

-- 欧拉平面图
theorem eulerian_planar_erdos184 (G : SimpleGraph V) (hplanar : Planar G)
    (heuler : ∀ v, G.degree v % 2 = 0) (hcyc : ∃ c, G.IsCycle c) :
    CycleEdgeDecomp G (n - 2) := by sorry

-- 无桥 cubic 平面图
theorem bridgeless_cubic_planar (G : SimpleGraph V) (hplanar : Planar G)
    (hcubic : ∀ v, G.degree v = 3) (hnobridge : ∀ e, ¬ G.IsBridge e) :
    CycleEdgeDecomp G (5 * n / 6) := by sorry
```

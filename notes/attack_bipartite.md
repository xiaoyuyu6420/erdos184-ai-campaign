# 二部图攻击记录：Erdős #184 的二部图特例（2026-09-10；同日按审查判决改写定位）

**结论**：原命题「二部图 ≤ n−1 条」被 K_{3,n−3} 下界否证属实。**定位（诚实三档）**：
- **验证过的已知结果（独立复算，非新结果）**：二部图需要 (3/2−o(1))n 条（min 侧奇且 ≫1）——Erdős [Er83b] 1983 的构造本来就是完全二部图 K_{2k+1,·}，Bucić–Montgomery 已公开发表同一构造与同值计算（arXiv:2211.07689 源码 main.tex line 1060：(3/2 − 1/(2s))t ≡ t(3s−1)/(2s)）；本报告定理 1.1(i)/1.3/推论 1.2 仅为该界的独立初等重证（度预算推导）。
- **真实的定位贡献**：一般二部图上界 ≤ ⌊3n/2⌋−1 归结为 **Hajós 猜想（1968，著名开放难题）的二部特例**（引理 A），附精确归纳 GAP（§5 GAP-1）与两条失败修复记录；顺带修正下界情形 (ii) 为 f(K_{s,t}) ≥ (2s+t−1)/2（BM 未记载，K_{2,5} 处取等）。
- **已死**：下界定理的一切新颖性声明；观察 3.5 的「结构性发现」提法（该蕴含链 BM line 180 已明文记载：EG ⟺ 每个 n 顶点欧拉图可拆成 O(n) 个圈）。

**上界侧**：Δ≤4 二部图 ≤ ⌊3n/2⌋−1（严格，但被模板 Thm 1.3 的一般图 n−1 支配，仅作方法论垫路）；一般二部图 ≤ ⌊3n/2⌋−1 归结为引理 A（= Hajós 二部特例，开放）——数值证据真实（n≤7 全枚举 + n≤11 随机零反例、oracle 经精确 DP 交叉验证）但已被 Heinrich–Natale–Streicher（arXiv:1705.08724，Hajós 猜想对全部 n ≤ 12 欧拉图 IP 验证）覆盖；归纳证明有一处已精确定位的洞（GAP 见 §5）。引理 A 若真，则二部渐近常数 3/2 完全确定（配合定理 1.3）。
**证据强度**：下界 = 已知结果的独立重证；上界 = Δ≤4 完全证明 + 一般情形归约为 Hajós 二部特例（含精确 GAP 与全部失败尝试记录）。

## 0. 问题重述与记号

Erdős–Gallai #184：每个 n 顶点图的边集能否划分为至多 O(n) 个边不相交的圈与单边（Erdős 猜 n−1）。
站点（erdosproblems.com/184，2026-04-01 版）指出 **K_{3,n−3} 需要 ≥ (1+c)n 条，故 n−1 版本为假**。K_{3,n−3} 是二部图，所以二部图版 n−1 命题同样为假。真正的问题：二部图的最优常数是多少？

记号：
- G 二部图，|V(G)| = n。
- **f(G)**：把 E(G) 划分为「圈 ∪ 单边」所需成员数的最小值（模板论文 2509.01901 的 f_ce(G)）。
- **c(H)**：欧拉图 H 分解为边不相交圈所需圈数的最小值。
- K_{s,t}：完全二部图，s ≤ t；s 顶点一侧称 **S 侧**（每点度 t），t 顶点一侧称 **T 侧**（每点度 s）。
- 已知边界：Bucić–Montgomery [BM22] 一般图 f(G) = O(n log* n)；Erdős [Er83b] 一般图下界 (3/2−o(1))n；Pyber 1985 覆盖版 n−1；Akbari–Aloni–Beikmohammadi–Clow [2509.01901]：Δ≤4 ⟹ f ≤ n−1。

## 1. K_{3,n−3} 下界机理（任务要求的「先做」）与 K_{s,t} 完整下界

### 定理 1.1（K_{s,t} 下界；对已知界的独立初等重证，非新结果）

设 s ≤ t。则 f(K_{s,t}) 满足：
- **(i) s 为奇数**：f(K_{s,t}) ≥ t·(3s−1)/(2s)；
- **(ii) t 为奇数**（s 偶）：f(K_{s,t}) ≥ (2s+t−1)/2（2026-09-10 修正后的更强形式；2s+t−1 为偶故为整数，且强于旧陈述 ⌈(3s−1)/2⌉）；
- **(iii) s, t 均偶**：f(K_{s,t}) ≥ t/2。

> **来源注（2026-09-10 审查后补）**：情形 (i) 与推论 1.2 无新颖性——BM（arXiv:2211.07689v2 源码 line 1060）逐字记载 Erdős [Er83b] 1983 的 (3/2−o(1))n 构造即完全二部图 K_{2k+1, n−2k−1}（s = 2k+1 奇、t = n−2k−1 ≫ s），并给出同值计算 (3/2 − 1/(2|A|))|B| ≡ t(3s−1)/(2s)；站点 erdosproblems.com/184 的 (1+c)n 即 K_{3,n−3}，c = 1/3 是 BM 公式在 s = 3 的平凡取值。本节度预算推导为独立重证；情形 (ii) 的 (2s+t−1)/2 与情形 (iii) 的 t/2 是 BM 未记载的 footnote 级精化。

**证明**。设分解由 a 个边不相交圈 C_1,…,C_a 与 b 条单边组成。设圈 C_i 长 2k_i。

(a) *圈长约束*：圈是简单交替圈，每侧顶点在圈内至多出现一次，故 2 ≤ k_i ≤ s。

(b) *边守恒*：st = 2·Σ_i k_i + b，即 b = st − 2K，其中 K := Σ_i k_i。

(c) *T 侧预算*：T 侧每顶点度 = s；每个圈在任一顶点处恰用 2 条边；分解边不相交，故每个 T 顶点至多属于 ⌊s/2⌋ 个圈。每个圈 C_i 用 k_i 个 T 侧顶点（每点至多一次，见 (a)），故
  K = Σ_i k_i = Σ_{u∈T} (u 所属圈数) ≤ t·⌊s/2⌋。

(d) *圈数下界*：a = Σ_i 1 ≥ Σ_i k_i / max_i k_i ≥ K/s（由 (a)，max k_i ≤ s）。

(e) *合成*：f = a + b ≥ K/s + st − 2K = st − (2 − 1/s)·K。因 2 − 1/s > 0，用 (c) 中 K 的上界：
  - s 奇：K ≤ t(s−1)/2，f ≥ st − (2 − 1/s)·t(s−1)/2 = t·[2s − (2s − 2 − 1 + 1/s)]/2 = **t(3s−1)/(2s)**。∎(i)
  - s 偶，t 偶：K ≤ ts/2，f ≥ st − (2−1/s)·st/2 = st − st + t/2 = **t/2**。∎(iii)
  - s 偶，t 奇：T 侧顶点度 s 为偶，无奇性强制；改用 S 侧预算：每 S 顶点度 t 奇，至多属 ⌊t/2⌋ = (t−1)/2 个圈，故 K ≤ s(t−1)/2。代入：f ≥ st − (2 − 1/s)·s(t−1)/2 = st − (2s−1)(t−1)/2 = [2st − (2s−1)(t−1)]/2 = **(2s+t−1)/2**（2026-09-10 修正：原稿误写中间式为 (3s−1)/2，且「与 (i) 的 t(3s−1)/(2s) 恰为 s,t 角色互换的对偶」为假——角色互换的正确形式是 s(3t−1)/(2t)，与 (2s+t−1)/2 仅在 s = t 时相等）。由 t ≥ s 知 (2s+t−1)/2 ≥ (3s−1)/2，故旧陈述仍真但被低估；新陈述在 K_{2,5} 处给出 f ≥ 4，与真值 f(K_{2,5}) = 4 取等。∎(ii)

**推论 1.2（K_{3,n−3}，站点 (1+c)n 的显式 c）**：s = 3, t = n−3（n ≥ 6）时
  f(K_{3,n−3}) ≥ (n−3)·8/6 = (4/3)(n−3) = (1 + 1/3)·n − 4，
即站点所说的常数可取 c 逼近 1/3。

**机理（三句话版）**：K_{s,t}（s 奇）的瓶颈是**大侧 T 的度预算**——每个度 s 顶点至多喂饱 ⌊s/2⌋ 个圈（每圈吃掉它 2 条边），s 奇时该顶点的边无法全部配进圈，预算耗尽与圈数税（每圈至多用 s 个 T 顶点、至多吃 2s 条边）相乘给出 t(3s−1)/(2s)；由 K ≤ t(s−1)/2 还可读出单边数下界 b ≥ t。**该机理同时是上界的路线图**：要压低 f，就要让每条边尽量进圈（偶度化）且让圈尽量长（少付圈数税）。

### 定理 1.3（二部图下界；= Erdős [Er83b] 构造的重述，非新结果）

对每个 ε > 0 与充分大的 n，存在 n 顶点二部图 G 使 f(G) ≥ (3/2 − ε)·n。

**证明**：取奇数 s ≥ 1/ε，则 (3s−1)/(2s) = 3/2 − 1/(2s) ≥ 3/2 − ε/2。取 t ≥ (3−2ε)·s/ε（ε < 1 时 (3−2ε)/ε > 1，故 t ≥ s；t 可再取大使 n 充分大），令 G = K_{s,t}，n = s + t。由定理 1.1(i)：f(G) ≥ t(3s−1)/(2s) ≥ t(3/2 − ε/2)。另一方面 t ≥ (3−2ε)s/ε 两边乘 ε/2 即 (ε/2)t ≥ (3/2 − ε)s，于是
  (3/2 − ε)·n = (3/2 − ε)t + (3/2 − ε)s ≤ (3/2 − ε)t + (ε/2)t = t(3/2 − ε/2) ≤ f(G)。∎
（2026-09-10 修正：原稿阈值 t ≥ s(3−2ε)/(2ε) 差因子 2 且不充分——在 s = 1/ε 处代入即失败，正确阈值为 t ≥ (3−2ε)s/ε；原稿行内「3/2 − ε/2·2 = 3/2 − 1/s」为无效算式，已删。）

**渐近常数**：limsup_{n→∞} max{f(G) : G 二部, |V|=n} / n ≥ 3/2（由已知构造给出）。

**与 Erdős 一般下界的关系（2026-09-10 改写）**：模板论文引 Erdős [erdHos1983some] 的一般图 (3/2−o(1))n 构造，据 BM（arXiv:2211.07689 源码 line 1060）该构造**本身就是完全二部图** K_{2k+1, n−2k−1}。原稿此处设置的 (α)/(β) 二选一已裁决为 (α)（GAP-3 关闭）：本定理与 BM 已公开的同值计算重合，非新结果；其剩余价值是给出该下界的初等度预算机理，并作为上界侧「二部渐近常数 3/2」的匹配下界——若二部上界 3n/2 + o(n) 成立，二部类的精确渐近常数即 3/2。

## 2. 上界骨架（严格部分）

### 引理 2.1（偶子图余项是森林；= 模板论文 Thm 1.4 的论证）

G 任意图，H 为 G 的**边数最大**的偶子图。则 G − E(H) 是森林。

**证明**：若 F := G − E(H) 含圈 C，则 C ⊆ F 与 E(H) 边不相交；H ∪ C 每点度 = deg_H + deg_C ∈ 偶+{0,2}，仍为偶图，且边数更大，与 H 的极大性矛盾。∎

由此 + 森林边数 ≤ n−1（连通时 = n−1，一般 ≤ n − 分量数）：

**命题 2.2**：f(G) ≤ c(H) + |E(G)| − |E(H)| ≤ c(H) + n − 1，其中 H 为 G 的边极大偶子图。

于是**一切归约为：欧拉二部图的圈分解数 c(H) 能压到多小**。

### 定理 2.3（Δ≤4 二部图，严格，不依赖引理 A）

若 G 二部、Δ(G) ≤ 4，则 f(G) ≤ ⌊3n/2⌋ − 1。更一般地，Δ(G) = d 时 f(G) ≤ (d/8 + 1)·n − 1。

**证明**：取引理 2.1 的 H，F = G−E(H) 森林。H 是欧拉二部图，Δ(H) ≤ d。由模板论文 Thm 1.5（偶图分解为 Δ/2 个 2-正则子图，其证明经 König 型匹配交换，自含）：H 的边集分解为 d/2 个 2-正则子图（各块**不要求生成**，故非 2-因子）。每块至多 n_H 条边，且是若干圈的并；二部圈长 ≥ 4，故每块含 ≤ n_H/4 个圈 ⟹ c(H) ≤ (d/2)·(n_H/4) = d·n_H/8 ≤ dn/8。（2026-09-10 修正：原稿「每个 2-因子恰有 n_H 条边」不准——模板 Thm 1.5 明言各块 need not be spanning（非 2-因子），边数 ≤ n_H；计数不受影响。）
f(G) ≤ c(H) + |F| ≤ dn/8 + n − 1。d = 4: ≤ n/2 + n − 1 = ⌊3n/2⌋ − 1（n 偶时 3n/2−1，n 奇时 ⌊3n/2⌋−1 = 3n/2 − 3/2 < n/2 + n − 1，改陈述为 f ≤ 3n/2 − 1 实数值即可）。∎

（对照：模板 Thm 1.3 对 Δ≤4 **一般图**给 n−1；二部版我们的 3n/2−1 弱于它，但这是给「无界 Δ」路线垫路的严格基线。）

### 关键引理 A（= Hajós 猜想（1968）的二部特例，开放）

> **引理 A（二部版，未证明）**：每个非孤立顶点数为 n 的欧拉**二部**图可分解为至多 ⌊n/2⌋ 个边不相交圈。

**文献定位（2026-09-10 审查后补）**：引理 A 是 **Hajós 猜想（1968）**的限制版——Hajós 猜想：每个 n 顶点欧拉图可拆成 ≤ ⌊(n−1)/2⌋ 个边不相交圈，一般情形至今开放（Lovász 1968；arXiv:1911.07778 摘要 "the general case remains open"；Fuchs–Gellert–Heinrich 2020；Girão–Granet–Kühn–Osthus）。引理 A 取二部子类，界 ⌊n/2⌋ 还略弱于 Hajós 的 ⌊(n−1)/2⌋。检索未见二部特例已有一般结果（K_{2,2m} 紧例说明二部界不能降到 n/2 − O(1) 以下），作为攻击目标仍合法，但任何进展的表述必须以 Hajós 猜想为基准。

若引理 A 真：f(G) ≤ ⌊n_H/2⌋ + n − 1 ≤ ⌊n/2⌋ + n − 1 = **⌊3n/2⌋ − 1** 对一切二部图成立（命题 2.2 直接代入）。结合定理 1.3 即得二部图渐近常数 = 3/2（完全确定）。

## 3. 引理 A 的证据

### 3.1 数值证据（暴搜，零反例）

- **n ≤ 6 一般图全体**（26704 个连通图 + 低阶）：c(H) ≤ ⌊n/2⌋ 与 f(G) ≤ ⌊3n/2⌋−1 零违规。
- **n = 7 一般欧拉图全体**：26614 个连通欧拉图，c(H) ≤ 3 = ⌊7/2⌋ 零违规；c/n 极大值 = 3/7 ≈ 0.429，由 C₃-花（c = (n−1)/2）及 K₇（Hamilton 三分解）达到——极值结构与「花」吻合，从不超 n/2。
- **n = 7 二部连通图全体**：67263 个，f ≤ 9 零违规；max f/n = 6/7 = 0.857（恰为 K_{3,4}，与定理 1.1 构造族吻合）。
- **n = 8,9,10,11 随机欧拉图**（一般 + 二部各 600/档，密度 0.35–0.85，奇度配对法生成）：c ≤ ⌊n/2⌋ 可行性判定零违规；可行性 oracle 与精确最小化 DP 交叉验证 300/300 一致（注：初版 oracle 有两处实现 bug——失败缓存单调性、边索引/位标志错位——均已修复并以精确 DP 复核，曾产生的两个假「反例」经精确 DP 证实 c = 3 ≤ 4）。
- **紧性例证**：c(K_{2,2m}) = m = n/2 − 1（恰拆成 m 个 C₄；数值确认）——二部双心「风车」族使引理 A 的界渐近取等，**⌊n/2⌋ 不能再降**。
- **小 n 极值对照**：一般欧拉图 c 的线性下界记录 = C₃-花的 (n−1)/2（达到但不超 n/2）；若 Hajós 猜想为假，超线性机制（ω(n) 增长，将证伪 EG，见 §3.4）必然结构特殊。
- **覆盖注（2026-09-10）**：Heinrich–Natale–Streicher（arXiv:1705.08724）已用 IP 方法验证 Hajós 猜想对**全部 n ≤ 12 欧拉图**成立——直接包含并超越本节全部数值范围；本节数值作为独立复算保留，边际证据价值有限。

### 3.2 一个「近乎证明」及其洞（诚实记录）

**归纳架构**（对非孤立顶点数 n 归纳）：取圈 C，令 H′ = H − E(C)（欧拉性保持：圈内各点度 −2 或 0）。按 |V(C) ∩ supp(H′)| 分三情形：
- **(i) ≥ 2 个共享顶点**；
- **(ii) 恰 1 个**（「耳朵」：C 除连接点 x 外全是度 2 顶点）——此情形证明干净：剥耳朵 c(H) ≤ 1 + ⌊(n−|C|+1)/2⌋ ≤ ⌊n/2⌋（|C| ≥ 4）；
- **(iii) 0 个**（C 是独立分量）——同样干净：c ≤ 1 + ⌊(n−|C|)/2⌋ ≤ ⌊n/2⌋。

**洞在情形 (i)**：我原稿断言「n′ ≤ n − 2」，其隐含推理是「共享 ≥ 2 ⟹ 孤立 ≥ |C|−2 ⟹ n′ = n − 孤立 ≤ n − 2」。**这是错的**：n′ = n − (|C| − 共享数)，共享数可以高达 |C|（即 C 的每个顶点在 H 中度 ≥ 4，删 C 后**无孤立点**），此时 n′ = n，账本 1 + ⌊n/2⌋ 溢出。最小活例是 **K_{4,4}**：删任一 C₄ 后其四个端点度 4→2、无孤立点，n′ = n = 8，归纳账本给 1 + ⌊8/2⌋ = 5，而真值 c(K_{4,4}) = 2 ≪ 5（全部删法实测确认）。（2026-09-10 修正：原稿举 K_{2,4} 为活例系误——K_{2,4} 中任何 C₄ 恰用两个度恰 2 的 T 侧顶点，删除后必孤立，n′ 恒 = 4，账本 1 + 2 = 3 = ⌊6/2⌋ 不溢出，按本归纳参数根本不是溢出例。）**归纳的记账方式本身失效，不是反例。**

### 3.3 两次修复尝试的失败记录

- **弧插入（absorbing C into the decomposition of H′）**：把 C 视为分解 D′（H′ 的归纳分解）上的若干弧段（度 2 顶点切弧），每段两端落在 D′ 的圈上，试图把弧段「插入」对应圈。问题：把弧替换进圈 Q 会**挤出 Q 的原有弧**，被挤出的边必须继续传递（环流推送），过程不保证终止；跨圈弧段虽能把两圈并一（账本 −1），但段与分解圈的对齐无控制。
- **织路（linkage route，模仿模板论文 Lemma odd paths）**：C = v₁…v_k，取 H′ 中 v_i→v_{i+1} 的极小路组 P_i，极小性给边不相交；T = ∪P_i 与 C 拼成偶图分解。账本需求 1 + c(T) ≤ |V(C)|/2 量级，但二部性迫使每条 |P_i| ≥ 3（v_i, v_{i+1} 异侧 ⟹ 路长奇），得 Σ|P_i| ≥ 3k，而预算只有 2k − 4。**数量级不匹配，死路。**

### 3.4 关键张力：c(H) 的线性界 = EG 的 O(n) 版的钥匙

由命题 2.2 的链条（严格）：对一般图 G，f(G) ≤ c(H) + |E(G−E(H))| ≤ c(H) + n − 1，H 为边极大偶子图。于是：

> **观察 3.5**：若「每个 n 顶点欧拉图可分解为 ≤ C·n 个边不相交圈」（C 为任意绝对常数）为真，则一切图 f(G) ≤ (C+1)·n − 1 = O(n)，Erdős–Gallai 的 O(n) 版本即被解决。

**溯源注（2026-09-10 审查后补；非本报告发现）**：该蕴含链 Bucić–Montgomery 已明文记载——arXiv:2211.07689 源码 line 180：「Conj [EG] **is equivalent to** conjecturing that every n-vertex Eulerian graph can be decomposed into O(n) cycles」；line 1060：「Hajós's conjecture implies the Erdős–Gallai conjecture, as any n-vertex graph can be decomposed into an Eulerian graph and at most n−1 edges…」，与命题 2.2 的「极大偶子图 + 森林余项」路线完全同构。原稿的「结构性发现 / 全题被压缩到一个引理」提法撤回。

**现状（取代原 (α)/(β) 二选一框架，2026-09-10）**：「c(H) ≤ C·n 是否有简单证明」不是被社区错过的简单事实，而是 **Hajós 猜想——公开开放 58 年的著名难题**，已确认于多个特例类（最大度 4：Granville–Moisiadis；平面：Seyffarth；射影平面：Fan–Xu；路宽 ≤ 6：Fuchs 等），数值侧 HNS（arXiv:1705.08724）已对全部 n ≤ 12 欧拉图 IP 验证。且原框架在逻辑上不对称：欧拉图上 f(H) = c(H)（每顶点关联的单边数为偶，单边集自身并成圈、可并入圈分解，故单边成员可消去——原稿未点明此引理），因此「c 超线性」直接推出 **Erdős–Gallai n−1 版为假**，而非中性的「困难内核」；对称二选一的表述误导，撤回。
- 判别实验：n ≤ 7 全枚举中 c/n 的极大 = 3/7 ≈ 0.429（C₃-花达到 (n−1)/2；K₇ 的 Hamilton 三分解同为 3），从未逼近超线性所需的增长形态；但 11 个顶点远不足以区分「线性」与「log* 型」增长（HNS 的 n ≤ 12 同样不够）。

**对二部版的含义**：一般版的线性界即 Hajós 猜想本身（开放）；二部特例（引理 A）可独立为真（潜在反例须依赖奇圈/非二部结构），若真则二部图 f = Θ(n)、常数 3/2 精确（配合定理 1.3）。**二部版引理 A 仍是合理的攻击目标：要么给出二部精确常数定理，要么其反例自动构成 Hajós 猜想的反例。**

## 5. GAP 清单（精确陈述）

**GAP-1（引理 A，唯一核心缺口）**：欧拉二部图 H，n 非孤立顶点，是否存在 ≤ ⌊n/2⌋ 圈的分解？卡点 = 删除任一圈 C 后无孤立点（C 的全部顶点度 ≥ 4）的情形，归纳账本溢出；弧插入与织路两条修复均已试败（§3.3）。
- 为什么难：该情形中 C 与 H′ 高度交织，任何「删 + 补」操作要么挤出旧边（终止性失控），要么路长预算超支（3k vs 2k−4）。
- 可能的出路：① 极小反例结构分析（证明 c(H) > n/2 的极小反例必有花瓣/耳朵结构，与 §3.2 情形 (ii)(iii) 的可剥性矛盾——即证明「无花瓣极小反例 ⟹ 存在可删圈且删后孤立 ≥ 2」）；② 换归纳参数（如 (n, m) 字典序或「度 ≥ 4 顶点数」）；③ 圈空间/匹配对偶（K_{2,2m} 取等 suggests 对偶对象是「双心结构」的某种匹配覆盖数）。

**GAP-2（2026-09-10 改写）**：引理 A（= Hajós 猜想二部特例）是否为真。注意一般版即 Hajós 猜想本身；其与 EG O(n) 版的等价性 BM line 180 已明文记载（非本报告发现）。若引理 A 真，二部图渐近常数 3/2 完全确定（配合定理 1.3），但一般 EG 不随之解决（Hajós 一般版仍开放）。

**GAP-3（已裁决关闭，2026-09-10）**：Erdős [erdHos1983some] 的 (3/2−o(1))n 构造**已确认本质二部**——BM（arXiv:2211.07689 源码 line 1060）逐字记载该构造为 K_{2k+1, n−2k−1}（s = 2k+1 奇、t = n−2k−1 ≫ s）及同值计算 (3/2 − 1/(2|A|))|B|。此 GAP 不复存在。

**GAP-4**：f(G) ≤ ⌊3n/2⌋ − 1 的常数项优化：K_{2,2m}（欧拉）与「花 + 森林」的组合暗示真极值可能是 ⌊3n/2⌋ − O(1) 的具体形式；s 固定的参数化上界（猜想：min 侧 = s 奇时 f ≤ t(3s−1)/(2s) + O_s(1)，即下界逐点可达）未攻。

```lean
import Mathlib.Combinatorics.SimpleGraph.Basic
-- 目标陈述（本机未装 Lean，仅给出形式化目标）

/-- 把 E(G) 划分为圈与单边所需成员的最小数 -/
noncomputable def cycleEdgeDecompNumber {V : Type*} (G : SimpleGraph V) : ℕ := by
  classical exact sInf { k : ℕ | ∃ (S : Finset (Finset ↥G.edgeSet)),
    (∀ e ∈ G.edgeFinset, ∃! P ∈ S, e ∈ P) ∧
    (∀ P ∈ S, G.isCycleOn P ∨ P.card = 1) ∧ S.card = k }

/-- 定理 1.1(i)：完全二部图 K_{s,t}（s 奇）的下界 -/
theorem K_st_lower_bound (s t : ℕ) (hst : s ≤ t) (hs : Odd s) :
    cycleEdgeDecompNumber (SimpleGraph.completeBipartite s t)
      ≥ t * (3 * s - 1) / (2 * s) := by sorry

/-- 推论 1.2：K_{3,n-3} 需要 (4/3)(n-3) -/
theorem K_3_n_minus_3 (n : ℕ) (hn : 6 ≤ n) :
    cycleEdgeDecompNumber (SimpleGraph.completeBipartite 3 (n - 3))
      ≥ 4 * (n - 3) / 3 := by sorry

/-- 定理 1.3：二部图下界 (3/2 - ε)n 可达 -/
theorem bipartite_lower_bound (ε : ℝ) (hε : 0 < ε) :
    ∃ (N : ℕ), ∀ n ≥ N, ∃ (G : SimpleGraph (Fin n)), G.Bipartite ∧
      (cycleEdgeDecompNumber G : ℝ) ≥ (3/2 - ε) * n := by sorry

/-- 引理 A（猜想）：欧拉二部图拆成 ≤ ⌊n/2⌋ 个圈 -/
theorem eulerian_bipartite_le_halves {V : Type*} [Fintype V]
    (H : SimpleGraph V) (hbip : H.Bipartite) (heuler : ∀ v, Even (H.degree v)) :
    ∃ (C : Finset (Finset ↥H.edgeSet)),
      (∀ e ∈ H.edgeFinset, ∃! Q ∈ C, e ∈ Q) ∧
      (∀ Q ∈ C, H.isCycleOn Q) ∧
      C.card ≤ (H.support : Finset V).card / 2 := by sorry

/-- 定理 B（条件于引理 A）：二部图全体 ≤ ⌊3n/2⌋ − 1 -/
theorem bipartite_upper_bound {V : Type*} [Fintype V]
    (G : SimpleGraph V) (hbip : G.Bipartite)
    (hA : ∀ (H : SimpleGraph V), H.Bipartite → (∀ v, Even (H.degree v)) →
      ∃ (C : Finset (Finset ↥H.edgeSet)), partition_into_cycles C H ∧
        C.card ≤ (H.support : Finset V).card / 2) :
    cycleEdgeDecompNumber G ≤ 3 * (Fintype.card V) / 2 - 1 := by sorry
```
